# BODYGUARD — Project Charter

노트북 웹캠과 3D 아바타를 이용해 스트레칭 동작을 선택하고, 자신의 움직임을 시범과 비교하며, 수행 기록을 확인하는 웹 서비스입니다.

> **개발 중인 프로젝트입니다.** 실제 웹캠 추종, 코칭 판정의 정확도, 최종 아바타, 전체 사용자 흐름과 운영 서비스 배포는 아직 완성·검증되지 않았습니다. 시제품과 테스트 결과를 출시 가능한 기능으로 해석하지 마세요.

## 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 팀 | UHI · 한성대학교 오픈소스 AI·SW 융합 프로젝트 |
| 대상 | 성별이나 직업에 관계없이 스트레칭이 필요한 사용자 |
| 해결할 문제 | 혼자 스트레칭할 때 자신의 움직임을 시범과 비교하고 수행 이력을 확인하기 어렵습니다. |
| 목표 | 신체 확인과 동작 선택부터 3D 시범·사용자 아바타 비교, 안내, 기록까지 웹에서 연결합니다. |
| 이용 환경 | 노트북 웹캠 한 대와 브라우저를 우선합니다. |
| 범위 | 웰니스 목적의 스트레칭 안내이며 질환을 진단하거나 치료하지 않습니다. |

## 사용자 경험과 첫 출시 범위

1. 계정으로 로그인한 후 신체 확인을 통해 동작을 추천받거나, 스트레칭을 직접 고릅니다.
2. 동작에 맞는 촬영 범위를 확인하고 코칭을 시작합니다.
3. 사용자의 움직임을 반영하는 아바타와 현재 단계의 시범 아바타를 나란히 비교합니다. 관찰 가능한 범위에서 필요한 부위와 수정 안내를 제공합니다.
4. 수행 결과를 확인하고 자신의 기록을 날짜별로 조회·관리합니다.

첫 출시 범위는 **신체 확인·추천, 직접 선택, 남녀 3D 아바타 기반 코칭, 계정과 수행 기록**입니다. 실제 동작별 안전성·카메라 관찰 가능성·정확도 검증이 선행되어야 합니다. 확인할 수 없는 관절을 임의로 추정해 수행 성공으로 처리하지 않습니다.

뷰티·미용, 자세 알림, PDF 리포트, LLM 리포트 요약, 변화 탐지는 출시 후로 이월했습니다. 발표 자료의 설명 AI 및 그 밖의 후속 기능은 설계·검토 항목이며 첫 출시 완료 기능으로 간주하지 않습니다. [첫 출시 계약과 단계별 기준](bodyguard/docs/release-plan.md)

## 현재 개발 상태

아래는 저장소의 개발 및 검증 범위를 요약한 것입니다. 합성 입력이나 시험 계정을 사용한 결과는 실제 사용자 검증이 아닙니다.

| 영역 | 현재 상태 | 남은 주요 작업 |
| --- | --- | --- |
| 회원·계정 | 이메일 계정, 세션, 복구·탈퇴와 기록 관리의 로컬 구현 및 시험 | 실제 메일·Google 공급자 연결과 운영 검증 |
| 동작 선택·추천 | 동작 카탈로그와 추천 후보 흐름 개발 | 동작 근거·촬영 조건·추천 기준 실측 및 사용자 흐름 통합 |
| 3D 아바타·코칭 | Blender 모델과 시범·사용자 아바타 제어, 부위 피드백 시제품 | 남녀 모델의 외형·변형·움직임과 실제 웹캠 추종 품질 검증 |
| 기록 | 본인 기록 저장·조회·삭제와 집계 개발·시험 | 실제 코칭 결과 생산·저장과 화면 전체 연결 |
| 출시·검증 | 격리 환경의 단위·브라우저·API·DB 시험 수행 | 실제 사람·노트북 조건별 정확도·성능, HTTPS·보안·라이선스·전문가 검토 |

홈의 인체는 정지 시안, 동작 영상은 검수 후보이며 웹캠 체험의 오른쪽 아바타는 중립 자세입니다. 동작별 교정 판정·로그인·기록 저장은 제공하지 않으며, 실제 사용자별 추종 정확도와 최종 아바타 품질도 검증 중입니다. [검수 페이지 설명](bodyguard/pages-preview/README.md) · [수업 제출 입력값과 접속 확인](docs/07_repository_submission.md)

[2026-11-12 공개 교체·외부 검증 결과](bodyguard/docs/review/pages-deployment-20261112/README.md)를 확인할 수 있습니다.

개발 중인 전체 웹과 테스트 방법은 [프런트엔드 안내](bodyguard/frontend/README.md)와 [기능별 진행 현황](docs/05_10w_review.md)을 확인하세요.

발표 자료에서 제시한 목표는 포즈 인식 15fps 이상, 피드백 지연 1초 이내, 육안 판정 대비 일치율 80% 이상입니다. 이는 목표치이며 실제 서비스의 달성 수치를 뜻하지 않습니다. 동작·기기·촬영 조건별 실측과 사용자 검증이 필요합니다.

## 처리 방식과 개인정보

```text
노트북 웹캠
  → 브라우저에서 포즈 추정
  → 관찰 가능 여부와 동작별 기준 확인
  → 사용자·시범 아바타와 피드백
  → 필요한 수행 요약을 계정별로 저장
```

카메라 영상과 원시 관절 좌표는 브라우저에서 처리하며 저장하거나 서버로 전송하지 않는 것이 프로젝트 원칙입니다. 계정·수행 기록 등 서버 저장 항목은 목적과 처리 범위를 별도로 안내합니다. 이 서비스의 결과는 의료 진단이 아니며, 통증이나 어지러움이 발생하면 동작을 멈추고 전문가와 상담해야 합니다.

## 기술 및 오픈소스

| 영역 | 기술 | 용도 |
| --- | --- | --- |
| 웹 | React, TypeScript, Vite | 웹 화면·상태·개발 환경 |
| 신체 추정 | MediaPipe Tasks Vision | 사전 학습 모델을 이용한 브라우저 포즈 추정 |
| 3D | Three.js, React Three Fiber, Blender | 아바타 렌더링·제어와 모델 제작 |
| 서버·데이터 | FastAPI, Python, PostgreSQL | 계정·수행 기록 API와 저장 |
| 테스트 | Vitest, Playwright, pytest | 단위·브라우저·API 검증 |

제품의 AI 접근은 **딥러닝**입니다. MediaPipe의 사전 학습 모델로 신체 특징을 추정하고, 별도의 동작별 규칙으로 코칭을 구성합니다. 자체 모델을 학습한 것은 아닙니다. 개발 보조 도구를 사용한다는 이유로 제품을 에이전트형 AI로 분류하지 않습니다.

오픈소스 코드·모델·3D 에셋의 라이선스는 각각 확인해야 합니다. 프로젝트의 MIT 라이선스가 모든 외부 의존성에 적용된다는 뜻은 아닙니다. 최종 배포물의 고지와 라이선스 검토는 진행 중입니다. [라이선스 검토](bodyguard/docs/stage5-license-inventory-runbook.md)

## 로컬 개발

Node.js와 pnpm을 준비한 뒤 프런트엔드를 실행합니다.

```bash
cd bodyguard/frontend
pnpm install
pnpm dev
```

브라우저에서 안내된 로컬 주소를 엽니다. 계정·기록 기능에는 별도의 백엔드·PostgreSQL 설정이 필요하고, 실제 이메일 인증에는 메일 공급자 설정이 필요합니다. 첫 실행 시 모델 자산 다운로드가 필요할 수 있습니다. 자세한 조건은 [프런트엔드](bodyguard/frontend/README.md)와 [백엔드](bodyguard/backend/README.md) 안내를 따릅니다. 로컬 개발 화면은 외부에서 접속할 수 있는 공개 테스트 URL이 아닙니다.
