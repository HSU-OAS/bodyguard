# A187–A189 — 원래 전문 목 배치와 얼굴 곡면 실제 대조

**새 아바타를 채택하거나 완료 처리하지 않았다.** 최신 사진의 얼굴·목·연속 연결, 남녀 통일 무의상 백색, 필요한 신체 구조/리깅 정확도와 전체1~6단계/승인 기준은 유지한다. 개발 A37·A-02/A-08 P2·Draft PR #9 미병합이다.

A187은 전문 body·blank-head·원래 동반 목 에셋의 부모 행렬을 독립 대조하고 동일 높이의 실제 native 단면을 만들었다. 부모 깊이축17.523/46.570mm 차이를 제거한 비교도 따로 기록했지만 **새 정렬로 선택하지 않았다**. 높이90%에서는 body 외곽/머리 면적 중심의 Y차가 남0.170mm·여9.509mm로 원래 배치에서도 가까운 반면, 내부 얼굴 cavity와 아래 턱/목 단면의 형태는 다르다. 따라서 부모 Y를 단순 제거하거나 경계 점 수만 맞추는 것은 연결 해법/해부학적 등록이 아니다. 동반 목 단면도 body보다 폭이 좁아 안전한 교체로 승인하지 않았다.

A188은 기존 전문 머리 cage266점 중 남181/여183점에 연속 마스크와 native XYZ SMOOTH12회/.5를 적용했다. cage 면/위상과 마스크0점은 정확히 유지했고 실제12PNG를 비교했다. 턱 끝이 둥글어졌지만 눈썹 같은 띠가 남아 미채택이다. 후방 cage 고정은 **모든 subdivision 후방점 불변**이라는 뜻이 아니다.

A189는 같은 전문 cage 점의 native convex 외곽을 참조해 앞면의 오목한 부분만 Y투영한 뒤 같은 국소 XYZ 정제를 비교했다. 새 구·원기둥/절차 인체·교체 메시를 생성하지 않았으며 전문 cage 위상을 유지했다. 실제12PNG에서 정면의 눈썹 띠는 줄었지만 측면 턱/뒤쪽 볼 윤곽과 목 연결은 아직 미달이다. 투영 중 최대 이동69.029/65.437mm, 최종 원래 cage 대비20.337/27.232mm를 그대로 기록한다. 이 머리 분리 시험 수치는 기존 목/skin의 추가6mm guard를 통과했다는 의미가 **아니다**. 턱 아래/옆면의 과한 투영을 실제 표면 구간으로 제한한 뒤 연결할 필요가 있다.

세 native 실행은 실제 exit0이고 현재 A146 전체 좌표/skin/면/group·각163rest bone/행렬 완료 snapshot과 입력 원본/전문 bundle 해시가 그대로다. **실행 성공·정면 개선은 최종 외형/해부학/임상 승인과 다르다.** 별도 머리 복사본만 수정했으며 서비스 에셋과 현재 몸/목/리그를 바꾸지 않았다.
