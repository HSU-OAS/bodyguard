## 해석과 수정 방향

A279는 수동 지정 픽셀의 **실제 주변 위치**를 확인한 진단이다. 경계 근처 일부 점이 기존 ROI 밖이라는 사실만으로 더 넓은 조형이 필요하다고 결론 내릴 수 없다. A280은 실제 이동/접힘 회귀로 반려했으며 강도/보호 기준을 낮추거나 좌표/skin을 사후 복구하지 않았다.

A282는 여성 여섯 대표 행에서 수동 guide 근처에 실제 신체–배경 경계가 있음을 확인한다. 자연스러운 목·승모근 **외곽선은 필요한 형상**이므로 그것을 없애는 것을 ‘내부 seam 개선’으로 목표 삼지 않는다. 이 증거는 모든 그림자 픽셀이 외곽선이라는 자동 영상 판정이나 전체 목/외형/해부학 PASS가 아니다. 여러 ray miss도 원본에 구멍이 있다는 뜻이 아니며 실제 ray와 선언한 scan 범위를 기록했다. 남성 마지막행의 미분류를 숨기지 않는다.

**A-02/A-08 외형 P2는 유지**한다. 내부 뒤통수의 패치처럼 보이는 표면과 남녀 전체 다각도/관절 확대·웹 품질은 별도로 검수해야 한다. 다음은 내부 posterior 마감의 실제 geometry·조명/표면을 분리해 필요한 국소 접합부만 다루는 것이다. 이미 실패한 아래 범위 확장이나 radial/강도 반복으로 완료하지 않는다. 필요한 구조를 지우거나 리그·가중치 정확도를 낮추지 않는다.

이번 새원본/GLB118·34렌더·Chrome·frontend 회귀는 **미실행**이다. 새 저장 형상이 없는 진단/실패 구간이며 이전 A278의 실제118개 변형·Chrome3개·frontend151개 회귀 증거를 새 수정본의 성공으로 전용하지 않는다. 이전 A276/A278 원본/GLB·A37 개발 기본값은 변경하지 않았다. 실제 시범/사용자 리타게팅/사람/카메라·전체1–6단계는 미완료이고 시크릿/계정/운영 DB/배포/비용 승인 경계도 그대로다.
