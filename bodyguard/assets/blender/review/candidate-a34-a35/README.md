# A34/35 제작 시험 — 기술 통과와 반려를 구분

2026-10-01 · Blender5.1.1에서 A27 별도 사본을 정제했다. 대형 후보 원본은 로컬 제작 폴더에 보존하며 현행 원본/웹 GLB를 덮지 않았다. A33 코드의 재현 기준은 `dd21cf1`이며 아래는 그 뒤의 native 제작 시험이다.

A34는 새 손목 절단 경계도 국소 smoothing에 포함하고 의상 rim에 native Bevel0.3mm/2segments를 적용했다. [실제 목](a34-female-neck.png)·[손](a34-male-hand.png), 원본 SHA-256 `ab7a07c8fd48794254b988d4a06a99eebca80109d358c095d28ead2f2f0c906b`. [전체 보고서](a34-deformation-report.json)는 118개 변형·242행, 최대edge2.943930·침투/방향 불일치0·failures0으로 실제 통과했다. 의상 경계/손목 표면이 참조 수준으로 완성됐다는 뜻은 아니다.

A35는 어깨의 원형 장식을 제외하고 상의 subdivision을2로 늘리며 모델의 상의 arm 가중치 제외 조건을0.15→0.45로 바꿔 시험했다. 이는 모델 패턴용이지 사용자/의학 판단값이 아니다. 상의102,871vertices로 증가했지만 [실제 목](a35-female-neck.png)·[손](a35-male-hand.png)에서 더 좋은 외형을 보장하지 않았다. 원본 SHA-256 `ee8085c803c5192f28d5913b468db601bfcb5502113102223283258b4efa598b`.

[A35 전체 QA](a35-deformation-report.json)는 **실패**다. 118개·242행 중 상의 침투 최대76표본·57개 실패 항목, 방향 불일치0이었다. edge2.943930·의상 연결1만 보고 합격시키지 않았다. subdivision1과 원래 arm 제외 조건으로 되돌리고 실제 곡면 연결·국소 정제로 검증한다. offset/침투 허용 기준을 늘려 감추지 않는다.

둘 다 GLB/웹/사람 시험은 **미실행**이다. 기존 A27 웹은 그대로이고 PR #9 외형 P2·S2.4/2단계는 미완료다. 이 시험 결과를 전문가 운동 승인이나 출시 검증으로 표시하지 않는다.
