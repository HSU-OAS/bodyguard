## 확인한 원인과 최소 비교

앞선 손목 핀/주름은 하나의 원인이 아니었다. [아티스트 메시 진단](asset-strip-diagnostic.png)은 새 신체 연결부만 임시 magenta로 칠한 **사람 데이터 없는 모델 QA 렌더**다. 신체 밖에 남은 백색 조각은 쇼츠에 섞인 팔 표면이었다. XYZ 범위만으로 신체에서 의상을 잘라 팔이 골반 옆에 있을 때 조각이 함께 남았다. 상의와 동일한 기존 arm 가중치 제외 조건을 쇼츠에도 적용했고, 모든 파생 의상이 한 연결 표면인지 제작/별도 QA에서 검사한다. 이전 기록의 국소 Smooth 원인 추정만으로 설명되지 않음을 이 실제 진단으로 보완한다.

[의상만 고친 최소 후보](minimal-fix-wrist.png)는 원래 전문 손목을 보존했으나 깊은 연결 주름이 남았다. 이 A32b와 native 손목 재구성 A32는 각각 기존 하네스의118개 기술 검사를 통과했지만 외형은 달랐다. 따라서 A33에는 capped Boolean 접합의 손목 구간만 native BMesh 절단·bridge·분할/정제한다. 원래 손가락 정점/가중치와 영역 밖 좌표는 보존 assertion으로 확인하고 기존 distal-hand QA 인덱스를 새 위상에 맞춰 재매핑한다. 인체를 도형으로 다시 만들지 않는다. 기술상 정점 수는 남142,915·여140,698로 바뀌었으며 리그는 각각163 bones다. 절단 폭/arm 가중치 조건은 아티스트 모델 편집용이지 사용자/의학 임계값이 아니다.

제작 중 구형 ROI는 가까운 다리도 절단해 경계3개 검사에서 저장 전에 중단됐다. 기존 arm 가중치로 다른 표면을 제외했다. native subdivision 뒤 캐시된 BMVert 핸들로 새 정점을 식별한 방식은 손가락 보존 검사에서 실패해 저장 전에 중단됐다. 기존 좌표로 정점을 구분한 뒤 영역 밖/손가락 보존을 실제 다시 통과했다. A31g는 [전체 기술 QA 실패](a31g-failed-report.json): 쇼츠 내부1/방향 불일치94 등4개 실패로 반려했다. 불일치를 허용하거나 손가락 선택을 삭제해 통과시키지 않았다.
