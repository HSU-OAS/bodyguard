## 사용 범위와 재검수

`pnpm dev`의 `/dev/avatar`에만 후보와 기술 재생을 둔다. production에 이 경로·뷰어·GLB를 포함하지 않는다. 시범 운동 액션, 카메라, 좌표 저장/전송, 성공 타이머는 없다. 에러 주입은 제어된 시험이며 실제 운영 장애 이력으로 표시하지 않는다.

Vitest 82개·사람 없는 시험 카메라 Chrome 회귀 1개·실제 API/격리 PostgreSQL의 production 계정 Chrome 9개(실제 60초 재발송 포함)도 실행했다. 마지막 계정 회귀에서 두 개발 경로가 production 404이고 계정 진입에서 GLB/WASM이 요청되지 않는지 확인했다. 메일은 시험 전달 장치이며 실제 Gmail 검증이 아니다.
