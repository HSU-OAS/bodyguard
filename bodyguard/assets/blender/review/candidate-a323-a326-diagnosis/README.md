## 검증·기존 증거 보존

최신 main `9733e4c`(S2.5b PR #15 실제 병합)를 정상 merge commit `1a9d156`으로 포함했다. 첫 흐름 문서의 한 충돌은 양쪽의 유효한 내용을 보존해 해결했다. 최신 합쳐진 frontend **211개/17파일**, Biome67파일, TypeScript, production build를 실제 실행했다. 이는 새 아바타나 실제 사람의 코칭 시험이 아니다.

새 Python9개 Ruff E/F(명시적 runtime path 설정 후 import E402 제외)·format 통과. 첫 정적 unused import/긴 줄 오류는 native 실행 전에 보완했다. Native는 Blender5.1.1 `b70da489d7f4`·NumPy2.3.4·기존 임시 SciPy1.16.2를 실제 사용했다. 새 설치·전역/프로젝트 의존 변경0. [기존 BSD runtime 권리 증거](../candidate-a316-a322-review/runtime-license/)를 유지한다. [공식 SciPy 풀이 API](https://docs.scipy.org/doc/scipy/reference/generated/scipy.sparse.linalg.spsolve.html)는 API 근거이며 최신 문서1.18과 실제 실행1.16.2를 구별한다. Blender 문서 직접 열기는402로 실패했으며 열람 완료로 표시하지 않는다.

23개 exact gzip 사본(계약·JSON·실패 코드·정리 코드·하네스·의존 도구)과 manifest/README/checker를 추가했다. 기존1123개 + A316–A322 폴더141개 = **1264파일 SHA 불변**을 전후 확인했다.
