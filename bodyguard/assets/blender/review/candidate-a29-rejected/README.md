A27의 별도 사본에서 `tailor_avatar_candidate.py`를 실행했다. 제작 코드 당시 SHA-256 `93a89f719fbb230241386775ffafe2484a9ecf6cf1e76140e82919bf4abf9819`, 임시 원본 `draft-a29-native.blend` SHA-256 `2dedbc492abb1b4efb71ee870e03cf92f397b2a0b9c92f6a6d4bedd42de825e5`다. 재현 코드는 이 기록을 추가한 Git 버전을 사용한다. 별도 원본은 로컬 제작 폴더에 보존했으며 반려한 대형 바이너리를 출시 에셋으로 복제하지 않았다.

여성 의상은 face 중심 삭제 대신 native BMesh contour 절단·보간한 전문 표면에서 만들었다. 인체의 모든 기존 정점/리그/가중치를 보존했고 남성 골반은 별도 돌출 쉘 대신 기존 전문 신체를 국소 정제했다. 단순 도형 인체·새 외부 에셋은 없다. 처음 제작에서 modifier 적용 뒤 무효화된 group 참조 때문에 저장 전에 실패했고 이름 재조회로 수정한 뒤 실제 생성/렌더를 재실행했다. 실패를 합격으로 세지 않았다.

[전신](front.png)·[여성 뒤](female-back.png)·[손목](female-hand.png)·[목/상의](female-neck.png) 원본 렌더를 직접 확인했다. 의상 경계는 더 연속적이지만 **손목의 국소 Smooth가 표면을 과하게 수축시켜 깊은 주름/핀치가 생기고, 같은 offset으로 겹친 상의/쇼츠가 허리에서 z-fighting**한다. 사진 수준의 완료품이 아니므로 **채택하지 않는다**. 조명/임계값을 바꿔 감추지 않았다.

[원본 기술 검사](source-deformation-report.json)는 114개 사지/손/몸통+4개 목, 118개를 실제 실행해 통과했다. 최대 국소 edge 비율2.943930, 남녀 연결 성분1·non-manifold0·가중치 오류0, 의상 내부/방향 불일치0, 전체 검사 행240개다. 이는 단일 관절·표본 기술 QA이며 **표면의 육안 품질이나 옷끼리의 겹침을 보장하지 않는다**. 외형 미달을 기술 PASS로 덮지 않았다.

GLB 왕복/웹/실제 사람 연결은 A29에서 **미실행**이다. 현행 A27 원본과 여덟 가중치 웹 GLB는 그대로이며 PR #9 외형 P2·S2.4/2단계는 미완료다. 후속 후보에서 수축하지 않는 국소 정제와 의상 층 분리를 다시 검증한다.
