# BODYGUARD 코칭 구조 시안

2026-10-07 승인된 v4 디자인 방향을 실제 버튼과 대화상자로 검토하는 독립 HTML이다. **제품의 코칭 기능이나 최종 3D 아바타가 아니다.** `frontend/`의 공개 라우트·인증·판정·API·3D 에셋은 변경하지 않는다.

## 확인할 흐름

- 상반신 / 전신 / 자세히: 두 정적 이미지의 표시 범위를 함께 바꾼다.
- 동작 변경: 아바타 썸네일이 있는 배치용 후보를 고른다. 서로 다른 동작의 실제 시범은 아니다.
- 설정: 현재 창의 구도와 설명 표시를 변경한다. 새로고침하면 초기화한다.
- 전체 시범: 준비 / 수행 / 유지 / 복귀의 **안내 문구**를 수동 전환한다. 재생·타이머·수행 판정은 없다.
- 일시정지 / 종료: 조작 상태 예시와 종료 확인 / 취소 / 초기화가 작동한다.
- 홈 / 기록 / 계정: 이번 검토 범위 안내만 연다. 기존 제품 기능을 없애거나 로그인한 것으로 꾸미지 않는다.

현재 이미지는 정지 화면이다. 마우스를 가져다 대도 움직이지 않는다. 실제 카탈로그의 hover 동작 미리보기와 현재 단계·확인된 오류에 대응하는 시범은 검증된 모션 에셋이 준비된 뒤 별도로 연결해야 한다. 카메라·서버 요청·브라우저 저장소 쓰기·개인정보 입력은 없다.

## 로컬 미리보기

이 폴더에서 실행한다. 제품 서버나 운영 배포가 아니다.

```bash
python3 -m http.server 4189 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:4189`를 연다. 종료는 서버 터미널의 Ctrl+C다. 이 폴더에 개인정보·시크릿을 넣지 않는다. 밝은 모드와 노트북 창을 대상으로 하며, 좁은 창·확대 검사는 모바일 앱 출시 범위 추가가 아니다.

## 실제 Chrome 검증

설치된 Chrome과 기존 프런트엔드의 `@playwright/test`를 사용한다. 별도 의존성 설치는 필요하지 않다. 새롭고 비어 있는 증거 폴더만 허용한다.

```bash
design_proof_dir=$(mktemp -d /private/tmp/bodyguard-design-proof.XXXXXX)
node verify.mjs /absolute/path/to/bodyguard/frontend "$design_proof_dir"
```

하네스는 임시 localhost 서버를 직접 열고 종료한다. 구도·간격·주 조작부 위치·대화상자 키보드 순환·상태 초기화·이미지 실패/실패한 재시도/복구·대비·동작 감소·CSS 200% 확대를 검사한다. 모든 재로드를 합쳐 카메라·저장소 쓰기·외부/API 요청·JS 오류를 확인한다. CSS 확대는 실제 브라우저 메뉴의 200% 확대 시험으로 표시하지 않는다.

실측·카메라 추적·임상 판정·리깅·GLB·프레임 속도·계정/API·사용자/전문가 실용성은 이 하네스로 검증할 수 없다. [실행 결과와 남은 조건](../../docs/review/coaching-design-prototype/README.md)을 확인한다.
