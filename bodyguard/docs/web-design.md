# BODYGUARD — 웹 디자인 계약

CEO 결정2026-10-05 · 화이트·블루 · web-design-studio 적용

2026-10-07: CEO는 의료·신체 케어 도구 분위기의 v4 **방향**을 승인했다. 기존 HTML 전체는 확정 디자인이 아니다. [새 방향 결정](coaching-design-decision-20261007.md)과 [클릭 가능한 독립 코칭 시안](stories/coaching-design-prototype.md)을 기준으로 구조를 검토한 뒤 실제 제품 적용 범위를 합의한다. 아래 기존 토큰·접근성 경계를 재사용하며 이 문서의 과거 구현 기록을 전체 화면 승인으로 해석하지 않는다.

## 목적 / 화면 위계

노트북 웹에서 사용자가 지금 할 행동과 현재 상태를 정확히 알아보게 한다. 공개 소개는 시작하기, 계정은 해당 단계 제출, 시작은 스트레칭 경로, 탐색은 직접 선택/추천 목적, 기록은 기간 조회가 주 행동이다. 삭제는 별도 확인 안에서만 적색으로 강조한다.

전문적인 인상은 넓은 백색 여백, 정돈된 한글, 일관된 컨트롤, 읽기 쉬운 상태 안내로 만든다. 의료기관 배지·자격·효과·후기를 꾸며 넣지 않는다. 불완전한 기능의 준비 중 안내·카메라 미사용·안전 안내는 유지한다.

## 공통 토큰 / 재사용

원본은 frontend/src/index.css의 .website 범위다. 별도 개발 측정 시제품의 판정 색은 바꾸지 않는다.

| 역할 | 값 | 사용 |
|---|---|---|
| surface / surface-soft | #ffffff / #f1f6fc | 백색 웹 바탕 / 안내·표 헤더 |
| ink / muted | #142b49 / #52647a | 제목·본문 / 보조문구 |
| accent / accent-hover | #1e5aa8 / #164780 | 주 행동·링크·선택 / 포인터 반응 |
| on-accent | #ffffff | 파란·빨간 버튼 문구 |
| line / control-line | #d9e3ef / #7b8ba4 | 구조 구분 / 입력·보조 버튼 테두리 |
| focus | #1e5aa8 | 3px 초점선, 4px 간격 |
| danger / error | #943a32 / #9c2c23 | 되돌릴 수 없는 삭제 / 오류 |

공식 Google 버튼의 규정된 중립색·아이콘은 별도로 유지한다. 색으로만 상태를 구분하지 않고 aria-pressed·aria-current·문구·role과 연결한다.

## 글자·간격·레이아웃·움직임

- 기존 시스템 한글 글꼴과 React 컴포넌트 유지. 외부 폰트 요청 없음. 16px × 1.25 비율의12.8/16/20/25/31.25/39.0625/48.828125px 역할 토큰을 사용한다. 한 화면에서는 해당 역할 중4~6개를 사용하고 큰 제목은 비율 끝값 사이에서 창 너비에 맞춰 조절한다. 기본 줄간격1.65, 제목1.24~1.3, 일반 글자400·강조600·제목700이다. 공식 Google 버튼의14px/500은 브랜드 규칙 예외다.
- 4px 배수 여백 중심, 컨트롤 최소48px, 입력/버튼8px·안내12px 라운딩으로 통일한다. 주 행동의 위치와 명칭은 변경하지 않는다.
- 넓은 웹은 최대1200px·좌우48px, 좁은 창은24px와 단일 열. 헤더 메뉴 줄바꿈. 기록 표는 표 영역만 가로 스크롤. 좁은 창·확대 시험은 네이티브/모바일 앱 범위 추가가 아니다.
- 버튼 배경·테두리만120ms 반응, reduced-motion은 전환 없음. 자동 카메라·장식 애니메이션·새 3D 그림·유리 효과·스크롤 연출 없음.
- 밝은 모드를 명시한다. 다크 모드는 출시 범위에 추가하지 않는다.

## 상태 / 검증

폼 처리 중·오답·성공·연결 실패·재시도, 기록 로딩·빈 상태·상세·삭제 확인/취소·만료·불확실 응답을 유지한다. 키보드·텍스트/컨트롤 대비·좁은 창·실제 계산 스타일·스크린샷은 [Story](stories/stage4-medical-web-design.md)와 [증거](review/medical-web-design/README.md)에 기록한다. 자동 토큰 검사는 실제 화면 평가나 전문가 검토를 대신하지 않는다.
