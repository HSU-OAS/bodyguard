미완료 판정과 아바타를 제품의 완성된 코칭처럼 공개하지 않는다. 내부 판정 보류·개인정보 경계와 기존 품질 기준은 유지한다.

2026-10-05 D2-R 보완: PR #34/35로 순수 소유권 controller/세션 bridge는 main에 포함됐다. 실제 카메라/native 모델 포트 Story는 비공개 구현·합성446건·실제 가짜 카메라 초기화/해제를 확인했지만 **SDK Google 계측 외부 시도 P2/B-09 실패**로 미완료다. [실패와 CSP 시험 진단](review/coaching-browser-ports/README.md). 해결 조건은 CEO 중요 개인정보·통신 정책 승인 → 외부 SDK 계측 차단 구현 → 실제 native/API/로그인/기록 회귀·운영 환경 강제 경계 실제 확인이다. 시험 HTML만의 CSP 성공·개발 proxy 차단을 출시 개인정보 gate로 세지 않는다. 영상/좌표/외부 요청 payload 저장0, 공개 코칭0·기존 원본/실패 보존. 독립 frame 계약·서비스 작업은 계속하며 같은 아바타 부위 새 사이클은 시작하지 않는다.
