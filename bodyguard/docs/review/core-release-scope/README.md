# 승인된 첫 출시 범위 — 실제 문서 검증

2026-10-11 · 시작 main49955d7 · codex/first-release-core-scope

CEO의 두 답변 원문을 운영 규칙/ADR-0019에 반영했다. Q-32를 결정 목록으로 옮기고 PRD·설계·출시 계약의 네 부가 기능을 출시 후로 표시했다. 핵심 추천·직접 선택·고품질 남녀 두 아바타·계정·기록/집계·데이터 관리와 나머지 실제 완료 기준은 유지한다. 기존 알림 설정/코드·Draft51/실패·원본/증거 변경0이다.

실행한 `node bodyguard/docs/review/core-release-scope/check.mjs`의 첫 두 실행은 ADR의 '자세 이탈·착석 알림'과 검사 문자열 '자세 알림'의 불일치로 exit1이었다. 문서에 '자세 알림(이탈·착석)'으로 명시한 뒤 같은 검사는 exit0이다. 검사 수용 기준을 삭제하지 않았다. `git diff --check`는 exit0이다. 이 실패는 문서 검사 실패이며 제품 실패/임상 검증이 아니다.

작성자 diff 리뷰: 변경은 개발 문서와 읽기 전용 문서 하네스뿐이다. 실제 승인보다 넓은 제품 변경·알림 활성화·새 UI/DB/CI/운영/아바타 수정이 없으며 scoped 미해결 P1/P2는 없다. 독립 외부/다중 에이전트/전문가 리뷰0이다. 제품 빌드·SQL·브라우저·카메라·실제 참여자 시험은 이 문서 Story에서 재실행하지 않았고 완료로 주장하지 않는다.

기록 화면 연결은 다음 별도 Story다. 전체1~6·출시 후보판·기존 시작P2/실측/최종 아바타/권리/외부/HTTPS/운영 게이트는 미완료다. 최신 diff/exact HEAD/CLEAN/체크 재확인 후 조건부 merge commit하며 체크가 없으면 체크 없음, 브랜치 삭제0이다.
