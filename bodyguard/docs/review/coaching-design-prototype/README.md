# S4.D2 — 클릭 가능한 코칭 시안의 실제 검증

2026-10-07 · 기준 main `991ed2b33a1abc6158b3a177f8431a104c476ba0` · 독립 브랜치 `codex/coaching-design-prototype`

## 실제 작동하는 화면과 범위

한 공간의 좌우 아바타, 구도 전환, 이미지가 있는 동작 변경 창, 설정, 수동 단계 안내, 정지 상태, 종료 확인/취소/초기화가 실제 HTML에서 작동한다. 아바타는 승인 시안의 **정적 이미지**다. 계정·기록 메뉴는 범위 설명만 열고 신규 화면을 확정하지 않는다. 카메라·실시간 추적·판정·실제 시범 재생·기록 저장은 연결하지 않았다.

- 다음 실행 `2026-10-07T05:09:14.935Z`: 5개 통과 / 6개 실패, exit 1. 대화상자 Tab 순환 assertion 실패 후 열린 modal이 뒤 클릭 검사를 막았다. focus 검사도 실패했다. [실패 보고서](failed/report.json)를 보존한다. 종료 시도 전에 이미 끝났으며 kill은 `no such process`로 끝났다. 프로세스가 강제 종료된 것으로 기록하지 않는다.
- 보완: 대화상자 Tab/Shift+Tab 경계 순환, 검사 후 열린 창 정리, locator timeout 8초, case별 진행 출력, 재로드 전체를 합산하는 경계 관찰, 실패한 재시도와 다시 복구 검사, 이전 증거 덮어쓰기 금지.
- 키보드 보완 후 Chrome 실행 `2026-10-07T05:10:33.014Z`: 11개 모두 통과, exit 0. [당시 보고서와 소스 hash](reviewed/report.json)를 보존한다.
- 이어진 Biome 전체 검사에서 반환값이 있는 forEach 콜백·import 정렬 13개 오류, `!important` 3개 경고가 발견돼 exit 1이었다. 콜백을 명시 블록으로 바꾸고 import·CSS 우선순위를 보완했다. 최종 Biome check는 오류/경고 없이 통과했다.
- 최종 Chrome 실행 `2026-10-07T05:15:18.410Z`: **11개 모두 통과**, exit 0. [최종 실행 보고서와 소스 hash](gate/report.json), [모든 재로드의 카메라/저장/외부/API 요청 0](gate/boundary.json), [실제 계산 스타일·대비](gate/contrast.json). 이 결과만 현재 구현 소스의 UI 통과 근거로 사용한다.

검증은 기존 로컬 Playwright 의존성과 설치된 headless Chrome으로 수행했다. 실행 중 소스 파일을 변경하지 않았으며 마지막 보고서의 hash는 해당 실행 종료 시 수집했다. 자동 검증은 실제 신체·참여자 시험이 아니다.

## 작성자 재검토와 디자인 critique

`web-design-studio`의 8개 최종 critique 기준과 보안·성능·정확성·유지보수 관점으로 시안 파일을 검토했다. 별도 리뷰어/Figma/axe 실행으로 표시하지 않는다.

| 기준 | 실제 관찰 / 보완 |
| --- | --- |
| visual-audit / hierarchy | 좌우 인체가 주 요소다. 제목과 도구는 위쪽, 주 조작은 아래쪽이다. 아바타 개별 테두리/패널/중앙 구분선은 없다. 파란 주 버튼과 중립 보조 버튼을 구분했다. |
| spatial-rhythm | 모델 간 넓은 간격과 동일 배율을 유지했다. 전신 구도를 축소해 1440×900 창에서 발끝과 조작부를 함께 보이게 했다. 확대 시 설명을 비교 공간 아래로 옮긴다. |
| craft-signals | 8/12px 라운딩, 상태·aria 동기화, 실패/재시도/복구, 종료 확인/취소/복귀를 구현했다. 반복 재시도의 오래된 load listener를 정리했다. |
| color-systems | 기존 회백색·블루 토큰, 문자 대비 4.5 이상을 실제 계산으로 확인했다. 이미지의 적색/화살표는 예시 문구와 함께 보여준다. 의료기관 배지·진단 수치·가짜 신뢰 지표는 없다. |
| type-systems | 시스템 한글 글꼴, 25/20/16px 제목·본문 위계와 작은 보조문구를 사용했다. 14px 도구 표기는 이 독립 시안의 조밀한 도구용 예외이며 제품 전체의 글자 계약을 변경하지 않는다. |
| motion-design | 120ms 버튼 반응만 제공하고 동작 감소에서 전환을 없앤다. 정지 이미지를 영상·추적·검증된 시범처럼 애니메이션시키지 않는다. |
| quality-checklist | 키보드/오류/복구/창 너비/확대 기본 검사는 통과했다. 홈·계정·기록의 전체 상태 및 실제 코칭 UI는 아직 구조 승인/통합이 필요하다. 전체 웹 출시 품질 통과로 세지 않는다. |

초기 1024px 전체 페이지 캡처에서 화면 반복 같은 비정상 이미지가 관찰됐다. 수정 후 viewport 캡처와 두 paint 대기 방식으로 재실행한 화면에서는 재현되지 않았다. 원래 현상의 근본 원인이 확정된 것으로 주장하지 않는다. 이전 캡처는 [원본](initial/full-1024.png)에 보존한다.

보안: 외부 입력/개인정보 폼/서버 상태 변경이 없고 CSP `connect-src 'none'`을 둔다. 아이콘 HTML은 고정 상수뿐이다. 성능: 정적 PNG 한 파일을 재사용하며 매 프레임 추론/애니메이션은 없다. 실제 3D 성능을 검증한 것은 아니다. 정확성: 미실측 판정과 수행 성공을 생성하지 않는다. 유지보수: 제품 밖의 한 디렉터리, 설치된 테스트 런타임 재사용, 재실행 가능한 단독 하네스다. 현재 시안 범위의 미해결 P1/P2는 발견하지 않았지만 전체 제품의 기존 P2는 그대로다.

## 다음 승인/미실행 항목

CEO는 **디자인 방향만 승인**했다. 클릭 가능한 구조의 검토와 제품에 적용할 변경 범위는 아직 합의 전이다. 이를 기다리는 동안 디자인과 독립적인 기존 검증/개발은 계속한다. 이 PR에 실제 제품 화면 변경을 섞지 않는다.

실제 browser-menu zoom, 화면 읽기 도구/axe, 사람 사용성, 실제 카메라/임상 코칭, 남녀 3D 외형·Blender/GLB·변형·성능, 인증/API 통합, 운영 배포는 미실행이다. 2단계 이월·SDK 개인정보 P2·기존 Draft PR의 미충족 기준과 전체 1~6단계는 미완료다.
