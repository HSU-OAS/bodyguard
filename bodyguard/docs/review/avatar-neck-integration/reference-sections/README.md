# 전문 원본 내부 단면 — 읽기 전용 확인

2026-10-10 · [Story](../../../stories/avatar-neck-integration.md) · [실패한 경계 보간](../explicit-attempt/README.md) · 새 모델/공개 웹 변경0

앞선 경계 보간은 후두부 부피의 평탄화와 접힌 새 면으로 실패했다. 다음 표면 설계에 원래 부피를 제공할 수 있는지, 보존된 전문 원본의 머리–목 내부 단면을 독립 Blender5.1.1에서 읽기 전용으로 확인했다. 남녀 각각5개 높이, 총10개 단면 모두 하나의 닫힌 단순 loop였으며 native 실행은 exit0이었다. **단면의 연결 조건만 확인했으며 새 아바타 제작·외형 통과가 아니다.**

| 원래 형상의 관찰 | 남성 | 여성 |
|---|---|---|
| 단면마다 교차점 수 | 479~511 | 435~490 |
| 단면 뒤쪽의 최대 인접 면각 관찰 | 0.228~0.477° | 0.281~2.253° |
| 같은 메시 공간의 뒤쪽 깊이 Y 최대 관찰 | 20.368~48.955mm | 5.305~45.604mm |

이 값은 사용자 웹캠 좌표·사람의 의학적 정상 범위·코칭 각도 기준이 아닌 **전문 에셋의 기하 관찰**이다. 다섯 단면이 유효하다는 것이 전체 표면의 무결함·리깅 정확도를 보증하지 않는다. 원래 형상 내부의 깊이가 높이에 따라 변하므로 외곽 경계만 보간하지 않는 후속 설계의 참고가 된다. 새 표면에 이 흐름이 유지되는지는 아직 검증하지 않았다.

private BMesh 복사본에만 `bisect_plane`을 사용하고 원래 메시/장면으로 되쓰지 않았다. rest pose와 rig→body 좌표 변환을 확인하고 전후 입력 SHA256 ce8887d0421653774c05baf4ef3ed8d222250020cc770f63d398f6fc2c10343b가 같았다. 새 점/면 저작, 모델 저장·GLB·전체 변형·브라우저·실제 사람·임상 판정·live 사용자 Blender 장면 변경은 없다. 기존 원본/실패 증거는 그대로 보존한다.

다음 저작은 이 내부 단면과 접선·원래 형상의 흐름을 기준으로 표면을 설계하는 것이다. 보호점/raw skin/원래 외부 면·손/rest rig/PBR·6mm 제작 예산·닫힘/winding/tiny 기준을 완화하지 않는다. 거리나 단면만 통과하고 접힌 core 면을 채택하지 않는다. 남녀 전체 원본·독립 재열기·118 기술 pose·GLB/왕복·실제 외형/Chrome 검증은 후속 필수이며 아직 미실행이다. 외형 P2·D2·전체1~6 미완료, Draft #108 병합 보류다.

```bash
node bodyguard/assets/blender/integration-neck/archive_reference_sections.mjs --check
```

`manifest.json`은 실제 실행 소스/로그/관찰 보고서3개와 현재 검사기/보존기2개의 압축 전후 SHA를 검증한다. `--check`는 바이트 보존 검사이며 Blender 재실행이나 제작 통과가 아니다. 이전 explicit-attempt42개 manifest를 변경하지 않고 별도 subtree에 보존한다.

이미 생성된 archive의 재생성 음성 시험은 실제 exit1로 거부됐고 manifest ea616b2fcd76b3cfbb671d809bee12540575548f5ea28643810b9268afc5ae34는 전후 같았다. 이후5개 바이트 확인도 통과했다. 다른 필수 검증을 대신하지 않는다.
