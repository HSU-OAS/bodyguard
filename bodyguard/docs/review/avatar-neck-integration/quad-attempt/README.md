# 목·어깨 국소 quad 시도 — 실패·미채택

2026-10-10 · S2.A1 · Draft PR #108 유지 · 공개 웹 변경0

Blender5.1.1에서 전문 원본 ce8887d의 뒤쪽 면만 native Grid Fill로 재구성했다. 새 원본은 저장하지 않았고 기존 원본·후보·GLB·검증 증거는 보존했다. 원본을 덮어쓰거나 전체 인체를 primitive로 생성하지 않았다.

## 실제 관찰

- 읽기 전용 경계 검사: 앞면과 손을 선택에서 제외했다. 남성은 단일685점 경계, 여성은717점/719edge의 접촉점이 있었다. 여성의 실제 제작은 남성 실패로 미실행이다.
- 초기 실행은 BMesh 참조 유효성/경계 유지/명시적 Grid Fill span/자체 가중치 전송 검사에서 저장 전 실패했다. 실패별 실제 소스·JSON·로그를 보존한다.
- 새 표면의 fairing은 원본에서6mm 넘게 벗어나 실패했다. 전신 대상 Shrinkwrap도 국소 참조 거리 검사를 실패했다. 허용치를 높이지 않았다. 이후 기존 뒤쪽 선택 면만 참조하는 native Shrinkwrap으로 표면을 맞췄다. **맞추기 전 최대28.1mm와 맞춘 후 최대2.45µm는 서로 다른 제작 상태**이며 이전 실패를 통과로 고치지 않는다. 외형 개선을 입증하는 수치가 아니다.
- Native Data Transfer는 보호점에0인 그룹 항목을 추가했다. 진단 첫 사례의 실제 값은 동일했다. 최종 실행은 모든 보호점의 0이 아닌 값이 exact인 것을 먼저 강제한 뒤, 기존에 없던 literal0 항목22401개만 제거했다. 값 변경이나 원래0 항목 제거는 허용하지 않았고 최종 raw skin 배열 exact 검사도 유지했다.
- 마지막 남성 실행: 얼굴/앞면·손·기존 외부 좌표/다각형/raw skin·163 rest bone/pose/world/PBR 보호를 확인했다. 닫힘0·winding0이지만 **면적1e-10m² 미만의 작은 면이2→610개로 늘어 exit1**이었다. 보호 검사가 통과했어도 새 표면의 품질 조건은 실패다. 출력 원본 저장0·아바타 채택0이다.

## 검증 경계와 다음 조건

이번 새 후보의 독립 재열기·GLB·118 기술 pose·왕복·동일 조명 렌더·Chrome는 **미실행**이다. 이전 후보의 성공이나 현재 archive byte/hash 검사를 이번 제작 성공으로 복사하지 않는다. 실제 사람·정확도·올바른 시범·노트북 품질·전문가/외형 승인이 아니다.

단일 복잡한 경계를 한 Grid Fill로 채우는 방식은 채택하지 않고 이 실행 구간을 종료한다. 다음 전문 제작에서는 후두부·목·승모근을 구분한 구간별 edge 연결과 경계 간격을 설계해야 한다. 이번 작은 면의 증가가 해당 연결 설계 문제라는 것은 작업 가설이며, 실제 형상·변형 검사로 확인할 필요가 있다. 작은 면 증가 guard를 낮추거나 무조건 dissolve/smooth 강도를 반복하지 않는다.

`manifest.json`은 보존한 실패 소스/보고서/로그의 압축 전후 SHA와 실제 native exit1을 기록한다. 원본/GLB/전체 변형/브라우저·실제 외형·실측·검증된 시범 및 전체1~6의 완료 기준과 별도 승인 경계를 유지한다. 미해결 P2 때문에 Draft #108은 병합하지 않는다.

## 로컬 보존 검수

Ruff·format 검사는 exit0, Biome는 exit0이며 선택적 문구 연결 style info1이 남았다. 이전137개·collapse37개·새36개 증거의 압축 전후 bytes/SHA, 원래 두 입력 SHA, 마지막 실행 소스와 현재 저작기의 exact 동일성, 관련 문서의269개 상대 링크를 실제 확인했다. archive 재실행은 기존 출력 거부 exit1이고 모든 증거 SHA는 그대로였다. 이는 파일 보존 검사이지 Blender/Chrome 재실행이 아니다. 이번 제품 빌드·전체 UI/API/SQL·실제 사람/운영 검증은 미실행이다. 검수 로그는 `post-verification/manifest.json`에 별도 보존한다.
