# 설치 Blender의 실제 제한 변형 API 확인

Blender5.1.1/build b70da489d7f4의 [실제 probe](probe.json)와 [terminal](native-exit.json)은 exit0·signal/spawn error=null이다. Professional 아바타/사용자 장면 없이 비인체81점/64면 격자에 native RNA·bind·평가 메시를 실행했다. 기본 iterations1은 유지했다. 실행 helper/runner gzip·로그와 실제 종료를 보존했다.

동일33개 anchor의 양수 그룹 값1/0.25는 native 결과가 exact 같았다. 그룹 값의 크기를 강도/감쇠로 사용하면 안 된다. 그러나 중심 target 오차2.494mm·경계 최대0.137mm로 실제 native anchor는 exact 고정이 아니었다. 이 수치는 격자 도구 동작 관찰이지 신체/자세 정상 범위나 아바타 허용치가 아니다. 신규 전문 표면 보완은 solver 오차를 기록하고 core/외부 좌표를 독립적으로 강제·검사해야 한다.

첫 [초기화 SIGSEGV](../native-deform-probe/README.md)는 별도 보존했고 같은 helper를 수정하지 않았다. factory startup의 기존 object 이름/type/world는 처리 전후 exact였고 생성 fixture만 제거했다. 사람 영상/좌표·professional 조형/원본 저장·렌더/GLB/전체변형/Chrome·외형 승인은 모두0이다. API 사용 가능성을 아바타 제작/외형·D2/전체1~6 통과로 세지 않는다. [새 저작 실행 보류](../lateral-native-deform-deferred.json)와 기존 Draft/외형P2·최소 문구/별도 승인 기준을 유지한다.
