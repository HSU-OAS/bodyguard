# S4.D3 — 독립 코칭 시안의 텍스트 최소화

제품 밖의 정적 HTML만 보완했다. 두 아바타 배치와 전신/상반신/확대·동작 후보·설정·단계 안내·종료 흐름은 유지하고 보조 설명을 기본 닫힌 “설명 보기”로 옮겼다. [실제 기본 화면](final/full-1440.png), [설명 펼치기](final/explanation-open.png), [상반신](final/upper-1440.png), [1024px 노트북 창](final/full-1024.png).

최종 아바타/검증된 동작이 아닌 기존 배치 이미지다. 이미지의 적색·화살표도 실제 교정이 아님을 계속 표시한다. 제품 React/API·카메라·인증/기록·판정·민감도/개인정보·운영은 바뀌지 않았다. 구조와 제품 적용 범위는 CEO 검토 전이다.

## 실제 검증과 실패 보존

- 시안 worktree의 최초 명령은 Playwright 미설치로 ERR_MODULE_NOT_FOUND/exit1, 브라우저 시험 전 실패였다. 동일 package/lock의 기존 대시보드 worktree 런타임을 명시 사용했고 새 설치/버전 변경은 없다.
- 기존11건 원본 UI 회귀: [11통과](baseline-runnable/report.json). 당시 소스 hash는 종료 시점 수집이며 실행 HEAD/시작 hash를 소급 기입하지 않는다.
- 새 설명 접기 기준을 원본 화면에 실행: [11통과/1실패](red/report.json). 설명 접기 요소가 없어서 실패했다. 보완 후 [첫12건 통과](green/report.json). 이 두 실행은 변경 중 파일의 시작/종료5개 SHA가 같고 당시 Git HEAD는 수집하지 않았다.
- 커밋 `eebd9f19061972ed97321ac0f854c5f1f00e7e34`로 [최종 실제 Chrome12건 통과](final/report.json). 실행 HEAD·원본5개 SHA를 서버/브라우저 시작 전과 종료 후 대조했으며 게시 시 Git blob/작업 파일과도 같았다. [수치·원본 로그 SHA·화면 SHA](summary.json).
- Enter/Space/마우스로 설명 열기/닫기·초점 유지, 종료 취소 상태 보존/확인 초기화, 기존 모달 키보드·이미지 실패/실패 재시도/복구·전신 발끝·구도 동기화·1440/1280/1024/820px·CSS200% 확대가 통과했다. [계산 스타일/문자 대비](final/contrast.json): 새 설명 버튼6.635:1, 3px 초점/동작 감소0s. [모든 재로드의 경계](final/boundary.json): 카메라/저장/외부/API 요청·JS오류0.
- 초기 보이는 DOM의 공백 제외 문자291→182. 이미지 안 글자나 전체 서비스 문구 길이는 포함하지 않는다. 텍스트 최소화가 안전 문구 제거를 의미하지 않는다.
- node --check 두 JS, 기존 Biome CSS/JS/하네스3파일, git diff --check 통과. 제품 코드 변경이 없어 제품 전체 회귀를 이 Story에서 다시 실행하지 않았다. 앞선 대시보드 통합 검증은 별도 증거다.
- 증거 게시기 첫 실행은 기존 PNG Git blob을 기본1MiB buffer로 읽다가 ENOBUFS/exit1로 실패했다. 중간에 복사된 보고서와 실패 메모를 보존하고16MiB 읽기 상한으로 보완했다. 같은 byte만 허용하는 게시기로 최종 원본 대조/불변 게시를 확인했다. UI 소스/검사 기준을 낮춘 보완이 아니다.

## 작성자 코드 검토·디자인 critique

`web-design-studio`와 지정8개 기준을 적용해 실제 최종 PNG와 변경 diff를 검토했다. 별도 에이전트/전문가/Figma/axe 검토로 표시하지 않는다.

| 기준 | 실제 관찰 |
| --- | --- |
| visual-audit | 두 인체가 주 대상이고 상시 보조 설명이 줄었다. 개별 아바타 상자·장식 배경을 추가하지 않았다. |
| hierarchy-principles | 제목·역할·주 조작은 남기고 중복 eyebrow/긴 상태 문구를 줄였다. 자세히 읽기는 선택 행동이다. |
| spatial-rhythm | 발끝·넓은 좌우 간격·기존 조작 위치가 유지된다. 펼친 설명도 모델 영역으로 넘치지 않는다. |
| craft-signals | native disclosure의 기본 닫힘/키보드/초점/종료 초기화를 실제 검증했다. 기존8/12px 라운딩·44px 조작을 유지한다. |
| color-systems | 같은 화이트·남색·블루 토큰. 새 설명 문자의 계산 대비6.635:1이며 색만으로 상태를 구분하지 않는다. |
| type-systems | 기존 한글 시스템 글꼴·제목/본문/보조 위계 유지. 문장을 줄였고 읽기 위해 강제 줄바꿈/새 폰트를 넣지 않았다. |
| motion-design | 설명은 native 열기/닫기이며 새 장식 애니메이션이 없다. 정지 이미지를 시범 모션처럼 움직이지 않는다. |
| quality-checklist | 기존11건과 새 설명 경계 통과. 좁은 창/CSS확대/오류·복구·키보드 통과와 미실행 범위를 분리한다. |

정확성: aria/status·보기·설명·종료 상태가 동기화된다. 보안: 외부 입력과 서버 변경이 없고 기존 CSP/경계 유지. 성능: 새 의존성·지속 루프·이미지 변경 없음. 유지보수: 제품 밖 native HTML과 기존 단독 하네스만 사용한다. scoped 변경에서 미해결 P1/P2는 발견하지 않았다. 전체 제품의 기존 P2는 그대로다.
