# Google 로그인 표식

`google-icon.png`는 공식 [사전 승인 브랜드 에셋](https://developers.google.com/static/identity/images/signin-assets.zip)의 `Android + Web/PNG @4x/Light/Theme=Light, Show text=No, Shape=Square, Platform=Android+Web@4x.png` 원본을 수정 없이 복사한 160×160 PNG다. CSS로 바깥 버튼 테두리만 가리고 가운데 20×20 **최신 gradient G**를 로그인 버튼 안에 표시한다. G의 색·형상·종횡비를 바꾸거나 자체 로고를 만들지 않았다. 별도 로고/앱 마스코트로 쓰지 않는다.

출처: [Google 로그인 브랜드 가이드](https://developers.google.com/identity/branding-guidelines), 2026-10-01 확인. Google 상표 권리는 Google에 있으며 사용은 해당 브랜드 가이드에 따른다. 공식 HTML 구성기의 Roboto/Arial fallback·light 버튼 색·한국어 계속하기 문구를 따른다. SDK script·외부 폰트·원격 이미지 요청은 추가하지 않는다. 실제 서비스 연결 때 공급자 검토는 별도다.
