# 신체·얼굴·손 CPU 우선 추론 후보

2026-11-10 · 개발 후보 · 출시 미승인

GPU 우선 모델 세 개를 직렬로 실행하는 첫 프레임이 응답 기한을 넘긴 별도 계측과, CPU 우선 시 가상 카메라로 짧게 정상 처리된 시험을 바탕으로 신체·얼굴·손 모델을 CPU 우선으로 생성한다. CPU 생성이 실패한 경우에만 같은 모델·옵션으로 GPU를 다시 시도하고, 취소한 경우 재시도하지 않는다. 모델·모든 기능·기한·판정 기준은 유지한다. 초기화 실패·취소·정리 경로는 Worker 단위 검사의 합성 SDK로 확인한다.

화면 저장 기능을 제거한 [시험 도구](safe-runner.mjs)에서 계측 주입 없는 실제 후보 Worker/SDK와 [여성](female-no-image.json)·[남성](male-no-image.json) 아바타를 사용해 공개 녹화 스쿼트 영상을 Chrome 가상 카메라로 각각 실행했다. 각각 45프레임을 처리하고 두 아바타·가상 카메라·Worker를 정리했다. 외부 요청과 쓰기는 0이며 원본 소스 해시가 시험 전후 일치한다. 첫 시험 도구는 아바타 렌더 이미지를 저장했기 때문에 화면 저장을 제거한 도구로 재실행했다. 첫 시험 결과와 출력은 로컬에 보존한다.

`avatarCoveredFrames`는 기술적 관절 연결 범위이지 사람과의 일치도나 자연스러움이 아니다. 각 실행에서 얼굴 방향은 검출되지 않았다. 이 영상으로 얼굴·손·신체의 실제 사람 정확도나 오판정률을 검증했다고 주장할 수 없다.

변경 코드의 Worker 관련 3파일·69개 검사([로그](targeted.log.gz))와 전체 130파일·2,185개 검사([로그](full-vitest.log.gz)), 변경 파일 Biome([로그](biome.log.gz)), 타입 검사([로그](tsc.log.gz)), Vite 빌드([로그](build.log.gz)), 공개 번들 guard([로그](guard.log.gz))를 실행해 통과했다. guard는 이 후보가 공개 번들에 포함되지 않았는지 확인한다.

이것은 한 기기·한 공개 영상의 단기 시험이다. 다른 노트북·부하·실제 웹캠에서의 시작, 장시간 성능과 얼굴·손 추적 정확도, 이전 간헐 오류의 완전한 해결은 미검증이다. 실제 사용자 검증 및 전체 게이트 전까지 공개 코칭에 사용하거나 PR을 병합하지 않는다.
