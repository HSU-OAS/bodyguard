# 날카로운 부위 보호 표면 시험 — 중단

2026-11-09 · 결과 미확인 · [이전 실패](../laplacian-20261109-intermediate/README.md)

같은 Blender 원본에서 이면각 40°를 넘는 기존 부위의 양면과 인접 정점을 고정하고 나머지 뒤 목·어깨를 보완하는 시험을 시작했다. 기존 선택 영역·최대 이면각·앞면/뼈대/가중치 보호 조건을 낮추지 않도록 한 [시험 스크립트](trial.py)다. 이 각도는 메시 보존을 위한 내부 기술 조건이며 사용자 자세 기준이 아니다.

한 번도 남녀 검사 결과를 출력하지 못한 상태에서 높은 시스템 부하가 계속되어 작업자가 이 시험의 별도 Blender 프로세스만 종료했다(exit 143). [중단 로그](interrupted.log.gz)를 보존한다. 결과 보고서와 후보 Blender 파일은 생성되지 않아 이 방법의 성공·실패나 외형 개선을 판정할 수 없다. 입력 원본 SHA-256은 `71c369c96667549d00a4e77ff5d0b301ce307d806d5f3b42e739f48b4b7a8a2d`로 실행 후에도 동일했다. 렌더·GLB·변형·브라우저 검사는 실행하지 않았다.
