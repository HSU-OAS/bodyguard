# 목·어깨 국소 곡률 시험 — 미채택

2026-11-06 · [이전 후보와 기준](../README.md) · **외형 P2 미해결**

기존 PR #150의 `71c369c9…` Blender 원본을 별도 사본으로 열고, 앞면과 바깥의 정점을 고정한 상태에서 뒤 목·어깨의 국소 가중 Laplacian 보완을 시험했다. 기존 토폴로지, 뼈대, skin, 정점 속성을 검증했다. `trial2`의 최대 변위는 남성 0.215mm/여성 0.165mm, 접힘은 0이었다. 선택 영역 최대 이면각은 남성 36.795°→36.776°, 여성 45.025°→45.025°였다. [실제 수치](proof/report2.json). 이면각은 기술 지표이며 독립적인 미관 합격 기준이 아니다.

기존과 같은 카메라·재질·조명·16 samples의 실제 Blender 렌더를 확인했다. [여성 뒤](preview/female-back.png) · [여성 앞](preview/female-front.png) · [남성 뒤](preview/male-back.png) · [남성 앞](preview/male-front.png). 여성 뒤쪽 표면의 요철이 여전히 보이므로 개선을 충분히 입증하지 못해 **후보를 채택하지 않았다**. 제품 반영·외형 승인 없음. 별도 121개 관절 변형 검사·GLB 왕복·브라우저 검증은 이 실패 후보에 수행하지 않았다. 해당 검증을 통과했다고 표시하지 않는다.

첫 실행은 보조 스크립트 누락으로 시작 전 실패했다([원문](proof/run.log.gz)). 보조 스크립트를 가져온 재실행은 modifier가 보호 영역까지 이동시켜 실패했다([원문](proof/retry.log.gz), [결과](proof/report.json)). 새 시험은 보호 외부 좌표를 정확히 복원하고 접힘·변위 제한을 유지했다. 후보 `.blend`, 실행 스크립트와 모든 실패 로그는 별도 경로에 남긴다. 원본을 덮어쓰지 않았다. 시각 검토에서 미채택한 후보이므로 내보내기/브라우저나 실제 운동 검증의 대체로 사용할 수 없다.
