# 여성 목·어깨 고곡률 부위 시험 — 미채택

2026-11-09. 기존 원본과 후보를 보존하고 별도 Blender 5.1.1 사본에서 시험했다. 표면의 얼굴 전면을 제외한 기존 영역에서 인접 면 각도가 10~40도인 부위와 그 주변 12mm에 가중치를 주고, 40도 초과 4개 예리한 모서리와 인접점은 고정했다. Blender의 Laplacian Smooth 0.15/6회로 [새 후보](models/candidate-unapproved.blend)를 만들었다. [작업 스크립트](trial.py)와 [기술 결과](report.json), [실행 로그](run.log.gz)를 보존한다. 이 값은 의료 기준이 아니라 조형 실험 설정이다.

선택 영역 밖·앞면, 원본의 토폴로지, 리깅과 피부 가중치는 변경되지 않았고 최대 정점 변위는 약 0.162mm였다. 해당 영역에서 90도 초과 접힘, 비매니폴드와 뒤집힌 면은 새로 발생하지 않았다. 이 기술 조건 통과만으로 외형이 승인되는 것은 아니다.

기준 원본과 두 기존 후보, 새 후보에서 **원본에 고정한 동일 정점 10,299개와 이면각 25,610개**를 비교했다([계산 스크립트](curvature.py), [선택 정점](selected.json), [기준·기존 후보](matched.log.gz), [새 후보](focused.log.gz)). 원본에서 10도 초과 모서리 280개, 새 후보 279개이고 95백분위 각도는 양쪽 모두 약 5.06도였다. 이 값만으로 외형 품질을 판정할 수는 없다. 동일 조명과 설정의 실제 Blender [뒷면](female-back.png)과 [앞면](female-front.png)을 확인했을 때 목 뒤와 어깨의 울퉁불퉁한 음영이 여전히 보여 **시각 개선이 충분하지 않다**. 후보는 채택하지 않는다.

최초 곡률 계산은 각 파일에서 영역을 다시 선택해 정점 수가 달랐기 때문에 직접 비교할 수 없었다([당시 결과](unmatched.log.gz)). 이후 원본 영역의 인덱스를 고정해 다시 계산했다. 처음 작성한 계측 스크립트의 비효율을 발견해 이 작업에서 시작한 Blender만 중단하고 고쳤으며, 중단 시 계산 결과는 생성되지 않았다. 기존 원본 SHA-256은 `71c369c96667549d00a4e77ff5d0b301ce307d806d5f3b42e739f48b4b7a8a2d`로 유지됐다.

새 후보는 시각 검토를 통과하지 못했으므로 GLB 내보내기, 애니메이션 변형 및 브라우저 검사를 실행하지 않았다. 기존에 별도로 검증한 후보의 결과를 이 후보의 검증으로 간주하지 않는다. 다음에는 렌더 조명·법선과 표면 자체를 분리해 문제 위치를 확인하고, 전문가 수준의 국소 조형 또는 대체 에셋 접근을 검토해야 한다.
