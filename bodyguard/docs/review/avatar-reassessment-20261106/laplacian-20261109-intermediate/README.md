# 목·어깨 중간 강도 보완 시험 — 미채택

2026-11-09 · Blender 5.1.1 · [이전 시험](../laplacian-20261109/README.md) · 최종 외형 및 성능 P2 미해결

기존 원본 SHA-256 `71c369c96667549d00a4e77ff5d0b301ce307d806d5f3b42e739f48b4b7a8a2d`을 별도 프로세스에서 열고 기존 trial과 같은 영역·전면 보호·최대 2mm 변위·접힘 및 이면각 기준을 유지했다. Laplacian 강도만 0.3/8회에서 0.2/8회로 변경했다. [스크립트](trial.py) · [결과](report.json).

남성은 최대 변위 약 1.065mm, 선택 영역 최대 이면각 36.794728°→36.763596°로 검사한 기술 기준을 통과했다. 여성은 최대 변위 약 0.807mm, 기존 최대 이면각 45.025392°→45.031591°로 증가해 기존 기준을 통과하지 못했다. 두 경우 원본 외 영역·앞면·토폴로지·가중치·뼈대 보호 검사는 유지됐고 접힘은 0이었다. 이면각은 외형이나 안전성을 단독으로 평가하는 기준이 아니다.

여성 기준 실패로 후보 파일은 저장하거나 채택하지 않았고, 원본 해시는 변경되지 않았다. 렌더·GLB·변형·브라우저 검사는 실행하지 못했다. 이를 외형 개선이나 아바타 완성으로 보지 않는다. 최초 실행은 보조 파일 누락으로 시험 시작 전 실패했으며, Blender 기본 exit code가 0이어서 성공으로 간주하지 않았다([로그](initial.log.gz)). 보조 파일을 복사하고 `--python-exit-code 1`을 지정한 [재실행](retry.log.gz)에서 위 기준 실패를 확인했다. 보조 파일은 이전 증거의 `executed/`에 있다.
