# 여성 목·어깨 깊이 방향 보완 — 실패 및 미채택

2026-11-09 · Blender 5.1.1 · [보존 중인 기존 후보](../protected-female-20261109/README.md)

기존 원본의 앞면·외부·날카로운 모서리 및 주변 보호 조건을 유지하고, Blender Smooth modifier를 깊이축에만 적용해 정면 윤곽과 높이를 보존하면서 뒷면을 다듬는 대안을 시험했다([실행 스크립트](trial.py)).

[보고서](report.json)에서 여성 최대 변위는 약 3.878mm였고, 선택 영역 최대 이면각은 약 45.025°에서 123.512°로 커져 접힘 기준에 실패했다. 사전에 정한 2mm 변위 한도 역시 넘었다. 검사 실행은 접힘 검증에서 먼저 중단됐고 [원문](run.log.gz)을 보존한다. 후보 파일은 저장되지 않았으며 원본 해시는 변경되지 않았다. 외형 렌더·GLB·관절 변형·브라우저 검사는 진행하지 않았고 이 방법을 채택하지 않았다.
