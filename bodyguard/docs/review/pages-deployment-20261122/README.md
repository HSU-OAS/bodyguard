# 2026-11-22 공개 검수본 배포 및 핵심 흐름 검증

사용자가 승인한 팔 좌우 수정 [PR #196](https://github.com/HSU-OAS/bodyguard/pull/196)의 병합 커밋 `32aba49e`를 [GitHub Pages 배포 44938152472](https://github.com/HSU-OAS/bodyguard/actions/runs/44938152472)로 공개했다. 빌드와 배포는 성공했고 [공개 HTTPS 주소](https://hsu-oas.github.io/bodyguard/)에서 확인했다.

## 공개 주소에서 확인한 동작

- 남녀 아바타의 전신·상반신·자세히 보기에서 양팔을 따로 움직이는 12개 조합을 확인했다. Chrome 가상 카메라와 합성 관절을 사용했으며, 올린 팔과 그쪽 어깨가 거울형 카메라 미리보기와 같은 쪽에서 움직였다.
- 실제 MediaPipe Worker와 WebGL을 유지하고 가상 카메라에 렌더된 아바타 영상을 공급했다. 남성 기본 모드에서 5초 동안 20개 표본에 몸 추종이 있었고, 여성 손가락 상세 모드를 켠 시험에서는 20개 중 19개에 몸 추종이 있었다. 두 시험 모두 종료 후 카메라 트랙이 닫혔다. 이 영상으로 머리나 손가락 정확도를 입증하지 못했다.

## 남은 품질 기준

여성 아바타의 뒷목 가중치 보정, 체적 보존 및 포즈 보정을 Blender에서 비교했다. 목을 기울일 때 접합부의 집힘이 남아 보정안을 제품에 채택하지 않았다. 실제 사용자와 노트북의 추종·손과 얼굴 정확도·동작별 오판정, 최종 외형, 공급자 연결과 전체 제품 HTTPS 운영 검증은 별도로 남아 있다. BODYGUARD의 자세 피드백은 관찰 가능한 움직임에 대한 코칭 범위로 유지한다.
