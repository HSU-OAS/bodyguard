## 작동 흐름

촬영된 VideoFrame의 실제 크기를 생성 시점에 고정한다. 원래 세대/순번/시각과 함께 같은 결과의 이미지 기하·optional presence를 보존해 코칭 evaluator에 전달한다. CSS 크기/아바타 표시 반전이나 추론 후 video 크기를 사용하지 않는다. 관찰 helper는 이 기하로 이미지 평면의 목·어깨 상대값을 계산하며, 누락/가림/복수/만료에서 이전 값을 재사용하지 않는다.

기존 소유 source의 기하 생략은 호환하지만 목 관찰은 unavailable이다. 잘못된 기하나 optional presence의 비수치 값은 고정 실패로 처리하고 정리한다. 낮거나 비정상 수치 presence를 버려서 신뢰도를 높이지 않는다. classifier·임상 임계값·추천/성공 판정은 추가하지 않았다.
