# 어깨 코칭과 손 CPU 추론 후보 결합 시험

2026-11-09 · 개발 검수 · 제품 공개·실제 사람 정확도 검증 아님

기존 Draft #163에 [손 CPU 우선 후보 PR #189](https://github.com/HSU-OAS/bodyguard/pull/189)의 두 Worker 소스 변경만 **임시로 적용**해 시험했다. 후보는 어느 쪽에도 병합되지 않았고, 임시 패치는 시험 후 되돌렸다. 개인정보·실제 사람 영상 없이 진행했다.

- [실제 SDK / 빈 가짜 카메라 시험](native.json)은 어깨 코칭 화면에서 시작, 일시정지, 새 세대로 재개, 중단을 수행했다. 두 세대의 Worker clean ACK와 카메라·아바타 자원 해제가 확인됐다. 빈 카메라는 동작을 성공시키지 않았다. [로그](native.log.gz). 하나의 시험으로 간헐 종료 P2 해결을 증명하지 않는다.
- [합성 입력 화면 시험](ui-corrected.json)은 남녀 GLB와 생성된 관절 입력으로 어깨 상승과 오류 색, 빈 입력의 성공 방지, 일시정지·재개, 완료 결과, 통증 중단과 권한 취소·401을 확인했다. 이 시험은 카메라와 Worker를 합성 소스로 대체하므로 CPU 후보의 실제 추론이나 실제 사람의 정확도를 검증하지 않는다. [남성 화면](male-synthetic.png) · [여성 화면](female-synthetic.png) · [로그](ui-corrected.log.gz).
- [첫 화면 시험](ui-first-failed.json)은 3개 흐름 이후 로그인 화면의 옛 제목을 기다리다 실패했다. 당시 [runner](ui-first-runner.mjs)와 [로그](ui-first-failed.log.gz)를 보존한다. 현재 실제 제목 `로그인`으로 테스트의 기대 문구만 고치고 위 4개 흐름을 다시 통과했다. 그 사이 한 번은 잘못된 작업 디렉터리에서 실행해 테스트 시작 전에 실패했다([로그](ui-wrong-cwd.log.gz)).

실제 사람의 자세·손 정확도, 시범과 판정의 전문 검토, 실제 노트북별 성능, 아바타 최종 표면과 간헐 Worker 종료 P2는 여전히 미완료다. 기존 출시 적격 동작은 0개다.
