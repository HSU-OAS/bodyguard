# 아바타 움직임 회귀 확인

2026-11-10 현재 후보에서 방향·자세·손·머리 회전과 기준 시범 재생의 기존 단위 시험 5파일 110개를 실행해 통과했다([집계·코드 SHA](summary.json), [실행 로그](vitest.log.gz)). 이 시험은 합성 입력과 수학적 회전, 프레임 간 보간, 가려짐·종료 시 처리를 검사한다. 실제 사람과 아바타의 일치도나 외형·관절 변형이 자연스러운지를 평가하지 못한다.

코드를 확인하면 사지의 첫 유효 방향은 기존 위치에서 보간하지 않고 곧바로 반영하며, 이후 프레임부터 반감기 기반으로 회전한다. 이 동작은 첫 추적에서 급격한 모습으로 보일 수 있다. 실제 화면과 신체 움직임을 비교하지 않은 채 다른 보간값이나 지연을 정답으로 확정하지 않고, 첫 추적·가림 후 재인식·빠른 움직임을 실제 사람과 함께 검토할 항목으로 유지한다.
