# 손 CPU 후보의 첫 추론 단계 분리

2026-11-09 · 실제 Chrome/SDK, 빈 가짜 카메라 · 원시 영상·좌표 미저장

[앞선 반복](../handcpu-repeat-20261109/README.md)의 첫 추론·종료 시간 초과를 조사했다. 손 CPU 우선 후보를 임시 결합하고 테스트 중에만 Worker의 신체·얼굴·손 추론 및 자원 정리 진입/종료에 고정 문자열을 넣었다. 호출 결과나 제한 시간은 바꾸지 않았다. [runner](runner.mjs) · [결과](stage-a.json) · [원문](stage-a.log.gz).

한 실행에서 세 모델 준비 후 첫 프레임의 `detect-start-body`만 기록됐고 신체 추론 완료·얼굴·손 시작은 Worker가 종료될 때까지 기록되지 않았다. 상위 화면은 기존 응답 기한과 정리 확인 기한을 넘겨 `cleanup-error`를 반환했다. 카메라는 정리됐다. **이 실행에서 지연은 신체 모델 호출 안쪽 또는 그 호출을 수행하는 Worker의 진행 중에 발생했다.** 내부 원인, GPU 드라이버 결함 여부, 과부하의 인과, 영구적인 교착 여부는 단정하지 않는다. 진단 변환을 한 한 번의 빈 가짜 카메라 시험이며 실제 사람의 정확도와는 다르다. 이후 신체 CPU 실행을 별도 비교한다.
