# 개발 방향 결정 — 2026-09-26

개발 폴더를 만들기 전에 받은 질문과 답을 그대로 옮겼다. 원문 29~37의 원본이다.

---

## 배경

"지금까지 나온 이야기로 MotionLayer 같은 문서 세트를 만들 수 있는가"를 확인해 보고했다.
무엇을 만드는지(문제·사용자·기능·범위)는 충분했다. 반면 어떻게 판정하는지와 어떻게 만드는지는 거의 논의된 적이 없었다.

사용자 답:
> 아니 어짜피 저기 내는건 명목상 그렇게 내는거고, 우리는 개발일정을 우리가 알아서 할거야.
> 그래서 어떤게 더 필요한지 정해야할것 이런거, 일단 앱에 방향성은 확실하게 나왔으니깐 가능할것 같아서

그래서 일정과 과목 항목은 빼고 개발에 필요한 것만 질문했다.

## 1차 질문

### 작업 중 화면
질문: 코딩·과제를 하는 동안 Bodyguard는 어떻게 떠 있을까요? 브라우저는 뒤로 간 탭의 화면 갱신을 멈추기 때문에 이걸 먼저 정해야 해요.

| 선택지 | 설명 |
|---|---|
| 작은 PiP 창 (추천) | 항상 위에 뜨는 작은 창에 아바타와 자세 상태를 띄운다. 크롬·엣지 기능이라 실제로 계속 측정되는지 검증이 필요하다 |
| 브라우저 창을 옆에 두기 | 화면 한쪽에 Bodyguard 창을 따로 띄워 둔다. 구현은 쉽지만 작업 화면이 좁아진다 |
| 뒤에서는 알림만 | 창이 가려지면 측정을 느리게 돌리고 자세가 무너질 때 알림만 띄운다. 아바타는 창을 열었을 때만 보인다 |

**답 (직접 입력)**
> 이건 그 웹을 켜야지 동작했으면 좋겠어.
> 계속 이게 되면 카메라도 계속 켜져있어야하고 무거울것 같아.

### 알림 기준
질문: 스트레칭 알림은 언제 띄울까요? 숫자는 초기값이고 설정에서 바꿀 수 있게 할게요.

| 선택지 | 설명 |
|---|---|
| 자세 이탈 + 오래 앉음 (추천) | 자세가 5분 넘게 무너지면 한 번, 자세가 괜찮아도 50분 앉아 있으면 스트레칭을 권한다 |
| 자세가 무너질 때만 | PRD 흐름 그대로. 자세만 괜찮으면 몇 시간을 앉아 있어도 알림이 없다 |
| 정해진 간격마다 | 자세와 상관없이 N분마다 알린다. 가장 단순하지만 카메라 측정과 따로 논다 |

**답**: 자세 이탈 + 오래 앉음

### 로그인
질문: 기록이 날짜별로 쌓이려면 사용자를 구분해야 해요. 로그인은 어떻게 할까요?

| 선택지 | 설명 |
|---|---|
| Google 로그인 (추천) | 비밀번호 화면 없이 구글 계정으로 들어온다. 다른 PC에서도 기록이 이어진다 |
| 로그인 없이 브라우저 기준 | 처음 접속한 브라우저에 익명 ID를 준다. 가장 단순하지만 브라우저 데이터를 지우면 기록이 끊긴다 |
| 이메일·비밀번호 가입 | 직접 가입을 받는다. 비밀번호 저장과 재설정 기능까지 만들어야 한다 |

**답 (직접 입력)**
> 구글 로그인 + 웹 자체 로그인도 필요해

### 저장 범위
질문: 서버에는 무엇까지 올릴까요? 영상은 어느 쪽이든 브라우저 밖으로 나가지 않아요.

| 선택지 | 설명 |
|---|---|
| 1분 단위 요약만 (추천) | 관절 좌표는 브라우저에서 각도로 바꾼 뒤 버린다. 서버에는 1분마다 지표 평균·이탈 시간과 스트레칭 기록만 올린다. 대시보드·변화 탐지·리포트에 충분하다 |
| 각도값을 초 단위로 | 그래프를 더 촘촘하게 그릴 수 있지만 데이터가 60배로 늘어난다 |
| 관절 좌표까지 (PRD 문구대로) | 나중에 계산식을 바꿔도 다시 계산할 수 있지만, 몸 형태 데이터가 서버에 남는다 |

**답**: 1분 단위 요약만

## 2차 질문

### 탭이 뒤로 갔을 때
질문: 웹을 켜 둔 동안만 측정하는 걸로 할게요. 그런데 켜 둔 채로 다른 창(코딩·과제)으로 넘어가면 어떻게 할까요? 고르신 '오래 앉음' 알림은 이 상태에서 제일 필요해요.

| 선택지 | 설명 |
|---|---|
| 뒤에 있어도 측정 (추천) | 탭만 열려 있으면 계속 잰다. 뒤에 있을 땐 1초에 한 번 정도만 재서 가볍게 돌리고, 자세가 무너지거나 오래 앉으면 알림을 띄운다. 브라우저 제약 때문에 되는지 먼저 확인해야 하고, 안 되면 2번으로 간다 |
| 보고 있을 때만 측정 | Bodyguard 화면이 보일 때만 재고, 다른 창으로 가면 멈춘다. 확실하게 동작하지만 작업 중 알림은 사실상 없다 |

**답**: 뒤에 있어도 측정

### 아바타
질문: 정자세를 보여줄 3D 아바타는 어떤 모습일까요? 처음엔 뼈대로 시작해서 이 모습으로 넘어가요.

| 선택지 | 설명 |
|---|---|
| 마네킹형 (추천) | 얼굴 없는 단색 인체. 부위별로 빨갛게 칠하기 쉽고 단색 강조 UI와 어울린다. 무료 에셋이 많지만 라이선스는 하나씩 확인해야 한다 |
| 캐릭터형 | 귀여운 캐릭터. 친근하지만 부위 색칠이 까다롭고 쓸 수 있는 에셋이 적다 |
| 뼈대로 끝까지 | 점과 선만 쓴다. 가장 쉽지만 '3D 인체 아바타' 기능보다 한 단계 낮다 |

**답**: 마네킹형

### 공개 범위
질문: 레포가 Public인데, AI 개발용 문서는 어디까지 올릴까요?

| 선택지 | 설명 |
|---|---|
| 대화 원문만 로컬 (추천) | AGENTS.md와 개발 문서는 레포에 올리고, 대화 원문(research/)만 .gitignore로 로컬에 둔다 |
| 전부 레포에 | MotionLayer처럼 research/까지 올린다. 요구사항 근거가 남지만 대화 내용이 공개된다 |
| 문서는 전부 로컬 | 레포 폴더 안에 두되 전부 .gitignore로 뺀다. 레포에는 코드와 README만 보인다 |

**답 (직접 입력)**
> 레포를 우선 개발할때는 프라이빗으로 잠그고 개발할거라서, 그렇게 했으면 좋겠어.
> 지금 즉시 올리지는 말고 나한테 전부 승인 받고 올려줘
