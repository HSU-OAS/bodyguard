# Figma 홈 개발 검수

- 기준: [Figma 홈](https://www.figma.com/design/8f6TiE81S5Cu2bjgTuHFeZ/BODYGUARD-%C2%B7-UI-%EC%84%A4%EA%B3%84?node-id=21-4)의 양쪽 패널과 중앙 아바타 배치.
- 개발 서버의 `/dev/figma-home`에서만 화면 구조를 확인한다. 배포용 빌드에는 포함하지 않는다.
- 중앙 인체와 일부 동작 그림은 Figma의 정지 시안이다. 출시용 3D 모델이나 검증된 자세를 뜻하지 않는다.
- 목 옆 기울이기·어깨 으쓱·팔 위로 뻗기에는 기존 Blender 제작 후보 미리보기 영상을 재사용한다. 영상은 마우스를 올리거나 키보드로 재생할 수 있으며 동작·아바타의 출시 승인을 뜻하지 않는다.
- 카탈로그에 연결되는 카드만 개발용 코칭 화면으로 이동한다. 미구현 동작과 메뉴는 비활성화한다. 코칭 화면은 기존 로그인 및 검증 게이트를 유지한다.
- 이번 범위는 홈 레이아웃 검수다. 코칭 화면의 최종 Figma 적용, 실제 카메라 추적과 자세 판정 검증은 포함하지 않는다.
