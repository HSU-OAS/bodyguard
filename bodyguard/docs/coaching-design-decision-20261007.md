# 코칭 웹 디자인 방향 승인 — 2026-10-07

CEO가 v4 의료·신체 케어 도구 분위기를 승인하고 기존 goal을 재개했다. 노트북 웹, 화이트·블루, 부드럽되 과장되지 않은 모서리·한글 정렬·도구 밀도, 하나의 공간에 충분한 간격의 두 아바타가 기준이다. 전신은 발끝까지, 상반신은 필요한 부위를 크게 보여준다. 왼쪽은 사용자 움직임, 오른쪽은 현재 단계·교정할 부분에 맞춘 검증된 시범이다.

기존 HTML과 이전 시안은 확정 디자인이 아니다. 다음은 [클릭 가능한 코칭 시안 Story](stories/coaching-design-prototype.md)의 보기 전환·동작 선택·설정·조작 구조를 검토받는 것이다. 구조 승인 뒤 나머지 화면·로딩·오류·빈 상태·접근성 계약과 제품 적용 범위를 확정한다. 이 문서는 전체 웹 구조·카탈로그·임상 기준·아바타 품질 승인이나 출시 완료를 뜻하지 않는다.

원본 자료는 Story의 배치용 에셋에 보존한다. 기존 실제 제품과 독립된 디자인 검토용 HTML만 추가하며 운영·비용·계정·시크릿·DB·배포·출시 권한은 기존 [운영 규칙](operating-rules.md)을 유지한다.
