## 화면 텍스트 최소화 — CEO 추가 결정

2026-10-07 CEO: “그리고 가능한 텍스트는 최소화로 할게”.

- 아바타 비교와 현재 해야 할 행동이 먼저 보인다. 상시 설명 문단·중복 상태 문구·여러 교정 문구를 동시에 늘어놓지 않는다.
- 교정 안내는 현재 확인된 우선 행동 하나를 짧게 보여준다. 세부 근거·수행법은 사용자가 펼쳐 볼 수 있다. 아바타의 부위 강조는 문구를 보조하며 검증되지 않은 부위를 추정하지 않는다.
- “내 동작 / 시범”, 주요 버튼, 촬영 준비·오류 복구 등 구분에 필요한 짧은 이름은 남긴다. 아이콘 전용 조작은 접근 가능한 이름과 키보드 포커스를 갖춘다. 색이나 hover만으로 의미를 전달하지 않는다.
- 중단이 필요한 안전 안내, 필수 동의·데이터 삭제 확인, 실제 기능과 정적 시안의 구분은 숨기거나 선택 설명으로 낮추지 않는다. 꼭 필요한 시점에 간결하게 제시한다. 기존 안전·개인정보 계약은 변경하지 않는다.
- 이 결정은 문구·정보 밀도 원칙의 승인이다. 코칭 구조 전체, 나머지 화면, 제품 대규모 적용 승인은 아니다. 기존 시안·검증 원본을 보존하고 다음 승인된 디자인 수정 구간에서 반영·재검증한다.

검토 시 상시 설명이 아바타를 가리는지, 현재 행동이 한눈에 구분되는지, 설명을 접어도 조작·안전·복구·키보드 사용이 가능한지 확인한다. [S4.D3 독립 HTML](stories/coaching-prototype-minimal-copy.md)의 텍스트 최소화와 실제 Chrome/화면 재검증은 수행했다. 제품 화면은 아직 적용하지 않았으며 클릭 가능한 구조와 적용 범위 합의도 남아 있다.
