# S2.T15 — 손목·손가락 관찰 표시 연결

2026-10-08 · 기준 main 815422b(PR77) · 비공개 기술 통합, 출시 완료 아님.

## 목적·제외

기존 A37 남녀 원본의 실제 관절 축과 GLTFLoader 이름을 읽고 손목2개·손가락30개를 owned 사용자 아바타에 선택적으로 연결한다. 원본과 GLB는 수정하지 않는다. 같은 입력의 명시 손 후보는 표시용이지 동일인·가림 정확도·자세 정답 판정이 아니다. 손가락 축 회전·손바닥 변형·중수골 관절 측정을 지어내지 않는다.

이번 목적은 표시 드라이버와 기존 몸/머리 owned pair 연결이다. native Gesture Recognizer의 같은 입력 수집·소유권 연결은 다음 독립 Story다. 공개 화면·제품 문구·추천/코칭 판정·API/SQL·운영/SDK 정책 변경0. 여성 무의상·얼굴/목 최종 외형 변경은 이월 그대로 유지한다.

제품 문구는 핵심 조작·필수 안전/동의·오류/촬영 안내만 간결히 남기는 CEO 방향을 유지한다. 이번 비공개 검증 화면은 확정 제품 디자인이 아니다.

## 수용 기준·하네스

1. 실제 보존 Blender 원본을 읽기 전용으로 검사하고 손가락 끝마디를 포함한32관절 이름/계층/축을 확인한다. 모델/재질/정점/position/scale/8가중치/기준 아바타는 불변이다.
2. 손 설정은 선택적이며 명시 왼손·오른손 camera reference와 scene basis를 비동기 load 이전에 복사·검증한다. 손목은 손바닥 평면을 이용한 회전, 손가락은21점의15선분 방향과 원본 twist 보존으로 구분한다. 임의 임상 각도·중립 자세를 만들지 않는다.
3. 원래 generation/sequence/at를 유지한다. 외부 getter 재진입/abort/예외, 역순/중복/만료, 복수/누락/클리핑/퇴화 입력을 테스트한다. 새 누락은 coverage를 해제하고 이전 값을 관찰처럼 유지하지 않는다. 안 보이는 관절을 정답 자세로 복원하지 않는다.
4. 손 없는 caller의 기존 상태·기본 몸/머리 동작과 정리 계약은 그대로다. 몸이 단일 완전 후보가 아니면 손 후보도 해제한다. 손 배열·기준을 복사하며 source/기준 모델/다른 세대나 소유자를 변경하지 않는다.
5. 단위 합성 시험 및 실제 Chrome/WebGL/A37 남녀32관절 회전·굽힘→가림→누락→복수→복구→만료→종료를 실행한다. 실제 카메라/SDK 양성/참가자 정확도 시험과 혼동하지 않는다. 아바타 전용 캡처만 허용하며 영상·개인 좌표 저장0.
6. 전체frontend·타입·Biome·assets/build·public guard·diff와 공개byte·5모델 불변을 검증한다. 실패·원본·SHA를 보존하고 Story P1/P2 해소 및 최신PR Git 게이트 후 병합한다.

## 남은 필수 조건

native 몸/얼굴/손 동일 입력과 소유권, 같은 사람 연결·실제 가림/깊이/좌표계·손가락 twist/중수골·피드백 판정, 최종 외형/권리·승인 디자인·실제 노트북/참가자·HTTPS/운영 게이트는 미완료다. 실제 시험 없이 D2나1~6단계 완료/출시 후보판으로 표시하지 않는다.
