# S3.A1 Blender 동작의 단계별 3D 시범 콘텐츠

2026-10-16 · base mainfeffa27 · codex/blender-reference-content · FR-S-01/03/04/06·FR-A-01/02/03·NFR-08

## 범위와 수용 기준

기존 전문 Blender 남녀3종 action을 재사용해 준비·수행·유지·복귀와 좌/우 단계에 맞는 실제 3D 시범을 만든다. 오른쪽 모델이 같은 전체 동작만 반복하는 대신 현재 단계의 clip을 선택할 수 있게 기존 referencePlayback에 연결한다. 첫 출시 전체 동작/추천/판정·다른4종을 이3종으로 대체하지 않는다.

- 보존된 `motion-preview-content/native/motion-preview-authoring.blend`와 PR150의 불변2be0ebe 남녀 GLB를 기준으로 한다. 기존 원본/GLB·메시·모든8가중치·리그·실패 증거는 덮어쓰지 않는다. 최종 외형/변형/성능 P2는 그대로다. 제작 보류 해제·로컬 무비용 권한으로 별도 후보만 제작한다.
- 전문 native action을 Blender에서 평가/내보낸다. 가능하면 메시 없는 애니메이션 GLB로 원본 신체/가중치와 분리한다. 실제 exporter가 보존하는 뼈/정지 변환과 기존 GLB의 binding을 대조한다. 맞지 않는 채널은 추측·소실시키지 않고 실패로 남긴다.
- 기존 native action의 정성 수행만 사용한다. 좌우 목 기울기·양 어깨 상승/이완·한 팔씩 위로 올리기의 [제작 근거](motion-preview-content.md)를 유지한다. 작화 시간/진폭과 프로그램 phase는 임상 정답/유지 시간·효과/처방이 아니다. 하체/의자 전체나 손의 힘/통증을 검증했다고 표시하지 않는다.
- 기존 ReferenceProgram/Playback을 재사용해 실제 clip의 단계/측면을 연결한다. 머리/팔/어깨 변형, 준비↔수행↔유지↔복귀·좌우 전환/정지·만료/잘못된 입력·소유권 종료를 검증한다. 시범이 사용자 모델·원본을 움직이지 않아야 한다.
- 개발 전용 고정 경로/크기·SHA 검증으로만 제공하고 production에는 후보/경로/GLB를 넣지 않는다. 기존 코칭 UI의 시범 미연결 자리에서 명시 검수만 가능하게 하며 새 메뉴/화면 개편은 하지 않는다. native 카메라/판정·자동 성공/점수·실제 기록을 시작하지 않는다.
- 실제 Blender export/원본 재열기·GLB 채널/정지 변환·브라우저/WebGL과 실제 화면을 확인한다. unit/DOM·전체frontend·타입/build/Biome·production guard·diff/리뷰를 통과한 응집된 PR로 기록한다. 실패/미실행/합성을 구분하고 미해결 P1/P2면 Draft로 둔다.

## 하네스 계획

1. Blender: 고정 소스 SHA·6action/slot·phase 경계·메시/가중치/리그 불변, 새 출력만 허용. exporter 실제 옵션 조회 후 각 action의 GLB 채널/샘플을 확인한다.
2. 순수 콘텐츠 unit: 지원3종/성별·phase/side와 version, 정확한 binding·유한 시각/값·불일치 거부·입력 불변. synthetic fixture와 실제 자산 검증을 분리한다.
3. 실제 Chrome/GLB: 남녀3종 단계별 픽셀/뼈 변화·좌우/준비/복귀·두 모델의 독립성·중지/숨김/계정/이탈/오류와 수동 재시도·전신/crop·가중치 보존·외부/카메라/저장0을 확인한다. 실제 SDK 양성/사람/임상 정답 검증이 아니다.

## 제외·남은 의존성

PR152의 간헐 SDK 시작/정리 P2나 PR150 최종 외형·8가중치 노트북 성능을 이 콘텐츠로 통과시키지 않는다. 실제 관찰→올바른 classifier/추천→시범 적응→실제 결과 생성 통합과 전체1~4/1~6 필수 기준은 남는다. 비용/계정·공급자/Docker·운영 DB/시크릿·배포/출시·중요 안전/개인정보 변경은 실행하지 않는다.

## 실제 구현·검증 결과

기존 코칭 공간의 오른쪽에 남녀3종 native action의 단계별 3D 시범을 연결했다. 명시 열기·단계/좌우·일시정지/재생·구도 선택과 손상 자산/컨텍스트 손실의 수동 재시도가 작동한다. 왼쪽은 연결 대기로 남고, 자동 코칭/판정/타이머/기록을 만들지 않는다. 공개 빌드에는 후보 GLB/개발 경로가 없다.

[실제 화면·출처/원본·실패·검증 기록](../review/blender-reference-content/README.md)에 Blender 원본 재열기와6개 animation-only GLB,163관절 binding·전체8가중치 CPU 변형, Chrome 실제 재생/복구, unit/전체 회귀 및 직접 리뷰를 구분했다. 초기 여성 정지 vector 값 거부·잘못된 하네스 selector·800px 손끝 잘림·기존 버튼명 회귀 실패도 보존했다. 원본/GLB 변경0·실측/임상/최종 외형 승인0이다.

범위 내 필수 검증을 통과한 별도 PR 게이트로 진행한다. 다음 핵심은 실제 사용자 관찰과 오른쪽 단계 시범의 동시 통합 및 동작별 판정/추천·결과 연결이다. 이 Story만으로 D2-T/I·3/4단계나 전체1~4/1~6을 완료하지 않는다. PR150/152의 별도 P2와 Draft/병합 금지도 유지한다.
