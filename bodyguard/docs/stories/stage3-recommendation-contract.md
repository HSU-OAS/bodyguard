# S3.1 — 추천 준비와 출시 적격성 계약

상태: 로컬 구현·검증 완료 / PR 게이트 대기 · FR-S-06 · 선행 main 955c853

## 범위

추천 입구의 정보 부족/검증 대기/직접 선택 복귀를 순수 계약으로 구현한다. 현재 출시 적격 동작은 0개이므로 실제 신체 추천이나 코칭 가능 동작을 생성하지 않는다. 카메라·아바타·임계값·원시 좌표·저장·외부 요청은 추가하지 않는다.

목적만 선택한 상태는 신체 확인 결과가 아니다. 미검증 후보 목록이 추천 후보로 새지 않도록 기존 개발 후보와 출시 목록을 분리한다. 실제 검증 규칙과 관찰 adapter는 최종 통합까지 미완료로 남긴다.

## 수용 기준 및 하네스

- 목적 없음/목적만 있음/신체 확인 불가/신체 확인 있음 각각 직접 선택 복귀를 제공한다.
- 신체 확인 있음으로 전달해도 검증된 규칙과 출시 동작이 없는 현재 상태에서는 추천 결과를 만들지 않는다.
- 기존 개발 후보 neck-side가 출시 목록에 포함되지 않는다.
- 입력을 변경하지 않고 결과의 상태와 안내가 결정적이다.
- Vitest 계약 시험, 전체 기존 회귀, Biome, typecheck/build 및 production 후보 차단을 실행한다.

순수 계약 시험은 실제 신체 분석·추천·화면 시연이 아니다. 후속 Story에서 보호된 추천 화면과 직접 선택 복귀를 연결한다. 본 Story는 임상 추천 규칙을 확정하지 않는다.

## 실제 실행 결과

- pnpm test: 17개 파일·206개 시험 통과. 신규 시험은 합성 상태 계약이며 실제 사용자 검증 아님.
- pnpm check: 64개 파일 통과, pnpm typecheck 및 pnpm build 통과.
- node scripts/check-selection-production.mjs: production 개발 후보 문자열0·미연결 엔진 문자열0.
- git diff --check 통과. 신규 코드/시험과 본 문서만 변경. 카메라·브라우저 시연·실측·운영 작업 미실행.
- 리뷰: 개인정보/외부 호출 없음, 목적만으로 신체 상태를 추정하지 않음, 실제 관찰 상태도 추천 규칙 검증을 우회하지 않음. 이번 계약 범위 미해결 P1/P2 없음. D2 이월 문제는 미해결 유지.

출시 적격 목록은 의도적으로 비어 있다. 시작 화면 복귀 주소는 현재의 보호된 허브이며, 직접 선택 화면 연결 자체를 완료로 세지 않는다. 화면 연결은 다음 Story의 별도 수용 기준이다.
