# S4.D5 — 최소 문구·움직이는 선택 시안

상태: 독립 시안·로컬 검증/작성자 리뷰 완료, 조건부 PR 게이트 진행. 최신 main a44e713(PR106 실제 병합)에서 codex/visual-motion-selection. 제품 구조 적용 승인 아님.

## 목적·경계

CEO의 화이트·블루 의료 케어 도구 방향·한 공간의 두 아바타·텍스트 최소화 안에서, 기존 독립 코칭 시안의 동작 선택에 실제 WebGL 미리보기를 연결한다. 긴 설명 대신 움직임으로 선택 경험을 검토한다. 기존 HTML/이미지/검증은 보존하고 별도 시안으로 만든다. 카메라·SDK·임상 판정·계정/API/기록·공개 번들·Blender/원본/GLB/새 조형은 변경하지 않는다.

출시 동작0·미완성 모델을 숨기지 않는다. 남녀 같은 **제작 시험 동작 하나**의 미리보기이며 검증된 스트레칭이 아니다. 구도 선택은 화면 배치만 변경한다. 모델·클립은 기존 증거와 동일 byte를 사용한다. 제품에 연결하려면 구조/적용 범위 합의와 동작/에셋 출시 게이트가 따로 필요하다.

## 명세·수용 기준/하네스

1. 새 동작 dialog는 제목·시험/임시 모델 구분·남녀·미리보기·재생/정지·구도 선택이 우선이다. 추가 설명은 기본 닫힌 details. 색/hover만으로 의미를 전달하지 않는다. 기존 전신 발끝/간격·정적 코칭 표시·카메라 미사용·비진단 안내는 유지한다. FR-V-01/FR-A-03/NFR-08.
2. 기존 단일 소유 미리보기 엔진을 재사용한다. 포인터/초점 자동 재생, 명시 정지, 남녀 전환, 늦은 로드 폐기·정확한 정리, dialog 닫기/Escape·숨김·pagehide 정리를 연결한다. 닫힌 상태나 이전 세대는 재생하지 않는다.
3. 동작 감소에서는 hover/focus 자동 재생0·명시 재생/정지 가능. 로딩·실패/재시도·정리 실패 차단을 간결하게 표시한다. 실제 모델의 정지 포스터와 움직임은 구분하며 제작 외형을 최종 외형으로 승인받지 않는다.
4. 실제 로컬 Chrome/WebGL에서 남녀 재생→정지·키보드·빠른 전환·닫기/재열기·가림·reduced-motion·로딩/실패 복구·1280/820px·CSS200%·초점·대비를 확인한다. 초기 미연결 실패와 최종 PNG/실행 소스 SHA를 보존한다. 네트워크는 시안/기존 자산만, 카메라/저장/API0. 실제 사람·임상/물리카메라·실제 브라우저 메뉴 확대/운영 배포 시험이 아니다.
5. 공개 build 바이트/원본 SHA 불변, 소스 타입/정적/기존 회귀·git diff --check. 리뷰/최신 main/exact HEAD/CLEAN/체크 후 조건부 merge commit. 전체1~6/D2·기존 시작P2/승인 UI/SDK/실측·외부/운영 게이트는 유지한다.

## 디자인 계약

기존 16px 본문/20·25px 제목, 백색·남색/청색 행동,8/12px 반경·44px 조작·8/16/24px 간격·단일 아이콘 계열을 재사용한다. 한 개의 시험 동작을 크게 보여주고 다른 옵션처럼 중복하지 않는다. 모션은 동작 이해에만 사용한다. web-design-studio→frontend-design→UI UX Pro Max의 reduced-motion 검색(실제 맞는 Animation 결과)을 적용한다. threejs keyboard 검색0, 한 번 좁힌 dispose 검색 결과는 직접 적합성 확인 후 기록한다. 새 디자인 시스템/외부 라이브러리/효과는 추가하지 않는다.
