# S3.2 — 보호된 직접 선택·추천 준비 화면

로컬 구현·검증 완료 / PR 게이트 대기 · FR-S-06 / FR-U-04 · main cf73926

디자인 계약: 기존 백색·청색 버튼·타이포·간격을 재사용한다. 한 화면의 주 작업은 시작 경로 선택이다. 직접 선택/추천 탭, 추천 목적 라디오, 시작 화면 복귀를 제공한다. 출시 동작0인 현재 목록은 실제 빈 상태를 표시한다. 후보를 공개하거나 가짜 분석 결과·활성 코칭 버튼을 만들지 않는다.

하네스: 직접 선택 빈 상태, 탭 이동·목적 선택, 추천의 정보 부족·검증 대기 안내, 복귀 링크를 DOM으로 재현한다. App의 SessionGate로 로그인/오프라인/로그아웃 실패 보호를 재사용한다. 순수/DOM 시험과 실제 Chrome 화면 확인은 각각 구분한다. 후자는 실행 전 완료로 표시하지 않는다.

수용 기준: /start→/explore 이동, 두 경로 선택, 선택한 목적 확인, 안전한 빈/준비 상태와 복귀가 작동한다. 카메라/저장/외부 호출 없음. 전체 회귀·Biome·typecheck·build·production 후보 차단이 필수다. 실제 추천·코칭·아바타는 미완료 유지한다.

## 실제 결과

작동 흐름: 보호된 내 시작 → 시작 경로 선택 → 직접 선택 빈 목록 / 추천 목적 선택 → 직접 선택 복귀 → 내 시작. 실제 Chrome에서 production 빌드의 흐름을 확인했다. 계정 응답은 mock이며 실제 가입·신체 분석·운동 수행 시험은 아니다.

초기 실패: ARIA 지원·semantic role 오류 및 테스트 DOM 환경 누락을 발견했다. fieldset/legend와 happy-dom으로 수정 후 회귀 재실행 통과. 첫 브라우저 실행은 sandbox localhost listen EPERM으로 실패했고 로컬 전용 실행 권한으로 재실행했다. CSS specificity 경고는 순서를 수정해 제거했다.

최종: Vitest210/18파일, Biome67파일 경고0, build/typecheck, production 후보/미연결 엔진 문자열0, 실제 Chrome6개 통과. 카메라 호출0, 외부 자산/측정 요청0, storage0을 하네스에서 확인했다. [실제 화면 증거](../review/stage3-explore/README.md). git diff --check 통과.

범위 리뷰: 동일 SessionGate 재사용, guest/503 화면 보호 시험, 임계값·원시 좌표·신규 서버/저장 없음. 이번 화면 범위 미해결 P1/P2 없음. 출시 동작0/아바타·실제 추천·코칭·전체 단계는 미완료다.
