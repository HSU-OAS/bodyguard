# S4.D3 — 독립 코칭 시안 텍스트 최소화

상태: 독립 HTML 보완·예비 검증 통과 / 실행 커밋 최종 재검증 전 · baseline `317cbd15902cc0c8322d318a238fe1f2cd197941` · `codex/prototype-minimal-copy`

CEO의 텍스트 최소화 결정과 S4.D2의 기존 독립 HTML 범위 안에서만 상시 부가 설명을 접는다. 제품 React/라우트/API·새 메뉴/화면·아바타 이미지/3D·판정/카메라·privacy·운영 변경은 없다. 기존 두 아바타 간격·전신 발끝·주 조작·화이트블루/한글/둥근 모서리를 유지한다. 구조 승인이나 최종 외형 승인이 아니다.

## 명세·수용 기준

1. 초기 화면은 두 아바타와 현재 구도·짧은 조작 이름이 우선한다. 중복 설명은 기본 닫힌 native `details`의 “설명 보기”로 옮긴다. 역할/정적 배치 예시·실제 판정 아님·카메라 미사용·비진단 구분·오류 복구·종료 확인은 계속 보인다. 시안 이미지의 강조도 실제 교정이 아님을 짧게 표시한다. FR-A-01/02·FR-V-01·NFR-08.
2. 마우스/Enter/Space로 설명을 열고 닫으며 초점이 남는다. 설명을 접어도 구도·선택·설정·수동 단계/일시정지·종료 취소가 작동한다. 종료 확인 시 설명도 닫힌 초기 상태로 돌아온다. hover나 색에만 의미를 맡기지 않는다.
3. 기존11개 실제 Chrome UI/경계 회귀와 새 설명 접기 회귀를 실행한다. 기존 제한·assertion 의미를 낮추지 않고 새 기준을 원본 화면에서 먼저 실패시킨다. 이미지 실패/복구·1440/1280/1024/820px 노트북 창·CSS200% 확대·focus/대비·reduced-motion·외부/API/카메라/저장0을 확인한다. 실제 브라우저 메뉴 확대·실측·최종3D 검증이 아니다.
4. 원본 이미지·기존 시안/증거·초기 런타임 부재 실패를 보존한다. 최종 실행 시작/끝 source SHA·실제 PNG·원본 SHA를 남기고 `web-design-studio` 및 지정 최종 critique로 실제 화면을 확인한다. scoped P1/P2 없음·최신 main/diff/exact HEAD/CLEAN/체크 뒤에만 조건부 PR 병합한다. 제품 디자인 구조/적용과 전체1~6은 미완료다.

## 디자인 계약

화면의 주 대상은 아바타2개다. 기존 백색/남색 본문·청색 행동, 한글 시스템 폰트·16/20/25px 위계·8/12px 모서리·기존 icon family/44px controls를 재사용한다. 설명 접기는 새 카드/라이브러리/장식 모션 없이 native HTML이다. 텍스트 수를 줄이려고 필요한 구분·안전·접근성 이름을 지우지 않는다. UI UX Pro Max의2개 targeted 검색은 설명 접기에 직접 맞는 결과가 없어 frontend-design의 점진적 설명과 native keyboard 기준을 권장안으로 사용한다. DB 검색 결과라고 주장하지 않는다.

## 실행

- 최초 baseline 초기화는 시안 worktree의 미설치 Playwright 경로 때문에 실패했다. 원본 log 보존, UI 시험 미실행으로 구분한다. 동일 lock의 기존 설치 frontend 런타임을 명시 사용한다.
- 동일 package/lock의 기존 설치 frontend 런타임에서 원본 S4.D2 구도·모달·오류·경계11건이 실제 통과했다. 새 설명 접기 수용 기준을 추가한 원본 화면은 11통과/1실패(설명 접기 요소 없음)였다. 원본 결과를 보존한다.
- 상시 부가 설명을 기본 닫힌 native details로 옮기고 중복 문구를 줄였다. 강조 예시·비진단·정적 시안·카메라 미사용·오류 복구·종료 구분은 유지했다. 첫 보완 Chrome12건 통과, 초기 DOM의 보이는 공백 제외 문자291→182였다. 이미지 안의 글자나 전체 서비스 문구 길이를 센 수치는 아니다.
- 실제 전신1440/1024px·설명 펼친 화면을 직접 검토했다. 아바타 간격·발끝·주 조작 위치는 유지되고 필요할 때만 상세 설명이 나타난다. 기존 이미지 SHA는 동일하다. source5개 시작·종료 대조에 실행 HEAD 및 설명 버튼 대비를 추가했으며 커밋 소스로 최종 재실행한다.
