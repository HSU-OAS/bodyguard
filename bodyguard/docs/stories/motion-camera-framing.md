# S3.C5 — 선택 동작·실제 입력의 촬영 준비 연결

기준 main `dde3d3c86731f1ba0c1c756769ddfb0aaaae187e` · `codex/motion-camera-framing` · FR-M-02/07·FR-S-06·FR-U-04·NFR-07/08

상태: 로컬 구현·검증 완료, 조건부 PR 게이트 진행 중. 2026-10-11 CEO 지시대로 추가 디자인/UI/UX 다듬기를 보류하고 독립 기능 연결을 우선한다. 같은 날 아바타 보류 유지·실제 참여자 연결은 나중이라는 답을 적용한다. Docker 연결 보류·전체 1~6 완료 기준은 불변이다.

## 범위

선택한 후보 동작의 기존 수행 안내에 맞는 촬영 준비를 실제 연속 SDK 입력에 연결한다. 기존 `trustedJoints` 기준과 개발 촬영 도구의 1초 입력 신선도만 재사용한다. 출시 판정/정확도 임계값을 확정하거나 조정하지 않는다. 결과는 고정 촬영 안내 상태이며 자세의 정답·동일인·의학적 분석·추천·적립·기록·시범 활성화가 아니다.

화면 구도(전신/상반신/자세히)는 보기 설정일 뿐 필요한 촬영 범위를 바꾸지 않는다. 동작 변경은 이전 카메라/Worker/입력과 촬영 상태를 종료하고 새 동작에서 명시 재준비해야 한다. 잘못된 동작 ID로 카메라를 열지 않는다. 새 아바타나 화면 구조·장식은 만들지 않으며 기존 준비 영역을 사용한다. 원시 영상·관절·예외를 DOM/로그/저장/서버로 내보내지 않는다.

## 수용 기준·하네스

1. 순수 계약: 머리/어깨, 팔, 상체, 전신의 필요 관절을 따로 검사한다. 상반신 동작에 전신이 보여도 불이익이 없고 전신 요구에서 다리 누락은 충족하지 않는다. 출력에는 좌표/관절 번호/원문 오류가 없다.
2. 단일 새 입력의 화면 안 좌표·기존 신뢰도를 검사한다. 빈/복수/불완전/비정상/오래된/미래 입력은 긍정 상태로 바뀌지 않으며 신선한 미검출은 즉시 이전 상태를 해제한다. 한 상태를 1초 넘게 유지하지 않는다.
3. 실제 React 카메라 준비→별도 입력 확인→촬영 안내→끄기를 연결한다. 준비 입력은 폐기, 촬영 안내로 코칭/시범/기록이 활성화되지 않는다. 동작 변경·숨김·종료·계정 변경은 이전 요약도 폐기한다. unknown ID는 카메라 연결을 제공하지 않는다.
4. unit/DOM은 합성 관절·계정/소유 자원으로 경계를 검증한다. 실제 Chrome·native 가짜 카메라·실제 heavy SDK에서는 미검출 촬영 안내/새 동작 명시 준비/구도 분리/권한 및 종료 흐름을 검증한다. 긍정 동작 정확도·사람 실측으로 세지 않는다.
5. 범위/전체 회귀·타입·정적 검사·production build 및 private 제외/CSP·diff·원본 증거·작성자 리뷰를 실제 실행한다. 실패는 보존하고 최신 PR 상태와 조건부 병합을 확인한다.

## 제외·남은 조건

아바타 제작/GLB/변형/새 브라우저 아바타 사이클·실제 사람·동작 성공 판정·추천/결과 생성·기존 시작P2·Docker/HTTPS/운영·비용·계정·시크릿·배포/출시는 제외한다. 기존 아바타/Docker 보류 및 이번 실제 참여자 보류를 존중한다. 이 Story 완료만으로 전체1~6이나 촬영 정확도 통과를 선언하지 않는다. 검증 결과·PR은 완료 후 실제 증거를 연결한다.
