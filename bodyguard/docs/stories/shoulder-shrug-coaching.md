## 범위와 근거

기존 목 전용 판정 다음으로 어깨 으쓱·이완의 실제 판정 코드를 구현한다. 같은 원본 프레임의 머리·어깨·팔·골반과 촬영 크기/반전·세대/순서/시각으로 image-plane 기하를 계산하고, 명시 검수 프로필의 시작→양쪽 상승→유지→복귀를 기존 세션/결과 생산에 연결한다. 목 코드를 어깨 동작으로 이름만 바꾸거나 귀–어깨 거리 감소만으로 성공 처리하지 않는다.

[CUH Neck sprain advice](https://www.cuh.nhs.uk/patient-information/neck-sprain-advice/)의 다섯 번째 동작은 어깨를 귀 방향으로 올린 뒤 이완하는 수행 근거다. 2026-10-17 원문 확인: 승인2025-02-07, version5, ID30927. 환자용 자료의 약물·일별 횟수·통증 경계는 일반 사용자 처방으로 복사하지 않는다. 원문은 카메라 투영 수치/허용 각도·개인별 필요성·유지 시간을 검증하지 않으므로 임상 기본값/운동량을 만들지 않는다. 잘못된 `/neck-sprain/` 주소는 조회 실패였고, 실제 목록의 `/neck-sprain-advice/` 원문을 확인했다. 원문 사진/영상은 복제하지 않는다.

## 명세·하네스

1. 단일 인물·필수 머리/양어깨/팔/골반의 visibility·제공된 presence·화면 범위와 원래 image 기하가 모두 필요하다. 가림/다인/원본 크기 없음·퇴행/오래됨/미래 입력에서는 성공하지 않는다. 픽셀 종횡비와 촬영 반전을 보존하고 화면 크기/CSS로 대체하지 않는다.
2. 골반선 기준으로 양어깨 높이·머리 위치/방향·몸통 기울기·위팔 방향을 계산한다. 몸 전체 이동/확대와 어깨 상승을 구별하고, 머리만 낮추기·몸통 기울이기·한쪽만 상승/팔 들기·과범위는 프로필에 따라 별도 오류가 된다. 3D 관절/통증/힘·깊이 회전 판정이 아니다.
3. 프로필은 `thresholds.ts`에 명시적으로 공급/복사/동결한다. neutral/target 분리와 양측 상승 방향을 검증하며 기본 수치가 없다. 시퀀스/원본 시각으로 판정하고 현재 세션의 동작/version/관찰 시간/단계가 맞을 때만 기존 세션에 전달한다. 외부 getter/세션 교체·닫힘의 늦은 결과를 채택하지 않는다.
4. 생성 기하로 정상/복귀·반전/종횡비·기울기/머리/팔 보상과 입력 경계를 반복 시험한다. 실제 진행 엔진/세션/제한 결과 DTO 및 모의 HTTP까지 시험하되 실제 사람·SDK·DB 저장 증거로 세지 않는다. 기존 목/추천 회귀, 원래 build/고지·production guard·Biome·diff와 작성자 리뷰를 수행한다.

## 경계·후속

이번 판정→세션 계약 다음에 어깨의 실제 사용자 아바타 상승 표현과 두 아바타 실행 UI/오류 표면·시범 반응을 연결한다. 현재 rig는 사지/몸통/머리 방향을 다루지만 어깨의 양측 상승을 완전히 재현한다고 입증되지 않았으므로 완료된 어깨 코칭으로 공개하지 않는다. 신규 Blender/GLB/공개 프로필·기준선/기록 쓰기·새 메뉴/UI 개편·안전/개인정보 정책·API/DB/시크릿/비용/외부/운영/배포/출시 변경은 없다. 공개 적격0·Draft150/152/SDK P2·기존 원본/실패·전체1~4/1~6 실제 기준을 유지한다.
