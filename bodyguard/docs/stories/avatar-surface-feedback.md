# S2.T19 — 관찰에 연결된 사용자 표면 오류 강조

Status: 소유 pair 구현·리뷰 보완·실제 WebGL 확인 / 커밋 고정 재검증·PR 전 / 단계 완료 아님

## 목적

오류가 확인된 부위를 사용자 모델 표면에 강조하고, 시범·원본·리깅은 보존한다.
색만으로 안내를 끝내지 않는 최소 텍스트 방향의 내부 연결 기반이다.
판정 규칙·각도·임상 효과·공개 화면·동작 적격성은 변경하지 않는다.
현재 A37은 최종 외형이 아니며 출시 적격 동작은 여전히0개다.

## 계약·수용 기준

- 옵션을 생략하면 기존 pair 동작·공개 byte가 동일하다. 설정은 load 전에 복사한다.
- 강조 영역은 명시 bone 목록으로 정의한다. 이 구간은 현재 관찰되는 사지8관절만
  지원하며 목·체간·손·세밀한 판정의 출시 기준을 축소하거나 대신하지 않는다.
- 오류 입력은 motion/version·현재 generation/pose sequence/원래 stamp와 정확히
  결합한다. pose driver가 복사한 관찰 coverage를 사용하며 caller가 가림을 덮어쓸 수 없다.
- 새 관찰·누락·복수 인물·불일치·만료·중단은 이전 강조를 지운다. 오래된 오류는
  새 관찰을 덮어쓰지 않는다. 확인 불가 색·초록 정상 판정·진행/기록 합성은 하지 않는다.
- caller가 공급한 attention/deviation만 주황/빨강으로 표시한다. 동작 오류의
  실제 검증을 이 표시 adapter가 증명하지 않으며 실제 classifier는 별도 선행 조건이다.
- 사용자 전용 geometry/material 복제와8가중치 셰이더를 사용한다. source/reference
  geometry·재질·pose·shape와 원본 GLB는 바꾸지 않는다. 추가 resource는 정확히1회 해제한다.
- 오래된 retained native pair에도 기존 controller 권한 확인을 유지한다.

## 진행 결과

남녀 실제 GLB/Chrome에서 강조→움직임→가림/미검출/복수→복구→만료→중단을 확인했다.
source/reference와8가중치·전신 구도는 보존했고 추가 GPU 자원은 이전 PBR cache 기준으로 회수됐다.
오류는 전부 합성 입력이며 실제 카메라·native SDK·사람·동작 기준 검증은 이 시험에 없다.
최초7계약 실패 후 구현했다. 미래 capture/RAF의 강조 유실과 poisoned 관찰의 잔존 강조는
7통과/2실패로 재현해 보완했고, sparse 설정의 불필요 load는12통과/1실패로 재현해 보완했다.
영역 typed mask로 vertex별 Map과 반복 배열 할당을 피했다. 실제 노트북 성능 완료는 아니다.
최초 sandbox loopback 차단 및 보고서 이름 충돌은 실행 준비 실패이며 Chrome 통과로 세지 않는다.
실패 receipt·초기/보완 번들을 보존한다. 초기 미커밋 소스는 hash·로그만 남은 부분이 있으며
전체 원문을 보존했다고 주장하지 않는다. 최종 커밋과 실제 재실행의 증거는 후속 정리에 연결한다.
공개 JS/CSS는 baseline과 동일하며 공개 디자인·조형·판정·운영 변경은0이다.
