# S2.3 — 첫 동작 관찰과 실제 검증

2026-10-01 · 진행 중 · 선행 S2.1 PR #6, S2.2 PR #7 main 병합.

근거: FR-M-01·02·07, FR-V-03, FR-S-01·02, [첫 흐름 계약](stage2-first-flow.md), [동작 근거·촬영 계획](../motion-evidence.md). 첫 후보는 손으로 당기지 않는 목 옆 기울이기다. 문헌의 수행 설명과 웹캠으로 실제 구별 가능한 특징은 서로 다른 증거다.

## 실행 단위

- **S2.3a 관찰 장치 보완**: 카메라 수명·복수 포즈·프레임 신선도·유효한 입력을 검사하는 개발 전용 하네스. 독립 PR로 검증한다. 이것만으로 S2.3 또는 2단계를 완료하지 않는다.
- **S2.3b 실제 동작 검증**: 팀원 본인의 수행과 관찰자의 라벨을 대조하고 튜닝/미사용 검증 조건을 분리한다. 실제 검증을 통과한 특징만 코칭 규칙으로 구현한다. 정상·보상·가림·추론 중단에서 성공과 시간 누적을 검증한다.

S2.3b 참여자를 기다리는 동안 S2.4의 조형·의상·리그 작업은 진행한다. 시범 각도·유지 시간, 출시 동작 판정은 S2.3b 전에는 확정하지 않는다. 영상·관절 좌표 저장/전송이나 참여자 정보를 수집하지 않는다. 현재 화면의 요약만 브라우저 메모리에 둔다.

1초는 개발 관찰 도구가 멈춘 프레임을 현재 촬영 증거로 쓰지 않기 위한 상한이다. 동작 판정 임계값·유지 시간·제품 추론 중단 기준으로 채택하지 않는다. 안내 문구의 기존 지연 표시와 즉시 데이터 무효화는 분리한다.

포즈 모델의 `numPoses`를 2로 설정하여 복수 검출 결과를 처리한다. 이는 **두 사람 검출 정확도나 대상 전환 방지를 검증한 것이 아니다**. 한 사람에서 다른 사람으로 바로 바뀌거나 가려진 사람이 누락되는 경우는 실제 관찰에서 별도로 검사한다. 미검출 인물까지 감지한다고 주장하지 않는다.

## S2.3b 현장 실행

1. 개발 도구를 조작하는 관찰자와 동작을 수행할 팀원을 분리한다. 자기 보고로 불편하면 즉시 중단하며 고개를 억지로 당기지 않는다.
2. 장치·브라우저·카메라 높이/거리·조명·옷·상반신/전신 범위를 익명 시험 조건으로 기록한다. 개인의 영상·좌표·이름·이메일은 기록하지 않는다.
3. 목 좌/우 기울이기·중앙 복귀, 작은 움직임·어깨 으쓱·몸통 기울임·고개 회전·손으로 당기는 상황을 대조한다. 강제로 위험 동작을 수행시키지 않고 손 당김은 접촉만 하는 중단 상황으로 확인한다.
4. 한쪽 어깨/얼굴 가림·두 사람·대상 전환·사선·역광·어두운 조건·카메라 중단을 별도 검사한다. 관찰자 라벨과 브라우저의 현재 입력 상태를 대조한다.
5. 튜닝 조건을 먼저 종료·동결하고 새 조건에서 재검증한다. 관찰 못 한 손의 압력·통증·목의 실제 3차원 관절 각도를 추정 결과로 확정하지 않는다.
6. 실제 결과를 바탕으로 세밀하게 볼 수 있는 특징·불가능한 특징·오류율·중단 조건을 문서화한다. 실패 시 이 동작을 출시 코칭에 연결하지 않는다.

현장 안내와 코칭 규칙은 자료·실측으로 구분한다. 자료 기반 안내 자체도 임상 검증/효과 보장이 아니다. 관절 신뢰의 기존 0.5는 시제품 값이며 S2.3b 이후 검증 없이 출시 기준으로 승격하지 않는다.

재생 실패/취소의 트랙 누수는 수정 전 실패를 확인하고 공통 camera 처리부에서 보완했다. Chrome의 SPA 이탈 시험은 주소만 바뀌고 카메라가 남는 결함을 잡았으며 App 분기를 실제 경로 구독으로 바꾼 뒤 재검증했다. 초기 happy-dom 시험 장치 오류와 잘못 선택한 E2E 링크의 실패를 제품 검증 통과로 계산하지 않았다.

자체 리뷰에서 비동기 소유권·중복 콜백·라우트 이탈·입력 경계·개발 도구의 production 제외·메모리 한도를 점검했다. 발견된 카메라 누수/라우트 이탈 결함을 해결했고 현재 미해결 P1/P2는 없다. 독립 전문가·실제 동작 리뷰가 끝났다는 뜻이 아니다.

경고: 기존 Three.Clock 폐기 예정 경고와 MediaPipe GPU/XNNPACK 정보·NO_COLOR 경고가 있다. 개발 카메라 E2E에서 서비스로 돌아갈 때 자체 API가 실행 중이 아니므로 로컬 프록시 연결 실패가 발생하나 페이지 오류는 없었다. 계정 자체는 별도 실제 API/SQL 9개에서 검증했다. 실제 사람 조건의 fps·검출 성능을 가짜 카메라 결과로 대체하지 않는다.

**S2.3b 실제 수행·정확도·시간/임계값·복수 인물 정확도·대상 전환·노트북 성능은 미검증이다. S2.3과 2단계 완료 기준은 아직 충족하지 않았다.** 참여자 연결을 요청했고 독립 S2.4 조형 작업은 계속한다.
