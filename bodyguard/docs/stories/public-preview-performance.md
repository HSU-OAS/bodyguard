# 공개 웹캠 검수본 성능·정면 맞추기 보완

상태: 로컬 구현·검증 완료, 공개 배포 미실행 · 요청일: 2026-11-12

## 문제와 범위

CEO가 공개 검수 URL에서 끊김과 인식 실패를 보고했다. 매 프레임 손가락 모델까지 실행하는 부하와 첫 신선한 입력 전에 정면 맞추기가 만료될 수 있는 시점을 보완한다. 이 Story는 공개 검수본의 런타임만 다룬다. Figma 홈 연결은 별도 Story다.

## 수용 기준

- 몸·머리 추적이 기본이며 손가락 상세 추적은 명시적으로 선택한다. 손목·팔의 포즈 관절은 유지한다.
- 첫 신선한 단일 신체·세부 입력 수신 후 정면 맞추기를 요청한다. 관절 신뢰도·원래 캡처 시각·판정·만료 기준을 완화하지 않는다.
- 같은 사전 녹화 가상 카메라로 기준선과 후보의 실제 SDK 지연과 입력 갱신을 비교한다. 렌더링은 추론 대기 중에도 계속된다.
- 시작·종료와 선택한 손가락 상세 모드를 확인한다. 영상·좌표·실제 카메라 촬영 및 외부 전송을 하지 않는다.
- 원본 및 실패 결과를 보존하고 실제 사용자 정확도를 검증했다고 주장하지 않는다.

## 변경

공개 검수본에서만 손가락 모델을 선택 실행하고 출력 번들을 축소한다. 렌더 해상도 상한을 기기 픽셀 비율 1.5로 두되 원본 GLB·리깅·표면은 바꾸지 않는다. 제품 코칭 게이트·정답/성공 판정 및 API는 변경하지 않는다. 공개 페이지 교체 배포는 별도 승인이다.

## 검증 결과

[같은 입력의 성능 비교와 회귀](../review/site-recovery-20261112/README.md)를 확인한다. 실제 사람 인식과 자연스러움은 미검증이며, 최종 손가락 상세 모드에서 머리 추적과 종료 상태 해제까지 재확인했다.
