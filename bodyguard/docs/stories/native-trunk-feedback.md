# S2.T23 — native 몸통 표시·오류 강조 통합

2026-10-08 · D2-T 비공개 통합 · 기준 main f55566d

## 목적·범위

명시적 trunk=true 호출의 spine05 집계 방향 표시와 같은 관찰에 묶인 오류 강조를 연결한다. 기존 팔·다리만 허용한 표면 프로그램에 spine05 한 개만 추가한다. 이는 supplied 오류의 표시 기반이지 올바른 자세 판정·개별 척추 검증이 아니다. spine04~01·골반/root·목/얼굴·원본 GLB·공개 화면/문구·의료 임계값·SDK 정책은 바꾸지 않는다.

몸통 표시를 켜지 않은 호출이 몸통 강조를 요청하면 카메라/원본 로드 전 거부한다. 네 필수 어깨11/12·골반23/24 관찰 중 하나라도 없으면 이전 강조를 유지하거나 성공으로 처리하지 않는다. 기존 세대·원래 capture 시각·순서·소유권·취소/정리 경계를 유지한다.

몸통 영역은 spine05 단독으로 저작한다. 모델 전체의 하나의 영향 peak로 색상 강도만 정규화하고 실제 skin 가중치와 원래 영향 범위를 보존한다. 0기여 하위 메시를 칠하거나 작은 기여를 별도로 확대하지 않는다. wholly unpaintable 모델은 거부한다. 기존 사지 표시와 프로그램 한도는 유지한다.

## 수용 기준·하네스

- 순수 표면/owned pair/native 단위 검사: 명시적 허용과 기본 호출 보존, 네 필수 관절 가림/화면 밖·복수/누락·만료의 강조 해제, 복구, 원본/시범·position/scale·skin 가중치 보존, 종료/이전 핸들 거부.
- 설치된 Chrome·실제 GLTFLoader/WebGL·native SDK·AuthProvider/HTTP/격리 PostgreSQL로 로그인→준비→두 아바타→기울기/강조→가림/복구→pause/resume→중단/본인 기록을 실행한다.
- native는 가짜 카메라의 실제 미검출을 먼저 계수한다. 생성 body 양성/오류를 별도로 표시한다. 실제 사람/신체 정확도·물리 카메라 권한·전문가 검증으로 세지 않는다.
- 남녀 화면을 아바타 canvas만 캡처하고, 외부 요청·raw 저장/전송0·자원 정리·기존 native 회귀를 확인한다. raw 좌표/영상은 증거에 저장하지 않는다.
- 전체 FE·Biome·tsc·production build/guard·diff 확인, 공개 JS/CSS byte·GLB 원본 불변, 실패 원본과 정확한 실행 증거 보존.
