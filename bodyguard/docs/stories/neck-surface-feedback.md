# S3.C3 — 목·어깨 오류의 사용자 표면 표시

2026-10-16 · PR158 merge `3b71975`의 최신 main에서 시작한다.

## 범위·설계

목 후보 판정의 같은 프레임 오류를 왼쪽 실제 GLB 표면에 연결한다. 기존 흰 공간/파란 컨트롤·빨간 오류 문구를 유지하며 메뉴/설정/배너를 늘리지 않는다. 오른쪽 제작 시범에는 색을 칠하지 않는다.

고정 원본의 `neck01/02/03` 가중치는 **목-머리선 표시 영역**, `clavicleL/R`와 `upperarm01L/R`의 어깨 캡 가중치는 **어깨선 표시 영역**으로만 쓴다. 변형 가중치의 턱/가슴 번짐은 원본 inverse-bind 관절 기준의 색상 경계로 제한한다. 이 경계/feather 비율은 표시 설계이며 자세 판정 수치가 아니다. 이 뼈들의 개별 회전/경추 각도를 측정했다는 뜻도 아니다. 기존 surface feedback의 사지·몸통 관찰 guard는 유지하고, 새 영역은 명시 image-plane 관찰 방식과 같은 capture stamp를 별도로 요구한다.

## 수용 기준·검증 하네스

- 판정 후보→같은 세대/순서/시각→왼쪽의 오류 부위 표시가 실제 코칭 검수 화면에서 작동한다. 어깨와 목 오류를 구별하고 근거 없는 초록 성공 표시를 추가하지 않는다.
- 목 영역은 현재 head 표시 추적과 해당 프레임의 귀/어깨 투영이 모두 유효할 때만 칠한다. 가림·낮은 신뢰도·다인·만료·잘못된 stamp/버전·중단/교체에서는 색을 해제한다. 확인 불가 영역에 별도 색은 칠하지 않는다.
- 남녀 원본/시범/사용자와 여덟 가중치·정점/노멀·스키닝 결과를 대조해 색 외 변경이 없음을 실제 GLB로 검사한다. 같은 오류의 연속 입력마다 전체 버퍼를 불필요하게 다시 쓰지 않는다.
- 실제 Chrome/GLB/classifier/engine에 생성 입력을 넣어 목/어깨·해제/복구·좌우 시범 독립·남녀/확대·재개/401을 확인한다. 실제 SDK 빈 가짜 장치 회귀는 양성 판정·사람 정확도 증거와 구분한다.
- 기존 surface/owned/native 단위 테스트와 프런트 전체·원래 타입/notice/build·production 격리·Biome·diff 및 작성자 리뷰를 통과한다. 실패/미실행/원문과 SHA를 보존한다.

## 제외와 남는 기준

임상 band/운동량 기본값·출시 동작/추천 승격·실제 사람 정확도·기록 POST·새 모델 조형/Blender/GLB 덮어쓰기는 하지 않는다. 후보 프로필은 여전히 테스트에서만 주입한다. 표시 영역의 구현을 개별 목 관절 측정/리깅 정확도나 최종 외형 승인으로 바꾸어 말하지 않는다. 기존 Draft150/152·SDK 과거 P2·운영 별도 승인과 전체1~4/1~6 실제 완료 기준을 유지한다.
