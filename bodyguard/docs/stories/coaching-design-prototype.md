# S4.D2 — 승인 디자인의 클릭 가능한 코칭 시안

상태: 독립 HTML 구현·로컬 검증 완료 / CEO 구조 검토 전 · 2026-10-07 · 기반 main `991ed2b`

## 결정과 범위

CEO는 2026-10-07 의료·신체 케어 도구 분위기의 v4 방향을 승인했다. 기존 HTML 전체를 확정 디자인으로 사용하지 않는다. 한 공간에 넓게 떨어진 두 아바타, 절제된 회백색·블루, 부드러운 모서리, 정돈된 한글 도구 배치를 유지한다. 아바타 개별 패널·과도한 알약형 배지·장식 배경·상시 큰 타이머는 사용하지 않는다.

이번 Story는 `design-prototypes/clinical-coaching/`의 독립 HTML 시안만 만든다. 제품 React 라우트·인증·API·판정·카메라·3D 원본·배포를 바꾸지 않는다. 방향 승인은 전체 화면 구조나 제품 적용 범위의 최종 승인이 아니다. CEO에게 클릭 가능한 구조 검토를 받은 뒤 기존 구현 적용 범위를 확정한다.

## 디자인 계약

2026-10-07 추가 결정: [텍스트 최소화 원칙](../coaching-design-decision-20261007.md)을 다음 디자인 수정 때 적용한다. 아바타·현재 행동 중심, 짧은 역할/버튼 이름과 한 가지 교정 안내, 펼쳐 볼 상세 설명을 기본으로 한다. 안전·필수 동의·오류 복구·정적 시안 구분과 접근 가능한 이름은 유지한다. 이 문서 기록은 HTML 변경·구조 승인·재검증 완료가 아니다.

FR-A-01/02/03, FR-S-03/06, FR-V-01, NFR-08. `docs/web-design.md`의 기존 색상·폰트·8/12px 모서리를 우선 재사용하되 시안 범위에서만 전체 공간과 조밀한 도구 배치를 시험한다. 실제 모델 대신 승인 시안의 정적 이미지 영역을 재사용한다. 웹캠에 보이는 범위와 3D 보기 범위는 별개다. 확인되지 않은 하체를 관측 움직임처럼 만들거나 전신 동작의 촬영 조건을 상반신 보기로 우회하지 않는다.

첫 출시 이후 뷰티, 의료 진단/치료, 신규 민감도 설정, 카메라 녹화, 수치 점수는 추가하지 않는다. 전체 시범은 실제 모션 에셋이 없으므로 재생된 것처럼 꾸미지 않는다. hover 미리보기는 실제 에셋 연결 전 정지 화면으로 설명하고, 이번 Story의 카탈로그 완성을 주장하지 않는다.

## 원본 보존과 알려진 한계

- 이전 v1~v4 시안을 덮어쓰지 않는다. 승인 v4 원본을 `assets/approved-reference.png`로 복사해 출처와 hash를 기록한다.
- 내장 이미지 도구의 투명 배치용 변환은 output moderation `sexual`로 실패했다(request `3fdb390e-5032-4a72-a075-5fd2c41ccfb4`). 결과 이미지 없음. 같은 요청 재시도·CLI/API 우회 없음. 대신 기존 승인 이미지의 표시 영역을 HTML/CSS에서 사용한다. 새 Blender 제작·변형 시험 아님.
- 정적 이미지의 빨간 표시·화살표는 검증된 자세 안내로 사용하지 않는다. 원본에 포함된 강조도 정적 배치 예시이며 실제 자세 안내가 아니라고 화면에서 설명한다.
- 최종 아바타·실시간 추적·각 동작 임상 기준·라이선스·성능은 별도 필수 완료 조건으로 남는다.
- 제품의 기존 실패/미실행 검증과 Draft PR9/29/36/51을 통과 처리하지 않는다. 전체1~6단계는 여전히 미완료다.
