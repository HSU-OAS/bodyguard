# S3.A2 같은 공간의 사용자 움직임·단계별 Blender 시범

## 목적과 구현 범위

기존 코칭 공간 오른쪽의 Blender 단계 시범과 왼쪽의 실제 카메라 관찰을 같은 renderer/공간에 연결한다. 기존 시범/입력 확인 버튼과 단계/좌우/구도 제어를 재사용하고 새 메뉴/디자인 개편은 하지 않는다. PR155 sourcefd98deb→merge53ff077의 실제 main 포함·동일 트리·브랜치 보존을 확인했다. PR152의 구현을 참고하되 Draft 자체를 병합/채택하지 않고 최신 main의 bounded 자산 읽기와 stage 수명주기를 유지한다.

- 명시 시범 열기와 명시 카메라 확인/입력 확인 후만 각 자원을 획득한다. 두 모델은 같은 불변 남녀 GLB의 독립8가중치 복제본이다. 왼쪽 사지·몸통은 기존 관찰 rig, 머리·손은 사용자가 요청한 현재 프레임의 표시 기준 맞추기를 사용한다. 올바른 자세/개인 신체 정답의 자동 보정이 아니다.
- CameraPreparation의 동일 복사 슬롯을 촬영 안내/기준 수집과 함께 한 번 소비한다. 추가 카메라/SDK/검출·다른 프레임 혼합·좌표 React state/저장/전송/로그를 만들지 않는다. SDK generation/sequence/at는 바꾸지 않는다. 표시 stage와 카메라의 소유권은 명시적으로 연결·해제한다.
- 새 준비/성별/동작/계정 변경·숨김/종료/오류 뒤 이전 관찰을 재사용하지 않는다. 가림·빈 결과·만료에서 왼쪽을 관찰 중/정답으로 표시하지 않는다. 애니메이션이 왼쪽을 움직이거나 관찰이 오른쪽의 뼈를 움직이면 실패다.
- 오른쪽은 사용자가 선택한 준비·수행·유지·복귀·좌우 단계만 보여준다. 아직 classifier가 없는 상태에서 자동 성공/오류 빨강·타이머·완료 결과/기록을 만들지 않는다. 실제 판정/추천·전체1~4 완성으로 과장하지 않고 이후 같은 핵심 흐름에 연결한다.
- 기존 원본/GLB/전문6action·실패 증거와 최종 외형 기준을 보존한다. 개발 후보는 production에서 제외한다. 실제 참여자/공급자/Docker·운영·안전/개인정보의 별도 승인 경계는 유지한다.

## 하네스·수용 기준

1. 실제 GLB의 독립 복제본에서 관찰과 native animation을 동시에 진행한다. 입력 generation/sequence·가림/만료·명시 머리/손 기준과 재연결, 원본/반대 모델 불변을 unit으로 검증한다. 합성 좌표 시험은 사람/SDK 양성/임상 시험이 아니다.
2. React 소유권 시험은 동일 슬롯 단일 전달, stage 늦은 준비/오류·카메라 중단·성별/동작/계정/언마운트·재시도 경계를 확인한다. 기존 카메라/기준 수집 기능과 시범만 보기 회귀를 유지한다.
3. 실제 Chrome/WebGL에서 두 모델 픽셀 변화·오른쪽 단계·왼쪽 사지/머리/손·가림/복구·800/1440px 전신/확대·숨김/401와 소유 context 종료를 확인한다. 합성 입력과 실제 fake-camera/native SDK 회귀를 따로 기록한다.
4. 원래 SDK5초 경계/정리 ACK와 기존 실패 증거를 유지한다. PR152의 간헐 시작/정리 P2를 같은 통과 blank 시험 반복으로 닫지 않는다. 통합 검증에 P1/P2가 남으면 PR을 Draft로 유지하고 병합하지 않는다.
5. 전체frontend/typecheck/build/Biome·production guard·diff·직접 리뷰가 필수다. 각 실패/미실행을 보존하고 원본/GLB 불변·실행 코드 SHA를 실제 확인한다.

## 남은 완료 조건

이 Story는 실제 관찰과 단계 시범의 연결이다. 올바른 동작 판정/추천·결과/기록 생산과 나머지4종 콘텐츠, 최종 외형/변형/목표 노트북 성능, 원래 SDK P2·참여자/외부/운영 증거 및 전체1~4/1~6 기준은 별도로 남는다. 하나를 구현했다고 나머지 기준을 제외하거나 낮추지 않는다.

## 구현·실제 검증 결과

하나의 renderer/canvas에서 왼쪽 사지/몸통·명시 머리/손 표시와 오른쪽 전문 Blender 단계 시범을 연결했다. 기존 복사 슬롯만 전달하고 세대/시각을 바꾸거나 추가 검출을 시작하지 않는다. 가림/빈 입력/만료·중단/새 세대/성별/동작/계정 변경을 분리하며, 연결 해제 시 보존한 관절 회전을 복원한다. 전신은 같은 공간, 확대는 모델별 무테 crop으로 겹침을 막는다. 실제 사용자 스캔이나 정답 판정은 아니다.

[실제 화면·실패·원본/GLB 보존·검증 구분](../review/shared-coaching-reference/README.md). 생성 좌표/실제 GLB Chrome5흐름과 실제 heavy/face/hands SDK+가짜 장치/3D 연속 입력9흐름을 구분했다. 실제 기본 카메라8·남녀3종 시범만 보기6 회귀도 확인했다. 시각 혼용과 ref 상태 갱신·구도/하네스 문제를 수정하고 초기 실패를 보존했다.

필수 전체 회귀/정적/build/guard·직접 리뷰와 PR 게이트를 진행한다. 원래 PR150/152의 미해결 P2와 Draft 병합 금지·전체1~4/1~6 미완료는 유지한다. 다음은 검증 근거를 가진 동작 판정/추천과 교정 시범 적응·결과 생산을 이 흐름에 연결하는 작업이다.
