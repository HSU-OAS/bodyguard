# S2.T17 — 단계에 반응하는 비공개 시범 재생

Status: 구현 전 계약·하네스 작성 / 단계 완료 아님

## 목적·범위

S2.T16 이후 최신 main에서 시작한다. 사용자의 관찰 리그와 별개인 시범 모델에,
전문 도구의 관절별 position/quaternion/scale 애니메이션을 재생한다.
시범은 waiting-start → seeking-target → holding → waiting-return에 맞추어
준비 → 수행 → 유지 → 복귀 클립으로 바뀐다. 동일 상태 전달은 재시작하지 않는다.
현재 보이는 자세에서 다음 클립으로 부드럽게 이어지며, 일시정지·관측 만료·종료에는
시간을 더하지 않는다. 애니메이션은 판정, 기록, 타이머, 성공, 반복 횟수를 생성하지 않는다.

화면·메뉴의 추가 확장이나 확정 디자인 변경은 없다. 텍스트 최소화 결정에 맞추어
시범 자체로 안내하는 내부 기반이다. 기존 A37 원본·GLB·외형·검증은 보존한다.
이 Story의 합성/제작 테스트 클립은 올바른 스트레칭 또는 출시용 시범이 아니다.

## 명시 계약

- 입력 program은 motionId/version, 중복 없는 stepId 목록, 각 단계의 AnimationClip,
  전환 시간과 입력 유효 시간을 명시한다. 임상 각도·시간의 기본값을 만들지 않는다.
- 관절 트랙은 해당 시범 모델에 실제 바인딩된 유일한 Bone의 local TRS만 허용한다.
  루트·재질·사용자 데이터·다른 모델의 경로나 모호한 관절은 거부한다.
- 데이터·클립 배열은 비동기 로더 전에 복사하며, private sampler는 독립적인 Bone만
  사용한다. 원본, 관찰 모델, geometry/weights, 다른 소유자를 변경하지 않는다.
- AnimationMixer는 private sampler에서만 작동한다. 재생 중 모든 관절의 TRS를
  검증한 뒤 한 번에 적용한다. 이전 자세에서 전환하며 빠진 트랙은 원본 rest를 사용한다.
- cue는 generation/증가하는 sequence/원본 at/motionId/version/stepId/status/phase를
  갖는다. 현재 소유권·정체성과 맞는 명령만 반영한다. 잘못된 현재 명령은 정지하며,
  오래된 세대·중복 입력은 현재 정상 동작을 덮어쓰지 않는다.
- 일시정지·입력 만료 뒤 첫 재개 프레임은 정지한 기간을 더하지 않는다. 클립은
  LoopOnce 및 마지막 자세 고정이며 자동 무한 반복하지 않는다.
- 종료/abort/해제 뒤 입력을 받지 않고 클립·sampler 참조를 정리한다. pair 옵션을
  사용하지 않는 기존 호출과 리소스 해제 계약은 유지한다.
- SDK·웹캠·개인 관절 입력·계정·API·DB·운영·공개 UI·출시 판정 변경 없음.
  program은 신뢰된 로컬 제작 코드/GLTFLoader 클립용이며 임의 실행 플러그인용 아님.

## 수용·검증 하네스

1. 실행 가능한 단위 계약을 먼저 작성하고 미구현 RED를 원본 그대로 기록한다.
2. 실제 Three 리그에서 네 단계 전환, 반복 cue, 부드러운 중간/종단, pause/resume,
   만료·시간 역행, 중복/다른 세대, 미등록 동작·단계·트랙, 복사/독립성, 종료를 검증한다.
3. 실제 순수 coaching progression의 합성 입력이 시범 단계만 바꾸는지 검증한다.
   이 입력은 임상 판정/실측이 아니며 verifiedMs 성공을 애니메이션에서 만들지 않는다.
4. 실제 Chrome/WebGL에서 변경하지 않은 남녀 A37을 로드하고 관절별 클립의
   전환·정지·독립성·전신 프레이밍·8 weights·해제를 확인한다. 합성 또는 별도
   제작한 비출시 클립과 실제 화면 증거를 구분한다. 카메라 호출/외부 요청은 0이어야 한다.
5. 전체 FE test/types/check/assets/build/공개 번들 유출 guard/diff를 실제 실행한다.
   실패와 이전 번들을 보존한다. PR diff·최신 main·충돌·체크를 읽고 author review를 한다.

## 제외·이월

전문가 검토 가능한 올바른 시범 데이터, 사용자 신체와 정확한 대응, 반응형 오류 강조,
최종 외형 승인·원본 재제작·GLB 변형 검수, 실제 캠/참여자·성능·SDK egress,
승인된 공개 레이아웃과 최종 세로 흐름은 D2 후속 조건으로 남는다.
0 qualified release motions를 유지한다. 이 Story 통과는 2단계/1~6단계 완료가 아니다.
