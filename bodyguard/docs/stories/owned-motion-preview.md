# S3.P1 — 선택용 동작 미리보기의 단일 소유 재생기

상태: 재생기·비공개 실제 브라우저 검증 완료, PR 게이트 진행. 공개 선택 화면 연결과 3단계 전체 완료는 아님. 최신 `origin/main` 85885c4에서 독립 `codex/owned-motion-preview` 브랜치로 시작.

## 목적과 경계

텍스트 설명 대신 사용자가 아바타의 움직임으로 동작을 알아보도록 한다. 이번 Story는 향후 승인된 스트레칭 선택 화면에 연결할 **재생·입력·자원 수명 계약**만 구현한다. 새 공개 화면이나 메뉴 구조를 확장하지 않는다. 기존 HTML 시안, 임상 동작 허용 목록, 카메라·계정·기록·안전 판정은 변경하지 않는다.

기존 Blender 제작 시험 클립과 보존 GLB를 사용하는 비공개 브라우저 하네스로 실제 움직임을 확인한다. 시험 클립은 올바른 스트레칭이나 출시 콘텐츠가 아니고, 모델 역시 최종 외형이 아니다. 동일 아바타 부위의 제작·검증 사이클을 재시작하지 않는다.

## 수용 기준 / 하네스 계약

1. 선택된 하나의 미리보기만 소유한다. 포인터 진입 또는 키보드 초점으로 재생한다. 초점이 남아 있으면 포인터 이탈만으로 중단하지 않는다.
2. 이탈·초점 해제·숨김·선택 변경·제거 시 RAF를 취소한다. 정상 중단에서는 시작 자세를 그린 후 자원을 해제한다. 중단된 자산의 늦은 로드 결과는 그리지 않고 정확히 한 번 해제한다.
3. 동작 감소 설정에서는 자동 재생하지 않는다. 명시적 재생 조작만 허용한다. 숨김 중에는 명시적 조작도 재생하지 않는다.
4. 동시 로드는 최대 하나다. 취소된 로드가 정리될 때까지 다음 로드를 기다린다. 취소 신호와 세대 격리로 이전 동작이 새 선택을 덮어쓰지 못한다.
5. 원본 시험 클립을 정방향·역방향으로 샘플링한다. 시간 역행·비정상 값, 로드·렌더·취소·정리 실패는 고정 오류 상태로 처리한다. 원시 오류 문자열을 사용자 상태에 노출하지 않는다. 정리 실패 후 재시도하지 않는다.
6. 제거는 진행 중인 로드의 정리까지 기다리는 장벽이다. 재사용/다른 소유자의 자산은 인수하거나 해제하지 않는다.
7. 결정적 단위 테스트로 입력 조합, 늦은 로드, 전환, 오류, 재시도, 시간, 반복 제거를 검증한다. 실제 Chrome에서 보존 남녀 GLB·Blender 시험 동작을 로드해 WebGL 움직임, 정지, 키보드·동작 감소·자원 해제를 확인한다. 모의 시험과 실제 브라우저 시험을 구분한다.
8. 원본 GLB·시험 클립 해시 및 공개 빌드 전후 바이트를 비교한다. 새 재생기는 공개 진입점에 연결하지 않는다. 카메라나 외부 서비스 접근·데이터 업로드는 하지 않는다.

## 완료 증거 / 제외

검증 결과는 `docs/review/owned-motion-preview/`에 기록한다. 실패한 최초 결과와 재실행 결과를 모두 보존한다. 단위 테스트 성공만으로 실제 GLB 검증 완료라고 기록하지 않는다.

공개 선택 화면 연결은 디자인 구조 승인과 동작·아바타 출시 게이트 충족 후 별도 Story다. 전체 2단계 외형·실측·통합 이월 목록, PR #101 시작 지연 P2, 실제 참여자·목표 노트북·HTTPS 운영 검증은 이 Story로 완료되지 않는다. 출시 후보판 선언은 하지 않는다.
