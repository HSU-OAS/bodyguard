# S3.C2 — 목 판정 후보의 두 아바타·진행·결과 화면 연결

2026-10-16 · 최신 main `5b03763`에서 시작. 임상 기준 확정이나 출시 동작 승격이 아니라, S3.C1의 실제 분류기를 기존 웹 화면/소유 자원에 연결하는 개발 검수 Story다.

## 범위와 수용 기준

- 기존 흰색 공용 공간·좌우 역할·전신/상반신/확대 구도를 유지한다. 별도 카메라 준비 화면과 실행 화면을 동시에 가동하지 않는다.
- 명시 구성과 네 가지 gate가 없으면 시작하지 않는다. 각도·유지 시간 기본값, 사용자 자세를 정답으로 삼는 자동 보정은 추가하지 않는다. 수학 fixture는 테스트에서만 공급한다.
- 한 소유 cohort의 카메라/Worker/소스/실제 Blender 시범·사용자 복사본을 사용한다. 같은 원래 세대·순서·시각의 입력을 분류기→기존 진행 엔진→시범에 전달한다.
- 오른쪽은 현재 좌우/단계를 재생하며 같은 동작을 무한 반복하지 않는다. 오류에는 준비 또는 목표 단계의 기존 제작 시범으로 돌아간다. 새 의학적 교정 동작을 지어내지 않는다.
- 준비/수행/유지/복귀와 일시정지·명시 재개, 종료·불편 시 중단, 완료/중단 결과를 화면에서 확인한다. 가림/만료가 유지 시간으로 누적되지 않는다.
- 개발 후보 결과는 실제 운동 기록으로 저장하지 않는다. 계정 회수·숨김·종료·교체 시 기존 소유권/정리 장벽을 유지하고 자동 카메라 재시작은 금지한다.

## 검증

DOM에서 실제 버튼과 소유 세션의 상태 전이를 검사하고, 실제 Chrome/React/WebGL/자체 GLB에 생성 관절을 넣어 좌우 단계·오류·빈 입력·중단·재개·결과 화면을 검사한다. 원래 frontend 전체 테스트·타입/notice/build·Biome·production 격리·diff 검사와 실제 diff 리뷰를 수행한다. 실패 증거를 보존한다.

## 제외·남은 기준

정답 각도/운동량·실제 사람 정확도·추천 출시·최종 아바타 외형/성능·세밀한 목 표면 착색·기존 SDK 간헐 P2는 완료가 아니다. 후보 화면을 공개 제품에 적용하거나 합성/모의 저장을 실제 코칭 기록으로 표시하지 않는다. 이 Story만으로 1~4 또는 1~6 완료를 선언하지 않는다. Docker/공급자/참여자 및 운영 별도 승인 경계를 유지한다.

## 구현 결과

`NeckCoachingRun`과 한 소유 cohort의 native 연결을 구현했다. 기본 route는 미검증 구성을 공급하지 않는다. [실제 화면·실패 보존·명령/소스 증거](../review/neck-coaching-workspace/README.md)에 연결한다. 후보 오류는 문구로만 표시하고 기존 제작 클립의 단계에 반응한다. 정확한 목 부위 surface coloring이나 실제 임상 프로필의 제공을 이번 범위의 구현으로 주장하지 않는다. 기존 원본/GLB·Draft/실패를 보존했다.
