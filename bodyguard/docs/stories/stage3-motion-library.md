# S3.3 — 근거 기반 동작 검수 목록 확장

로컬 구현·검증 완료 / PR 게이트 대기 · FR-S-01/06 · main 2535198

## 명세와 디자인

기존 개발 전용/로그인 보호 목록·검색·부위 필터·상세·출처·주의점·복귀를 여러 동작으로 확장한다. 기존 토큰·목록 배치·버튼을 재사용하며 상세에 코칭 후보/안내만 후보와 관찰 한계를 표시한다. 출시 목록에는 넣지 않고 코칭 버튼은 비활성 유지한다.

자료 재확인: CUH chin retraction, AAOS crossover arm stretch p1, Leeds lateral muscles stretch p4, Kingston and Richmond trunk stretch를 2026-10-05 원문으로 확인했다. 숫자 처방은 제품 정답값으로 옮기지 않는다. Oxford PDF는 두 차례 접근 실패하여 어깨 으쓱 후보의 신규 콘텐츠 적용을 보류한다. 팔 위로 뻗기는 원문 관련 문단 재확인이 남아 있다. 원안 W는 제외 유지.

## 하네스와 완료 기준

- 5개 목록(기존 목 옆 기울이기 포함), 부위/검색 및 각 상세·복귀.
- 안내만 후보는 정면 확인 한계와 타이머/성공 판정 없음이 명확함.
- 각 항목 ID·출처·주의점·불변 데이터, W/뷰티 제외, 무검증 각도·초·횟수 없음.
- production에 신규 후보/안내 UI가 포함되지 않음.
- 전체 Vitest·Biome·build/typecheck·production 차단 및 실제 Chrome 목록/상세 시험. 합성 계정과 실제 수행은 구분.

이 Story는 동작 수를 5개로 출시 확정하는 것이 아니다. 자료 접근/실측·규칙·시범 애니메이션은 미완료이며 전체 3단계 게이트는 유지한다.

## 실제 결과

개발 목록은 목2·어깨1·상체2이며, 각 상세와 필터/복귀가 작동한다. 출시 목록은0개로 유지하고 신규 후보는 production 번들에서 제외했다.

Vitest215개/18파일, Biome67파일, build/typecheck, production 문자열 차단, 최종 실제 Chrome7흐름 통과. 계정은 mock, 카메라0·외부 자산 요청0·브라우저 저장0. 실제 사람 수행·추천·판정·시범 검증은 미실행.

실패 기록: 최초 단위 시험은 기존 목 검색 결과1개 가정이 깨져 실패, 정규화된/분해된 검색 결과의 동일성을 검사하도록 수정했다. 브라우저 첫 실행은 Chrome 초기화 beforeEach 시간 초과로 실패(나머지6 통과), 두 번째는 계정 확인 상태가 둘 있는 시점에 포괄 status locator를 사용해 실패(나머지6 통과). 화면 로딩 완료 heading을 기다리도록 고친 뒤 전체7 통과. 시간 제한을 늘리거나 실패를 skip하지 않았다.
