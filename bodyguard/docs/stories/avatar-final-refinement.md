# S2.A2 최종 통합 아바타 보완

2026-10-12 · 시작 main `285e289d3f9906ab674a591deae700de3123f79c` · `codex/avatar-final-refinement` · FR-A-02/03/08

CEO가 아바타 제작 보류를 해제했다. 기존 Draft108/원본/미채택 후보/실패는 보존하고 별도 편집 원본에서 얼굴–목–어깨 연결을 보완한다. 최신 참조는 Draft108의 `reference/ceo-reference.png`(SHA256 `45b313912dee5ae2218b1fe76086abb35a9b948fab9e877f1a9d2b05f832de62`)다. 여성 의상 없이 남녀 공통 매끈한 백색·중립 신체 표현과 체형/관절 구조를 유지한다. 단순 primitive 인체/AI 정적 이미지를 최종 3D로 대체하지 않는다.

## 구현 전 계약과 검증

1. 전문 제작 메시의 기존 목 접합 결함을 실제 이미지/원본에서 확인한다. 동일 smooth 수치 반복이 아니라 필요한 연결/위상을 Blender native 도구로 보완한다. 원본은 불변, 수정 후보는 새 경로에만 저장한다.
2. 손/발/전신·성별 체형·몸통/어깨 구조는 유지한다. 목을 매끈하게 보이게 하려고 필요한 움직임/뼈/가중치 자유도를 줄이지 않는다. 위상 변경이 필요하면 명시한 국소 구간만 편집하고 skin 전송/정규화·연속성/닫힘/유한값을 검증한다. 기존 ID/토폴로지 exact 보호가 새로운 접합 저작 자체를 막는 조건으로 사용돼서는 안 되며, 바뀐 구간과 새 검증을 명시한다.
3. 같은 PBR 재질/조명/카메라의 정면·측면·3/4·뒤 목·좌/우 목 변형·어깨 올림/팔 올림/교차/몸통 회전에서 실제 렌더를 직접 확인한다. 흐림/유리한 조명으로 결함을 감추지 않는다. 기술 변형 각도는 운동 처방/정답이 아니다.
4. 독립 `.blend` 재열기, GLB export/import, 전체 기존 리그 변형, 실제 Chrome의 두 독립 skeleton/관찰 업데이트·원본 불변·8가중치·자원 회수를 재실행한다. 실제 사람 정확도와 합성 움직임을 구분한다.
5. 외형·리깅 P2가 남으면 실패/미채택으로 보존한다. 후보를 공개 웹/최종 모델로 적용하지 않고 전체1~6 완료로 선언하지 않는다. 비용·새 에셋 계약/계정·시크릿·운영/배포/출시는 제외한다.

## 현재

Blender MCP 연결은 실패했고 설치된 Blender5.1.1의 격리 background 실행을 사용했다. 남녀 실제 접힘 core의 native 국소 위상 보완은 통과했다. 이후 마감 후보들은 실제 렌더에서 평가하며 **뒤 목/어깨 마감의 외형 P2는 아직 미해결·미채택**이다. [원본·실제 화면·실패·검증](../review/avatar-final-refinement/README.md)에 최신 상태를 기록한다. 이 PR은 Draft로 보존하며 병합/제품 적용/아바타 완성/전체1~6 완료로 표시하지 않는다.
