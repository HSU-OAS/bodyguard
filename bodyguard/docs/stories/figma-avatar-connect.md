# 피그마 코칭 검수에서 내 움직임 연결

## 범위·수용 기준

- 개발용 코칭 화면에서 기존 시범 후보가 준비되면 `카메라로 내 움직임 연결`을 제공한다. 사용자가 이 버튼을 직접 누른 뒤에만 기존 카메라 준비와 연속 입력을 순서대로 시작한다. 초기 렌더·동작 선택만으로는 카메라를 켜지 않는다.
- 기존 `카메라 확인`과 별도의 `입력 확인` 절차는 유지한다. 카메라 권한·브라우저 안 처리·기존 소유 세대와 오류 처리·정리 조건은 바꾸지 않는다.
- 준비 중 취소, 계정 변경·화면 이탈, 보이지 않는 탭, 시범 닫기나 교체가 발생하면 이전 요청은 늦게 움직임을 시작하지 않는다. 정리 실패 상태는 재시작하지 않는다.
- 개발 검수 화면에서만 사용하며 촬영 입력·합성 프레임을 정확한 자세 판정이나 출시 승인으로 취급하지 않는다. 개인 정보 저장·운영 배포·실제 참여자·아바타 조형은 범위 밖이다.

## 검증

React 합성 상태 시험에서 명시 동작 전 카메라·연속 입력 호출 0, 준비 완료 후 관찰, 준비 중 취소, 화면 이탈과 시범 교체의 늦은 응답 차단을 확인했다. 실제 Chrome·MediaPipe SDK와 **가짜 카메라**를 이용한 `scripts/test-figma-avatar-connect.mjs`에서는 버튼을 누르기 전 카메라 호출 0, 한 번의 명시 동작 후 연속 입력 상태, 종료 후 트랙 정지 및 외부 요청 0을 확인했다. 실제 사람 추종·정확도·실제 권한 거부 화면은 검증하지 않았다.

프런트 전체 129개 파일·2,163개 테스트, TypeScript·Biome·빌드와 개발 전용 코칭 코드의 공개 번들 제외 검사를 통과했다. 새 브라우저 시험은 실행 Chrome 경로를 명시한다: `node scripts/test-figma-avatar-connect.mjs '<Chrome 절대 경로>'`. 카메라·모델 자산과 Node 24, 설치된 테스트 의존성이 필요하다.
