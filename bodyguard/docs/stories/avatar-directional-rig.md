# S2.T1 — 관찰된 사지 방향의 실제 리그 연결

상태: 비공개 리그 연결·최종 로컬 검증 통과 / PR 게이트 진행 / baseline `979f5e639877d69e4a7e9bfec7edb98edbbb01d2` / `codex/avatar-rig-driver`

FR-A-01/03·FR-M-07·NFR-07/08에 따라 실제 Blender 유래 남녀 GLB의 독립된 두 리그에 서로 다른 관찰 방향을 전달한다. 공개 화면·디자인 구조·판정·카메라·SDK·계정·운영은 변경하지 않는다. 기존 외형 후보와 실패 증거는 보존하고 **외형 수정/동일 부위 조형 사이클은 시작하지 않는다.** 출시용 아바타나 올바른 운동 시범으로 채택하지 않는다.

## 수용 기준

1. 명시한 bone→descendant anchor만 사용한다. 기존 rest local transform·가중치·체형·관절 길이는 보존한다. 부모의 회전과 glTF 이름 정규화에 의존하지 않고 실제 계층의 world 방향을 local 회전으로 변환한다. 연결 불가·중복·0/음수 배율·비유한 변환은 준비 실패다. 양수 비균일 배율은 전체 affine inverse로 정확히 지원한다(아래 실제 GLB 발견).
2. image/world가 같은 관측 프레임이어야 한다. 기존 가시성·화면 범위 기준으로 shoulder→elbow, elbow→wrist, hip→knee, knee→ankle만 전달한다. world의 미러 변환을 명시한다. 누락·NaN·무한·길이0은 그 방향을 만들지 않는다. 축 비틀림·목/체간·손·실제 체형 복원을 추정하지 않는다.
3. 세대·단조 timestamp/sequence·수명·명시 유효기간이 맞는 프레임만 사용한다. 불완전 프레임은 이전 관측과 합치지 않는다. 빠진 방향/만료/종료는 마지막 렌더 회전을 동결하고 유효 추적에 포함하지 않는다. 중립 또는 시범 정답으로 자동 보정하지 않는다. 이 상태는 측정·교정·통과 판정이 아니다.
4. 표시용 반감기를 명시하고 frame-rate 독립 slerp를 적용한다. 새 프레임 수신과 GPU 렌더를 분리한다. 정지/close는 멱등이며 외부 소유 원본/다른 리그를 수정·해제하지 않는다. 프레임/좌표를 로그·저장·서버로 보내지 않는다.
5. 결정적 Three.js 수학·계층·가림·수명 하네스와 실제 Chrome/GLTFLoader/남녀 GLB 렌더에서 두 skeleton 독립성·서로 다른 관절 방향·원본 불변·전체 전신 배치를 확인한다. 관측 입력은 합성이다. 실제 웹캠 정확도·운동 정답·외형·노트북 목표 성능 통과로 확대하지 않는다.
6. 공개 build는 새 driver/GLB/probe를 포함하지 않는다. 필수 로컬 검증·작성자 리뷰·최신 diff/충돌/체크를 확인한 뒤 사전 승인 Git 규칙으로 PR을 진행한다. D2-A/M/T/I/P 및 전체1~6 완료 기준은 유지한다.

## 하네스

- 단위: 회전한 부모/rest 축·chain anchor·누락/잘못된 입력·시간 역행/세대·close/abort·반감기·두 리그 분리·bone position/scale 불변.
- 통합: immutable PR9 source `25a9bd6c7392890e3b5d5d6ae1046bb7087d56ad`의 기존 A37 GLB만 임시 추출. 남녀 각각 GLTFLoader 실제 파싱·8-weight mesh와 driver, browser WebGL 렌더/방향/원본 hash. GLB는 이번 PR/공개 bundle에 복제하지 않는다.
- 회귀: 기존 frontend unit·타입·Biome·build·production guard. API 변경0이므로 backend 재실행을 새 증거로 주장하지 않는다.

## 남은 필수 통합

단일 방향은 축 비틀림을 결정하지 못한다. 몸통/쇄골/목의 분산 회전, 손가락, 카메라 좌표계·관찰 오차·지연의 실제 사람 검증, 검증된 시범 단계와 적색 피드백, D2-A 외형·원본/GLB/변형 재검증은 후속이다. 이 Story의 합성 방향 검사는 이 항목들을 대신하지 않는다. 기존 디자인 구조/제품 적용·SDK privacy·외부/운영 승인도 유지한다.

## 실행 중 확인

첫 실제 Chrome은 A37의 root scale `[1, 0.9999999403953552, 0.9999961256980896]`에서 준비 실패했다. 새 GLB를 만들거나 배율을 정규화하거나 허용 오차를 늘리지 않는다. 양수 비균일 배율의 결정적 시험을 먼저 실패시킨 뒤, 회전 분해 대신 부모 전체 역행렬을 사용하도록 수정한다. 실제 transform·bone 길이는 그대로이며 품질 기준 완화가 아니다. 최초 수집 실패는 0개 실행, 첫 unit 실행6통과/4실패는 Quaternion 내부 callback 비교 및 부동소수 기대값의 하네스 오류로 구분·보존한다.

최종 실제 Chrome 남녀2흐름은 서로 다른 사지 방향·독립 뼈대·source 불변·여덟 가중치·전신 정점 투영·동작 후 구도/close를 통과했다. runtime commit `05fbf02`에서 실행했고 현재 source SHA도 대조했다. 표시용 보간의 합성 오차를 실제 사람의 자세 정확도로 주장하지 않는다. 전체 frontend792·타입/Biome·원래 준비/빌드 순서·공개 guard 통과, 공개 JS/CSS는 PR63과 byte 동일·공개 GLB0이다. [실제 화면·실패·원본 보존·작성자 리뷰](../review/avatar-directional-rig/README.md). 그림 안의 모델은 **미완성 A37**이고 디자인 승인/외형 수정 완료가 아니다.

코드 리뷰로 cloned skeleton GPU texture 해제/멱등 dispose를 보완하고 source 비해제 회귀를 통과했다. 초기 발끝 잘림을 정점 투영 RED로 재현한 뒤 검수용 직교 카메라만 수정했다. 공개 guard는 생성된 누출 sentinel을 실제 exit1로 차단했으며 제거 후 exit0이다. 해당 sentinel은 이번 작업에서 만든 임시 검증 파일이다. 기존 후보 worktree의 삭제 상태1959개는 변경하지 않았고 Git blob1959개를 실제 확인했다. 원본 Blender·GLB·기존 증거와 PR9 source는 유지한다.

API/SQL·Gmail/Google·실제 카메라/참여자·목/체간/손·검증된 시범/피드백·목표 노트북 성능·전체1~6은 이번 검증이 아니다. 공개 제품에는 아직 연결하지 않는다. 다음 통합은 관찰 가능한 몸통/목·손의 별도 근거/좌표계 검증과 검증된 시범·피드백 연결이며 기존 별도 승인·완료 기준은 유지한다.
