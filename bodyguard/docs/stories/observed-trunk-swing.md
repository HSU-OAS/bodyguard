# S2.T22 — 관찰된 몸통 방향 연결

2026-10-08 · D2-T 보완 · 비공개 런타임 통합

## 범위

같은 단일 pose 결과의 양 어깨11/12·골반23/24가 현재 화면 안에서 관찰될 때, 두 중점 사이 방향을 사용자 아바타의 spine05→neck01 축에 연결한다. 기존 GLB의 실제 계층을 확인해 지정한다. 이는 몸통의 **집계 방향 표시 후보**이지 개별 척추·골반 회전·비틀림·신체 이동 거리 측정이 아니다. 골반/root와 중간 척추의 저작된 local 회전·길이는 그대로 유지한다.

기존 기본 호출은 사지8개를 유지하며, owned pair/native adapter의 명시적 trunk=true 호출만 추가한다. 사용자 모델만 움직이고 시범·원본은 변경하지 않는다. 같은 세대·sequence·원래 capture 시각과 부모 먼저/full affine inverse·보간을 기존 방향 리그에서 사용한다. 추가 센서/SDK·시크릿·운영·의료 임계값·공개 화면/문구·조형/Blender/GLB 수정은 없다.

## 수용 기준·하네스

- 합성 좌표의 옆/앞 기울기와 mirror 방향을 실제 리그 축에 전달한다. 부모가 움직인 뒤 사지의 세계 방향도 유지한다.
- 네 필수 관절 중 하나라도 가림/화면 밖/비정상/누락이면 몸통 coverage는 즉시 제거하고 이전 값을 정답으로 재사용하지 않는다. 몸통 누락이 유효한 사지를 막지는 않는다.
- 단일 image/world33개가 아니거나 세대/순서/시간이 잘못되면 기존 경계를 유지한다. 복사 이후 원시 배열 변경·재진입·종료가 이전 관찰을 되살리지 않는다.
- 골반/root·중간 척추 local 회전, 모든 position/scale, 원본/비교 모델과 여덟 skin 가중치를 보존한다. 머리/손 옵션의 기존 회귀를 실행한다.
- owned pair/native 옵션은 await 이전 복사·엄격한 boolean 확인·bound bone 검사·취소 정리 경계를 유지한다.
- 단위 회귀와 설치된 Chrome의 실제 남녀 GLB/WebGL에서 옆/앞 기울기→가림→복구→만료→종료를 실행한다. 생성 관찰을 실제 사람/native 양성 검증으로 표시하지 않는다.
- 전체 FE·Biome·tsc·production build/guard·diff 확인. 공개 JS/CSS byte와 GLB 불변 확인. 실패 원본과 실제 실행 증거 보존.

## 근거·완료 경계

[MediaPipe 공식 결과 설명](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker/web_js)은 image/world 좌표와 골반 중점 원점을 설명한다(2026-10-08 확인). 이를 실제 해부학적 정확도 보장으로 해석하지 않는다. 추가 수치 임계값/성공/타이머 판정을 만들지 않는다.

3→4→5→6의 독립 구현 이후 이월 D2-T의 비공개 통합이다. 같은 부위 새 조형 사이클을 시작하지 않는다. 시작 P2·실제 사람/촬영 조건·최종 외형/권리·승인 공개 구조·운영 및 전체1~6 게이트는 그대로 미완료다. 최소 텍스트·기존 파일/실패와 사전/별도 승인 규칙 유지.
