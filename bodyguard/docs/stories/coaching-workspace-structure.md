# S4.D6 — 코칭 공간·동작 선택의 React 구조 적용

2026-10-11 CEO가 코칭 화면·동작 선택 구조의 로컬 구현·검증·PR을 승인했다. SDK PR126의 merge `5d12491`을 확인하고 최신 main에서 별도 `codex/coaching-workspace-structure`로 시작한다.

## 디자인·기능 계약

- 노트북 웹, 기존 화이트/블루 토큰과 한글 폰트·16px 본문·8px 간격 단위·8/12/16px 모서리를 재사용한다. 별도 디자인 시스템·패키지·장식 배경·진단 수치·큰 타이머는 추가하지 않는다. web-design-studio를 적용한다.
- 넓은 하나의 공간: 왼쪽 내 움직임 / 오른쪽 현재 단계 시범. 개별 아바타 카드/테두리 없음, 충분한 중앙 간격. 전신/상반신/자세히는 표시 구도만 바꾸며 촬영 판정을 통과시키지 않는다.
- 왼쪽 짧은 주 메뉴, 상단 구도/동작 변경/설정, 하단 시작·시범·나가기. 동작 선택은 검색·부위 필터·시각 미리보기 영역이 있는 대화상자다. 기존 안내/근거/주의점과 검색·필터 복귀는 유지한다.
- 미리보기 컴포넌트는 검증된 미디어가 있을 때 hover/키보드 focus와 명시 재생·정지를 지원한다. 이탈·숨김·소스 변경·unmount에서 정지하고 reduced-motion에서는 자동 재생하지 않는다. 현재 연결 가능한 검증 미디어는 없으므로 없는 동작 이미지를 만들거나 한 포즈를 여러 동작으로 표시하지 않는다.
- 아바타 보류 중이므로 새 GLB·렌더·외형/변형 검증 없이 scene 연결 대기를 정직하게 표시한다. 개발/로그인 보호 라우트에서 구조만 검수한다. 출시 적격0, 실제 시작/판정/시범/타이머/저장/카메라 권한 호출은 활성화하지 않는다. 빈 두 영역을 실제 두 아바타 기능 완료로 세지 않는다.
- 설명은 접고 현재 동작/짧은 필수 상태와 조작만 상시 표시한다. 실제 기능과 구조 검수 구분·안전 안내는 숨기지 않는다. 뷰티·미용 또는 다른 미승인 화면은 확장하지 않는다.

## 수용 기준·하네스

1. 실제 React 라우트에서 동작 선택→구도 전환→설정→동작 변경→수행 안내→돌아가기/나가기, 검색 빈 상태/초기화/없는 ID 복구가 동작한다.
2. 대화상자 이름·초기 초점·Escape·초점 복귀·키보드 조작, 좌우 순서 유지·좁은 웹/확대·reduced motion, 로그인 미확인/실패/로그아웃 시 보호를 확인한다.
3. unit의 media 제어는 합성 포트임을 표시한다. 실제 Chrome의 화면/조작 시험은 카메라/SDK/GLB·원시 좌표 없이 수행한다. 실제 인증/SQL과 제어 익명/회원 응답을 구분한다.
4. 전체 frontend·타입·범위 Biome·원래 build/고지/private guard·diff와 작성자 리뷰를 통과한다. 미완성 코칭 구조가 공개 production bundle/route에 들어가지 않아야 한다.

## 제외·완료 경계

범위 안의 기존 UI 연결만 변경한다. 아바타 원본/증거·이전 HTML은 보존한다. 임상·판정·시작 지연P2·참여자/공급자·운영/배포·전체1~6 기준은 미완료다. 비용0, 운영 변경0. 실패하면 이 UI 목적의 변경만 되돌리며 기존 기능/에셋은 보존한다. 구조 적용 뒤 검증된 scene/동작 미디어 연결은 보류 해제 및 실측 완료 의존성이다.

## 실행 결과

실제 React의 선택/상세→코칭 구조→구도·설정·동작 변경→안내/나가기와 검색·필터 복귀를 구현했다. [실제 화면·검증/실패·작성자 리뷰](../review/coaching-workspace-structure/README.md)를 남긴다. 빈 scene/카드 미디어를 아바타나 움직이는 동작 완료로 세지 않는다. 기존 조건부 PR 게이트를 적용하며 전체 출시 조건은 그대로다.
