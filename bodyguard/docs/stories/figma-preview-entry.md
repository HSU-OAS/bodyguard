# Figma 홈을 공개 검수본 진입 화면으로 연결

상태: 로컬 구현·검증 및 승인된 공개 검수본 배포 완료 · 2026-11-12

## 문제와 설계 계약

CEO가 기존 공개 URL이 Figma와 다르다고 지적했다. 기존 URL은 별도의 웹캠 검수 화면으로, Figma 홈과 연결되지 않았다. 승인된 Figma 프레임 21:4의 화이트·블루, 좌측 서비스 메뉴·중앙 정지 시안·우측 동작 목록 구조를 재사용한다. 새 디자인 체계·제품 기능·회원 데이터를 만들지 않는다.

## 수용 기준

- 공개 검수 빌드의 첫 화면에서 실제 Figma 홈 컴포넌트를 사용한다. 제품의 DEV·로그인·코칭 판정 게이트는 변경하지 않는다.
- 1440×960에서 좌측 x40/y150/264×620, 우측 x1010/y150/390×620 배치와 기존 Figma 이미지·SVG를 확인한다.
- 원래 Figma 동작 그림을 보여주고, 연결된 후보 세 가지는 호버 또는 키보드로 기존 Blender 영상을 재생한다. 준비되지 않은 동작·계정·기록은 활성 기능으로 꾸미지 않는다.
- 선택 뒤 웹캠 체험으로 이동하며, 선택한 동작명과 적합한 보기 범위를 전달한다. 우측 기준 아바타는 중립 자세이며 완성된 동작별 코칭·판정을 제공하는 것으로 주장하지 않는다.
- 패널 접기·펼치기·1024px 창·키보드 포커스·모션 감소와 실패 복구를 검수한다. 영상·좌표 저장·전송은 추가하지 않는다.
- 기존 성능 보완을 포함한 실제 SDK·Worker·WebGL 시작/추종/종료를 가상 카메라로 확인한다. 실제 사용자 정확도 검증과 구분한다.
- 새 공개 번들의 React·React DOM·React Router 라이선스 원문을 동봉한다.

## 제외

계정·기록 API 연결, 신체 분석/추천의 출시 승인, 검증되지 않은 동작별 성공 판정, 새 아바타 제작·적용, 실카메라 시험과 배포는 이 Story의 완료 주장이 아니다. Pages 교체는 별도 승인 후 진행한다. 이전 공개본은 성공 실행 41945822637 / b80f6408이며 문제 시 해당 기존 실행의 재실행으로 복구한다.
