# S3.4 — 보류 동작의 근거 재확인·검수 목록 연결

2026-10-08 · 로컬 구현·검증 완료 / 조건부 PR 게이트 · FR-S-01/06 · 기준 main7516c641

## 목적·범위

S3.3에서 자료 접근 실패/관련 문단 미확인으로 적용하지 못한 기존 후보 #3 어깨 으쓱·이완과 #6 팔 위로 뻗기를 재확인한다. 이미 있는 로그인 보호 개발 목록의 검색·필터·상세·복귀에만 연결한다. 새 공개 화면이나 코칭 가능 목록을 만들지 않는다.

원문은 실제로 열어 해당 문단과 환자 교육 문맥을 확인한다. 출처의 숫자 처방·약물/질환 안내·다른 동작을 제품 정답으로 옮기지 않는다. 원문 이미지/PDF를 복제하지 않고 수행법을 짧게 바꾸어 적는다.

## 수용 기준·하네스 (구현 전)

- 검수 목록 7개: 기존5 + 어깨 으쓱·이완 + 팔 위로 뻗기. W 원안·뷰티는 제외 유지.
- 어깨는 양쪽을 부드럽게 올리고 편하게 내리는 과정. 머리·양 어깨·몸통 촬영 조건을 적되 웹캠으로 힘·통증·깊이를 알 수 있다고 주장하지 않는다.
- 팔 올림은 원문의 **한 팔씩 번갈아**/바르게 앉음/편안한 범위/복귀 변형만 반영한다. 뒤로 손 뻗기나 동시에 양팔을 강하게 올리는 지시를 섞지 않는다.
- 두 항목 모두 pending-validation. 실시간 후보는 검증 계획일 뿐이며 자동 교정·성공·타이머/카메라 시작은 없다. 실제 적합성/임계값/오판정·시범 검증은 미완료 유지.
- 순수 데이터 시험: ID·출처·불변성·검색/부위 필터·수행/주의/관찰 한계·숫자/효과 주장 금지.
- 실제 Chrome: 각 상세/참고 자료/비활성 시작/Back·키보드, guest/계정 오류, production 경로와 신규 문자열 제외. mock 계정·카메라0와 실제 사람 검증을 구분한다.
- 전체 FE 시험·타입·Biome·build/production guard·git diff --check. API는 변경하지 않는다.

## 제외·완료하지 않은 것

공개 UI 구조/디자인 적용·동작별 3D 미리보기/시범·새 조형/Blender/GLB·classifier/각도/시간·동작 출시·외부 계정/비용/시크릿/운영 DB/배포/출시. 최소 텍스트·안전/개인정보 경계·원본/실패 증거를 유지한다. 원문 도달은 수행 설명의 확인이지 실제 코칭 정확도나 일반인 적합성 인증이 아니다.

PR85는 실제 merge7516c641로 main에 포함됐고 [결과 기록](https://github.com/HSU-OAS/bodyguard/pull/85#issuecomment-6058364965)을 확인했다. 시작 지연 P2와 전체1~6단계 미완료는 그대로다.

## 실제 결과

검수 목록7개와 두 항목의 검색/필터·수행 안내/출처·복귀가 실제 Chrome에서 작동한다. 전체10브라우저 흐름/1179 FE·타입/Biome250/build/guard 통과. 계정mock·실제 카메라/사람/판정0, 출시 적격0이며 공개JS/CSS는 PR85와 동일하다.

pnpm launcher 실패와 구현 전 RED5실패/7통과를 보존했다. 실제 bin으로 단위 시험을 수행했고 정책/timeout/skip 변경 없이 최종 통과했다. guest/production 후보 부재와 source 불변성 검사를 보완하고 재검증했다. [실제 화면·원본/실패·리뷰·남은 조건](../review/motion-source-recovery/README.md).
