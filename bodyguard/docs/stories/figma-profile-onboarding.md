# Figma 가입 후 기본 정보 화면

Figma `AUTH-02`(21:3)의 384px 중앙 폼, 청색 브랜드·주요 버튼, 나이·키·몸무게 단위와 성별 선택을 기존 React 화면에 적용한다. 기존 계정 관리 화면의 저장·삭제 기능은 유지한다.

## 범위와 기준

- 이메일 가입 확인 뒤 선택형 기본 정보를 작성하고 `다음`을 누르면 저장이 확인된 뒤 기존의 안전한 목적지로 이동한다. `나중에 하기`는 값을 저장하지 않고 이동한다.
- 항목은 기존처럼 모두 선택 사항이다. 오류·계정 교체·저장 결과 불확실·동시 수정 시 자동 진행하거나 임의로 덮어쓰지 않는다. 이 변경은 수집 항목·API·DB·외부 전송 정책을 늘리지 않는다.
- 계정에서 다시 여는 기본 정보 화면은 수정·전체 삭제·충돌 방지 안내를 유지한다. 가상 계정·모의 API를 사용하며 실제 사용자 정보를 사용하지 않는다.
- 공개된 GitHub Pages 검수 시제품, 아바타 제작·코칭, 운영 DB·배포는 변경하지 않는다.

## 검증 기록

Figma 원본 맥락과 렌더를 확인하고, 로컬 브라우저에서 가상 계정·모의 API로 기본 정보 입력 후 다음 화면 진입을 확인했다. 이 시험은 실제 메일·운영 DB·실사용자 검증이 아니다. 변경 전용 단위 시험에서 가입 후 건너뛰기, 저장 후 이동, 저장 실패 시 이동 중단, 계정별 조회·수정·삭제와 오류 복구를 확인했다.

최초 전체 프런트 테스트는 빌드와 브라우저 서버를 동시에 실행하는 중 기존 코칭 화면 로딩 테스트 한 건의 시간 내 렌더를 확인하지 못해 실패했다. 실제 실패로 기록하며 원인은 확정하지 않는다. 서버를 종료하고 동시 실행 수를 2로 낮춰 다시 실행한 결과 전체 129개 파일·2,150개 테스트가 통과했다. 변경된 파일 Biome·TypeScript·빌드·공개 번들 검사는 통과했다. 실제 Figma 스크린샷과 로컬 데스크톱 화면은 비교했으며 좁은 화면의 실제 브라우저·외부 접근성 감사는 실행하지 않았다.
