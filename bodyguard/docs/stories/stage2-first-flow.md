기본 실행은 표 순서다. S2.3 관찰 준비와 S2.4 조형은 독립적으로 준비 가능하지만 시범 확정·코칭 공개는 실측에 의존한다. 외부 계정 연결 대기 중에도 합의 범위의 독립 작업을 진행한다. 새 Story는 사전 승인 규칙에 따라 최신 main의 새 codex/* 브랜치에서 시작하며, 중요한 범위·안전·개인정보 변경과 운영/외부 계정 작업은 별도 승인을 받는다.

공통 게이트를 먼저 고정하고 S2.1·S2.2를 시작 직전에 상세화했다. 이후 상세 명세·실행형 하네스도 이전 결과를 반영해 해당 Story 시작 직전에 작성한다. 한 PR에 2단계 전체를 넣지 않는다.

## 화면 계약

| 화면 | 버튼·기능 | 상태·예외 |
|---|---|---|
| 공개 시작 | 로그인·가입, 소개·공개 미리보기 | 카메라 없음. WIP 모델을 완성 제품처럼 광고하지 않음 |
| 계정 | 이메일/비밀번호, 코드·재발송, 로그인·구글·재설정 | 입력/전송/성공/만료/재시도/요청 제한. 미구현 버튼을 작동하는 것처럼 표시하지 않음 |
| 보호된 시작 | 직접 고르기·추천 입구·로그아웃 | 세션 확인 중 개인 UI 먼저 노출 금지. 추천은 3단계 연결 전 시작 불가 |
| 동작 상세·준비 | 수행 과정·주의점·출처, 남녀 외형, 시작·뒤로 | 해당 동작의 필수 관절만 요구. 세션/자산 확인 후 사용자가 시작해야 카메라 요청 |
| 코칭 | 기준 동작 / 내 움직임, 수행 단계·핵심 수정 안내·일시정지·중단 | 촬영 안내 우선. 영상·디버그·확인 불가 색 없음. 불확실한 자세의 성공/오류를 지어내지 않음 |
| 결과 | 완료/중단/건너뜀, 수행 요약·다시 선택 | 미수행 구간을 완료·효과로 만들지 않음. 기록 목록은 4단계 |

내비게이션은 시작·동작 선택·계정 상태 중심이다. 추천·기록·설정 등 출시 필수 기능은 삭제하지 않되 미완성 페이지를 가짜 차트/결과로 채우지 않는다. 목적 복귀는 내부 허용 경로만 사용한다.

## 공통 하네스·통과 기준

| 게이트 | 검증 | 반드시 막을 것 |
|---|---|---|
| 인증 | 실제 API/DB, 만료·위조·다른 계정·CSRF, 화면 직접 진입 | 오류 때 개인 기능을 게스트에게 여는 폴백 |
| 동작 | 순수 TS 시간 포함 재생 + 실제 사람 관찰 | 가림/화면 밖/복수 인물/추론 정지/대상 변경/자산 실패의 성공·타이머 누적 |
| 프레이밍 | 상반신/전신/어깨 가림/얼굴 누락/조명·사선 | 더 많이 보이는 것을 오류로 처리하거나, 필요한 부위 누락을 성공 처리 |
| 카메라 | 늦은 권한 응답·play 실패·시작 중 취소·재시작·이탈·세션 만료 | 뒤늦은 스트림 누수, 지난 프레임/응답으로 상태 부활 |
| 아바타 | 남녀 정면/측면/3/4·좌우 시작/진행/복귀·관절 확대·GLB 재가져오기·두 화면 | 참조 품질 부족, 침투/찢김, 좌우/거울 반전, 루프 끊김 |
| 성능 | 실제 장치·브라우저·전원·모델·두 아바타 조건 | 인식 15fps·피드백 1초 기존 목표 미달, 평균값으로 끊김·지연 숨기기 |
| 개인정보·접근성 | 요청/로그/저장소, 키보드·레이블·초점·읽기 순서 | 영상/좌표 유출, production 테스트 우회, 핵심 접근성 누락 |

S2.3a에서 landmarker.ts를 numPoses: 2로 설정하고 복수 추정 결과를 즉시 무효화한다. 이 설정과 합성 시험은 실제 두 사람 배제·대상 전환을 입증하지 못한다. S2.3b에서 실제 복수 포즈/대상 전환과 성능을 함께 검증한다. 아바타의 세밀한 보간은 세밀한 측정 증거가 아니다.

목은 손으로 당기지 않는 자료 기반 변형을 먼저 시험한다. 사진의 손–머리 접촉을 동작 정답으로 복사하지 않는다. 통증은 자기보고로 중단하며 카메라가 통증·압력을 검출한다고 주장하지 않는다.

## 단계 종료와 권한

화면 시연·테스트 실행 결과·Blender/GLB/권리·실측표·수정·남은 위험을 묶어 제시한다. 지금 표는 **검증 계약이지 통과 기록이 아니다**. 일반 사용자/다장치 회귀·HTTPS 배포·보안·운영 준비는 5~6단계에 남는다.

Gmail/Google 계정·시크릿·실제 외부 발송, 서버·운영 DB·배포·비용은 CEO 별도 승인 후 작업한다. 연결이 없으면 실제 연결 시험은 미검증으로 남기고 S2.7 통과를 요청하지 않는다.
