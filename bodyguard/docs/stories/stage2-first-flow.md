## 단계 종료와 권한

화면 시연·테스트 실행 결과·Blender/GLB/권리·실측표·수정·남은 위험을 묶어 제시한다. 지금 표는 **검증 계약이지 통과 기록이 아니다**. 일반 사용자/다장치 회귀·HTTPS 배포·보안·운영 준비는 5~6단계에 남는다.

Gmail/Google 계정·시크릿·실제 외부 발송, 서버·운영 DB·배포·비용은 CEO 별도 승인 후 작업한다. 연결이 없으면 실제 연결 시험은 미검증으로 남기고 S2.7 통과를 요청하지 않는다.
