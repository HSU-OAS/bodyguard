# 선택형 기본 정보

CEO는 2026-11-05 Figma 기본 정보의 선택 입력·계정 저장을 승인했다. 이 Story는 로컬 구현·검증과 코드 병합까지이며 운영 DB 적용과 배포는 별도 승인이다.

## 사용자 계약

- 닉네임·나이·키·몸무게·성별은 모두 선택 사항이다. 입력한 값만 보관하며 비워 둔 항목 없이도 계속할 수 있다.
- 본인이 계정 화면에서 각 항목을 수정·삭제하거나 전체 기본 정보를 삭제할 수 있다. 회원 탈퇴 시 계정과 함께 삭제한다.
- 데이터는 해당 계정의 프로필 관리에만 사용한다. 현재 자세 판정·진단·추천에 사용하거나 외부 서비스에 전송하지 않는다.
- 나이는 입력 시점의 값이며 자동으로 생년월일을 추정하지 않는다. 성별의 선택 안 함은 저장하지 않은 상태다. 입력값 전체를 삭제해도 충돌 방지용 계정별 수정 번호는 탈퇴 시까지 유지된다.

## 구현·검증 계약

- 인증된 계정에서만 조회·저장·삭제하며 요청 시 세션과 계정 일치를 확인한다. 수정 충돌은 조용히 덮어쓰지 않고 다시 조회하도록 한다.
- 데이터베이스에는 계정 소유 프로필만 저장한다. 회원 탈퇴의 기존 계정 삭제 트랜잭션에서 연쇄 삭제한다. 원본 영상·관절 좌표는 수집하지 않는다.
- 마이그레이션은 새 파일만 추가하고 격리 시험 DB에서 적용한다. 운영 적용·롤백은 별도 백업과 승인 후 진행한다. 데이터가 있는 프로필 테이블은 자동 롤백으로 삭제하지 않는다.
- 두 가상 계정의 조회·수정·삭제 격리, CSRF·계정 교체, 잘못된 값, 충돌·재시도, 회원 탈퇴 시 연쇄 삭제를 실제 격리 PostgreSQL에서 검증한다.
- 화면은 저장 전·저장 중·완료·오류·재조회·빈 값과 키보드 사용을 확인한다. 실제 사람의 개인정보나 외부 공급자는 시험에 사용하지 않는다.

- 합성 계정으로 웹 화면에서 기본 정보를 저장하고 새로고침해 읽은 뒤 전체 삭제하고 다시 조회했다. 브라우저와 실제 로컬 API, 격리 PostgreSQL을 연결한 시험이며 실제 사용자 정보는 사용하지 않았다.
- 가입 인증 후 선택형 정보로 이동하고 건너뛰는 흐름, 두 계정 간 격리, 계정 전환 시 응답 폐기, 실패 후 재조회와 충돌, 탈퇴 시 삭제를 확인했다.
