# S2.M4 — 관찰자 촬영 범위 대조

2026-10-09 · 구현 전 계약 작성 후 제한된 구현·로컬 검증 통과 · 선행 main 6791e5d / S2.3a·S2.M1~3

근거: FR-M-02·07, FR-S-01, ADR-0003·0012, S2.3b. 기존 `/dev/measure`의 수동 상황 기록에는 독립 관찰자 라벨과 튜닝/별도 촬영 구분이 없다. 실제 참여자 검증을 준비하는 개발 도구만 보완한다. 공개 디자인·제품 판정·시범·리깅을 바꾸지 않는다.

## 범위와 화면 계약

- 기존 상황 선택·현재 프레임 기록·최신100개 메모리 요약·지우기·측정 취소를 유지한다. 라벨 미선택 튜닝 기록은 기존대로 가능하다.
- 추가 선택은 `판단 보류 / 필수 부위 충분 / 필수 부위 부족 / 복수 인물`. 수행 상황 이름은 정답 라벨이 아니다. 기록 후 라벨을 보류로 되돌려 다음 관찰을 명시적으로 입력한다.
- 관찰자 라벨과 알고리즘의 범위 결과를 나란히 표시한다. 충분/부족은 현재 선택한 머리·어깨 또는 전신의 필수 관절에 한정한다. 자세의 옳음·안전·통증·성공을 뜻하지 않는다.
- 비교 가능한 튜닝 기록이 있어야 `튜닝 마치고 검증 시작`을 활성화한다. 관찰자는 튜닝에 사용하지 않은 촬영 조건임을 확인한다. 이는 사람의 확인이며 도구가 새로운 조건·독립성·다른 사람을 검증했다는 뜻이 아니다.
- 검증 시작 시 모델·촬영 범위·FPS·손/얼굴 설정과 튜닝 대조 집계를 동결한다. 새 프레임만 별도 검증에 기록하며 같은 프레임을 반복 라벨링해 표본을 늘리지 않는다. 설정을 바꿨다 되돌려도 지우기 전에는 검증을 재개하지 못한다.
- 실제 관찰 전에는 관찰자/수행자 분리·촬영 조건·동의·안전 안내가 별도로 필요하다. 이 Story의 합성 시험으로 S2.3b를 통과하지 않는다.

도구는 좌표·각도·영상·관찰자/참여자 식별자·자유 입력을 기록/다운로드/전송하지 않는다. 선택지·필수 관절 개수·범위 범주·임시 프레임 시각/설정만 브라우저 메모리에 둔다. 프레임 시각은 중복 방지용이고 사람/장치 독립성 증거가 아니다. 기존1초·관절 신뢰값은 시제품 관찰 조건이며 출시 임계값으로 승격하지 않는다.
