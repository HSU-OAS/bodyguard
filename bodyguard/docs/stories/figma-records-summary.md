# 기록 화면 전체 기간 합계

Figma 기록 화면에서 선택한 기간의 기록 건수와 관찰 시간 합계를 모든 페이지에 걸쳐 표시한다. 합계는 완료 여부나 자세 정확도를 나타내지 않는다.

- 기록 목록 API에서 사용자·기간 조건을 적용한 건수와 관찰 시간 합계를 목록과 같은 SQL 조회 시점으로 반환한다. 빈 페이지도 같은 합계를 반환한다.
- 기존 서버가 두 합계 필드를 모두 반환하지 않으면 전체 목록이 첫 페이지에 들어온 경우에만 그 목록을 합산한다. 잘못되거나 불일치하는 합계는 오류로 처리한다.
- 계정 소유권, 기록 삭제, 페이지 범위와 영상·좌표 비저장 정책은 바꾸지 않는다. 스키마 마이그레이션은 없다.
- 격리 PostgreSQL의 가상 기록으로 23건, 페이지별 합계, 기간 경계, 빈 페이지와 계정 분리를 검증한다. 브라우저에서도 가상 계정·기록으로 실제 API와 시험 DB를 연결한다.
- 실제 사용자·운영 DB·인증 메일·배포에 대한 검증은 이 Story의 결과에 포함하지 않는다.
