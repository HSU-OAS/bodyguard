# S2.1 — 계정·세션 하네스 계약

2026-10-01 · **구현 전 / 아래 검증 전부 미실행**. [상세 Story](stage2-account-api.md), [단계 게이트](stage2-first-flow.md).

실행형 하네스가 검사할 계약이다. API/DB는 아직 없으며 표나 기존 프런트 테스트로 계정 검증을 통과 처리하지 않는다. 구현 PR에서 하네스의 실제 실패(red)와 구현 후 통과(green) 증거를 남긴다.

## 실행 장치

- pytest + 실제 FastAPI TestClient·PostgreSQL 18 격리 테스트 DB. 시간/난수/메일만 fixture로 통제하고 인증 의존성을 성공 stub으로 바꾸지 않는다. [FastAPI 공식 테스트](https://fastapi.tiangolo.com/tutorial/testing/).
- 메일 fixture는 메모리 outbox·발송 실패만 재현. 공개 outbox API·production 가짜 발송·관리자 우회 없음. 자료는 가상 주소/비밀번호.
- 시간은 fixture clock을 경계값으로 이동. SQL 경쟁은 PostgreSQL 독립 연결로 검증. sleep으로 만료를 기다리거나 동시성을 생략하지 않음.
- 테스트 DB 접속 정보·식별자 확인 후 준비. 운영/일반 URL drop/reset 금지. 사용자 DB나 개발 폴더를 포괄적으로 삭제하지 않음.
