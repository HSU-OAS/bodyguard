# 출시 아바타 제작 계약 — 1단계

[A39b 목 재구성/실제 재검수](../assets/blender/review/candidate-a39b/README.md)는 원본/GLB 각각118개·Chrome3개를 통과했지만 실제 목 기울임/뒤 목 외형 결함이 남아 채택하지 않았다. 개발 기본 모델 A37·외형 P2·아래 제작/완료/승인 계약은 그대로이며 이전 A39 GLB 실패 원본과 증거도 보존했다.

별도 A38 국소 표면 정제·원본/GLB 각각118개·Chrome3개와 동일 조건 A37 비교를 실제 실행했다. [원본·미리보기·실패/미실행](../assets/blender/review/candidate-a38/README.md). 국소 수치는 개선됐지만 뒤 목·전완/최종 외형은 미달이라 A38은 채택하지 않았다. **개발 기본 모델 A37/외형 P2와 아래 제작 계약·승인·완료 기준은 그대로다.**

상태: 2026-10-01 S2.4 진행 중. **현재 A37 작업 원본/웹 후보는 승인된 출시 아바타가 아니다.** CEO의 무의상 백색 중성 마네킹 변경을 별도 후보에 반영하고 신체 좌표/가중치·각163bones 보존, 원본/여덟 가중치 왕복 각각118개·121행, 실제 개발 기본 연결 Chrome3개를 검증했다. 전체 외형 P2는 남아 있다. [상세 Story](stories/stage2-avatar-candidate.md)·[현재 검수/실제 미리보기](../assets/blender/review/candidate-a37/README.md)·[이전 A27](../assets/blender/review/web-eight-weight/README.md)·[네 가중치 실패](../assets/blender/review/web-candidate/README.md)를 구분한다. 아래 초기 제작 기록과 기존 원본/GLB/증거는 보존했다. 실제 운동 예시·사람 추적·노트북 웹캠 통합 성능은 미검증이며 [출시 계획](release-plan.md)의 2단계 전에 검증한다.

## 시각 목표와 금지선

**2026-10-01 CEO 변경이 여성 참조의 의상 요구보다 우선한다.** 남녀 모두 별도 의상 없는 매끈한 백색 중성 마네킹 표면으로 제작한다. 여성 자연 곡선·관절을 유지하고 유두·생식기의 사실적 세부, 의상 경계·허리선·옷단은 제거한다. 남녀 재질·마감을 통일하며 필요한 신체 구조·리그·변형 정확도는 낮추지 않는다. A36 실행/증거를 마무리한 다음 안전한 후보 A37에 반영했다. 이전 원본·의상 검사·반려 증거는 역사 기록으로 보존한다. 의상이 없는 후보의 의상 침투 검사는 적용 대상 없음으로 명시하되 전신/관절118개·가중치/위상·왕복·실제 웹·외형 기준은 유지한다. 별도 무의상/동일 재질 검사도 실제 실행했다.

CEO가 제공한 여성·남성 4분할 이미지(정면 중립, 정면 목 기울임, 3/4 전신, 목·어깨 확대)가 **시각 기준**이다. 남녀 모두 얼굴 요소 없는 매끈한 머리, 무광에 가까운 따뜻한 백색 신체, 해부학적으로 납득 가능한 체간·어깨·목·팔·다리 비례, 손·발의 자연스러운 실루엣, 관절 경계의 절제된 표현을 갖춘다. 성별 선택은 외형 선택이지 판정 규칙의 성별 차별화가 아니다.

- 기준·사용자 아바타는 **같은 품질의 모델**을 쓴다. 둘을 나란히 띄워도 피부/머리/관절 묘사가 빈약해지면 미통과.
- 목 기울임 확대에서 머리·목·승모근·쇄골·어깨 연결이 매끄러워야 한다. 목이 막대처럼 회전하거나 어깨가 침투·찢어지면 미통과.
- 어깨 올림, 팔 위로 올림, 팔 교차, 몸통 회전 등은 리그에 필요한 회전 자유도를 확보한다. **뼈 개수 자체는 품질 보증이 아니다.** 운동별 가중치·실루엣·관절 충돌을 장면으로 검수한다.
- 가시성 낮은 관절의 움직임은 화면에서 부드럽게 보간할 수 있지만 이를 측정·성공 판정의 근거로 사용하지 않는다. 카메라가 못 본 부위에 별도 ‘확인 불가’ 색을 칠하지 않는다.
- 실제 사진처럼 보이는 정적 렌더만으로 통과하지 않는다. 목표 브라우저에서 두 아바타가 움직일 때의 형태·프레임 안정성·로딩 실패 복구가 통과 대상이다.

## Blender 제작 순서와 검수 컷

1. **베이스 점검**: Blender에서 남녀 별 메시·리그·가중치·shape key·제3자 에셋을 조사한다. 기존 MPFB 원본은 비례와 리그 출발점일 뿐, 그대로 내보내지 않는다.
2. **조형**: 참조 이미지에 맞춰 얼굴 특징 제거, 머리/목/쇄골/흉곽/어깨/손의 실루엣 정제, 관절 경계·재질을 조형한다. 정면·측면·3/4 중립 및 목·어깨 확대에서 비교한다. 단순 구·원기둥 코드 조합으로 대체하지 않는다.
3. **리깅·애니메이션**: 남녀의 동일한 동작 이름·단계(`시작 → 진행 → 목표 → 복귀`)를 유지한다. 동작별 근거가 확정된 뒤에만 올바른 시범 포즈를 만들며, 목은 한 덩어리 머리 회전으로 끝내지 않고 목/쇄골/어깨 변형을 확인한다.
4. **웹 내보내기**: Blender 원본 `.blend`를 추적하고 GLB로 최적화한다. 재질·스킨 가중치·애니메이션·모델 파일 크기를 비교하며, 웹에서 두 모델 동시 재생을 실제 노트북으로 측정한다. 내보내기 결과를 다시 가져와 실루엣과 동작이 유지되는지 확인한다.

현재 조형 원본은 남성 **95,962개 base vertex**, 여성 **93,746개**다. 머리 표면을 정리한 조형용 메시이며 두 개 동시 표시에는 그대로 보내지 않는다. 별도 웹용 메시를 만들어 목·손·관절 실루엣을 보존하면서 정점 수·GLB 크기·로딩 시간·프레임을 실측해 결정한다. 지금 수치만으로 웹 성능 합격을 주장하지 않는다.

검수 컷은 여성/남성 각각 `정면 중립`, `측면 중립`, `3/4 중립`, `#1 좌·우 목 기울임(시작/최대 편안한 범위/복귀)`, `어깨 관절 확대`, `웹 두 아바타 동시 재생`이다. 각 컷에 `참조와의 차이`, `메시 침투/찢김`, `과장된 신체 비례`, `프레임/지연`을 기록한다. 사진의 포즈는 디자인 참고일 뿐 올바른 운동 범위나 손의 압력을 정하는 의학 근거로 사용하지 않는다.

## 현재 원본 점검과 권리

2026-09-30 Blender 5.1.1에서 이전 MPFB 시제품(남녀 각 19,158 vertices·리그 각 163 bones·액션 0개)을 검사했다. 얼굴 특징과 약한 신체 조형이 참조에 맞지 않아 **조형 베이스로 탈락**시켰다. 현재 작업 원본은 [Blender Foundation의 CC0 Human Base Meshes v1.4.1](https://www.blender.org/download/demo-files/)의 남녀 realistic body와 전문 제작 head 에셋을 가져와 얼굴 요소를 없애고 목 연결을 조형한 것이다. 몸통 전체를 voxel remesh하면 디테일이 손상돼, 머리·상부 목만 표면 정리했다. 단순 코드 기반 인체 생성이 아니다.

MPFB의 core 리그·가중치를 전송해 각각 **163 bones·139 deform weight groups**를 연결했다. [공식 라이선스](https://static.makehumancommunity.org/about/license.html)에 따라 core assets CC0와 플러그인 소스 GPL/AGPL을 구분한다. 기존 donor 원본은 변경하지 않았고, 현재 `.blend`에는 남녀 메시·리그·재질·패킹한 참조가 들어 있어 외부 donor 없이 편집·검수할 수 있다. 이후 추가하는 피부·의복·텍스처·모션 에셋은 **각각** 출처와 웹 재배포 권리를 확인한다. 제3자 에셋 미확인 상태에서는 배포하지 않는다.

이전 목 시험의 판정을 정정한다. [남성](../assets/blender/review/rig-local-axis-error-male-neck.png)·[여성](../assets/blender/review/rig-local-axis-error-female-neck.png)의 잘못된 시험은 목 뼈의 **local Y(뼈 길이 방향)**를 회전해 옆 기울임이 아니라 비틀림을 만들었다. 따라서 ‘기울기가 부족하므로 리그 탈락’이라는 결론은 유효하지 않다. 현재 하네스는 장면 Y축을 각 뼈의 rest frame으로 변환하며, head 변화가 그 축을 따른다는 것을 수치로 확인한다. 자동 전송을 최종 채택한 것은 아니며 운동별 축·가중치·변형 검수가 남아 있다.

## 현재 검수 결과와 남은 차이

[이전 시제품](../assets/blender/review/mpfb-rejected-front.png) → [조형 전 베이스](../assets/blender/review/sculpt-base-front.png) → [현재 정면](../assets/blender/review/faceless-front.png)·[3/4](../assets/blender/review/faceless-quarter.png)를 비교한다. 얼굴 요소 제거와 머리·목 연결은 진행됐지만 참조처럼 완성된 외형이라고 판단하지 않는다.

| 검수 | 현재 증거 | 아직 통과하지 않은 것 |
|---|---|---|
| 메시·가중치 | 남녀 각 연결 성분 1개, non-manifold edge 0개, 가중치 합 미달/초과 정점 0개 | 위상 수치만으로 침투·해부학적 정확성을 보증하지 않음 |
| 목 확대 | 좌우 각각 [남성](../assets/blender/review/faceless-neck-male-left.png)·[여성](../assets/blender/review/faceless-neck-female-left.png) 렌더, four-bone FK 회전축 검사 | 목 표면·쇄골 변형 정제, 실제 시작·진행·복귀 애니메이션 |

하네스의 `20°`는 **기술적 변형 시험**이다. 사용자에게 목표 각도로 안내하거나 유지 타이머의 성공 기준으로 사용하지 않는다. 동작 근거·촬영 검증 전에는 올바른 시범 애니메이션으로 배포하지 않는다. 수치 검사는 원본 base mesh에 적용하며 실제 변형은 검수 렌더를 함께 확인한다.

## 1단계 종료 전에 남길 증거

- 수정 가능한 Blender 작업 원본과 사용 에셋 목록. 시제품 원본을 이름만 바꾼 파일은 제작 완료로 간주하지 않음.
- 참조 이미지와 남녀 정면·측면·3/4 스크린샷 대조, 수정 필요 항목.
- #1 첫 동작의 시범 포즈 제작 전 별도 동작 근거·촬영 Story 결과를 확인한다. 두 Story는 독립 PR이며 상대 Story가 `main`에 병합되면 링크·동작을 재검증한다.
- 실제 노트북 성능 측정은 다음 단계. 사전 수치만으로 합격 처리하지 않음.

현재 Story는 위의 **제작 착수 증거**를 로컬에 준비했다. [원본과 재현 방법](../assets/blender/README.md)에 반복 검수 명령, 출처·버전·권리를 기록했다. 이 기록은 로컬 구현·검증 기준이며 PR·병합·단계 통과와 최종 외형 승인은 별도로 진행한다. 2단계나 출시 완료로 표시하지 않는다.
