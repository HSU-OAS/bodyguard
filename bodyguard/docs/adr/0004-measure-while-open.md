# ADR-0004. 웹을 켜 둔 동안만 재고, 가려진 탭에서는 1초 간격으로 잰다

상태: 확정 (2026-09-26), 가려진 탭 측정은 M-1 검증 전 · 근거: 원문 30, 31

## 맥락
작업 중 알림이 이 서비스의 핵심이다. 그런데 작업하는 동안 Bodyguard 탭은 다른 창 뒤에 있다.
크롬은 가려진 탭의 화면 갱신을 멈추고 타이머를 늦춘다.
한편 사용자는 카메라가 계속 켜져 있으면 무거울 것 같다고 했다(원문 30).

## 결정
- 페이지가 열려 있는 동안만 측정한다. 닫으면 끝난다. 상주 프로그램이나 확장 프로그램은 만들지 않는다
- 탭이 가려지면 약 1초에 한 번으로 줄여 계속 잰다
- 브라우저가 막으면 가려진 동안은 멈추고, 다시 보이면 잰다

## 근거
- 사용자가 직접 골랐다 (원문 30, 31)
- 보일 때 15fps, 가려지면 1fps라 부담이 크게 준다

## 결과
- M-1 실험 결과를 아래에 적는다 (방식 a·b·c, design §4.3)
- 폴백으로 가면 가려진 동안 자세 이탈 알림은 오지 않는다. 오래 앉음 알림은 시간만 세서 유지한다 (design §7.3)
