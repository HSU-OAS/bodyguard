# ADR-0019 — 첫 출시 핵심 흐름과 후속 부가 기능

2026-10-11 · 상태: CEO 확정 · 담당: CTO

## 결정과 근거

CEO는 기존 기록 화면의 기능 연결에 **“기존 기록 화면 연결 진행 승인”**, 네 부가 기능의 출시 후 이월에 **“네 부가 기능은 출시 후로 이월”**로 답했다. 빠른 첫 출시를 위해 핵심 경험을 유지하고 비용·별도 검증이 필요한 부가 기능은 다음 출시로 옮긴다.

| 첫 출시 유지 | 출시 후로 이월 |
|---|---|
| 신체 확인과 추천, 직접 선택, 고품질 남녀 두 아바타의 세밀한 코칭 | 자세 알림(이탈·착석)과 해당 알림 전달/연결 |
| 로그인·회원가입·계정 복구, 수행/자세 기록과 일·주 집계 | PDF 리포트 |
| 데이터 관리·삭제·탈퇴, 오류/빈 상태·접근성·개인정보·운영 | LLM 리포트 요약, 변화 탐지 |

## 구현 경계

기존 기록 화면에 일·주 전환·날짜 선택·실제 저장된 기록 집계·빈 기록·오류·재조회를 연결한다. 새 메뉴·대규모 디자인 개편·배포는 이 승인에 포함하지 않는다. 현재 저장 데이터는 client-reported 기록이며 집계를 의료 판단·건강 점수·검증된 코칭 효과로 표시하지 않는다.

원래 요구·후속 세부 설계·기존 코드/설정·Draft PR #51·이전 파일과 실패/검증 증거는 보존한다. 후속 기능을 삭제하거나 구현/검증 완료로 표시하지 않는다. 이미 있는 알림 설정 화면/저장 API를 이 문서만으로 제거하거나 활성화하지 않는다.

## 유지되는 필수 조건

뷰티·미용은 출시 후다. 아바타·참여자·Docker·공식 라이선스 문의·실제 Gmail/OAuth 공급자 연결 보류는 유지한다. 신체/추천/판정의 실측, 최종 원본/GLB/변형/브라우저/외형·권리, 전체 흐름·실제 HTTPS/운영·안전·개인정보 게이트는 모두 남는다. 별도 운영·비용·계정·시크릿·배포·출시 승인도 그대로다. 이 네 부가 기능 이외의 1~6단계 품질 기준을 낮추지 않는다.

## 검증

이번 결정 기록은 제품 기능의 동작 시험이 아니다. 최신 승인 원문·첫 출시/후속 매핑·Q-32 정리·문서 링크·금지 파일/제품 변경 없음·diff를 점검한다. 기존 데이터/원본/실패 증거 보존과 로컬·원격 PR 조건부 병합을 확인한다. 사용자 기록 화면의 구현·SQL/브라우저·접근성 검증은 다음 별도 Story에서 한다.
