# ADR-0003. 서버에는 1분 요약만 저장한다

상태: 확정 (2026-09-26) · 근거: 원문 34

## 맥락
과목 PRD와 기존 README는 "관절 좌표·각도값을 시간축으로 서버에 적재"라고 적었다.
좌표를 저장하면 계산식이 바뀌어도 다시 계산할 수 있다. 대신 몸 형태 데이터가 서버에 남는다.

## 결정
- 브라우저에서 좌표를 지표로 바꾼 뒤 버린다
- 서버에는 1분마다 지표별 평균 편차·이탈 시간·측정 시간, 그리고 스트레칭·알림 기록만 올린다

## 근거
- 대시보드(일·주), 변화 탐지(일 단위), 리포트는 1분 단위면 충분하다
- 초 단위보다 데이터가 60배 적다
- 서버에 몸 형태 데이터가 없으니 유출돼도 피해가 작다

## 결과
- **계산식을 바꾸면 과거 기록을 다시 계산할 수 없다.** 요약에 `client_version`을 남겨 구분한다
- 과목 PRD·README의 "좌표·각도값 적재" 문구와 달라졌다. 과목 문서는 사람이 고친다
- DB 스키마에 좌표 컬럼을 두지 않는다
