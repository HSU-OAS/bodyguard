# ADR-0018. 첫 출시에는 Blender 제작 남녀 3D 아바타 두 개를 쓴다

상태: 출시 범위 확정 (2026-09-29 CEO 결정) · 모델·리타게팅 세부와 동작별 촬영 가능성은 검증 중

## 맥락

ADR-0009의 스켈레톤 → 정적 마네킹은 빠른 기술 실험 순서였다. 현재 MPFB·스켈레톤 시제품은 CEO가 제시한 남녀 참조 이미지의 출시 품질에 미치지 못한다. 단일 노트북 웹캠으로 세밀한 움직임을 보이되, 카메라가 확인하지 못한 관절을 정확한 자세로 판정하면 안 된다.

## 결정

- Blender에서 참조 이미지 스타일의 얼굴 없는 흰색 남녀 모델, 관절 리그, 동작 애니메이션을 새로 제작한다. 기준 동작 아바타와 내 움직임 아바타를 나란히 표시한다
- 기준 동작은 출처·수행 과정·주의점을 확인한 뒤 시작·진행·목표·복귀까지 애니메이션으로 만든다
- 사용자 아바타는 관찰 가능한 관절만 따라간다. 부드러운 화면 보간은 판정 근거로 사용하지 않는다
- 필수 관절이 가려지거나 프레임 밖이면 성공·타이머를 멈춘다. 확인 불가 부위에 별도 색을 칠하지 않고 촬영 위치를 안내한다
- 출시에 필요한 모델 로드가 실패하면 스켈레톤으로 코칭을 강행하지 않는다

## 검증

실제 목표 노트북에서 참조 이미지와 정면·측면·동작 확대 외형을 비교하고, 남녀 리그의 관절 변형·두 아바타 동시 재생·지연·프레임 안정성을 확인한다. 동작별 정상·오류·가림 사례를 별도 판정 하네스로 검증한다. 모델·텍스처·애니메이션의 사용·재배포 권리를 기록한다. 통과 수치와 리타게팅 방식은 실측 전 확정하지 않는다.

## 영향

ADR-0009의 뼈대·정적 마네킹과 ADR-0014의 스켈레톤/회색 표시는 시제품 설명으로 남는다. 첫 출시의 시각화·확인 불가 UX에는 이 결정이 우선한다. 좋음·주의·이탈의 3단계 판정 원칙과 진단 금지는 유지한다.
