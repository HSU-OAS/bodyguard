# ADR-0016. 손가락은 MediaPipe Gesture Recognizer로

상태: 확정 (2026-09-26) · 근거: 원문 53, 54, 55

## 맥락
몸 모델(Pose)은 손을 엄지·검지·새끼 뿌리 세 점으로만 준다. 엄지척 같은 손 모양을 알 수 없다.
사용자가 손가락도 붙이기를 원했다. 나중에 캐릭터(아바타)가 붙을 때도 손가락이 있어야 자연스럽다 (원문 53, 54).

## 결정
- 같은 패키지(MediaPipe Tasks Vision 1.0)의 Gesture Recognizer를 쓴다. 모델 8.0MB, Apache-2.0
- 손마다 21점과 제스처(엄지척, 엄지 아래, 주먹, 편 손바닥, 검지 위, 브이, 사랑해)를 받는다. 두 손까지
- 3D에서는 손 모델의 손목을 몸 모델의 손목 위치로 옮겨 붙인다. 어느 손인지는 몸 손목과 가까운 쪽으로 정한다
- 손가락이 붙은 쪽은 몸 모델의 거친 손 점을 그리지 않는다
- GPU로 먼저 시도하고 안 되면 CPU로 내려간다. 데모에서는 켜고 끌 수 있다

## 근거
- 새 의존성 없이 이미 쓰는 패키지 안에서 해결된다
- 제스처 분류까지 모델이 해 줘서 직접 만들 것이 없다
- 사용자가 엄지척과 손가락이 붙는 것을 직접 확인했다 (원문 55)

## 결과
- 추론이 몸 모델에 더해진다. 녹화에서 heavy 기준 몸 19.3ms, 손 14.1ms, 26fps였다 (2026-09-27)
- 두 모델 좌표계의 축이 같다고 보고 위치만 맞추므로 손 크기·방향은 근사치다
- 제스처를 제품에서 어디에 쓸지는 정하지 않았다 (Q-29). 지금은 데모에서 표시만 한다
