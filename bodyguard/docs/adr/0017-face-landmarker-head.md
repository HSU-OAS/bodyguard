# ADR-0017. 둥근 머리의 방향과 눈·입은 MediaPipe Face Landmarker로

상태: 확정 (2026-09-27) · 근거: 원문 55, 56, 57

## 맥락
스켈레톤 머리를 둥근 얼굴로 바꾼 뒤(원문 55), 처음에는 몸 모델(Pose)의 얼굴 점 깊이값 z로 머리 방향을 구했다.
사용자가 녹화한 52초를 0.1초 간격으로 재 보니 늘 아래를 보고(2D 중앙값 41°, 3D 32°) 2D는 0.1초 사이 좌우로 최대 20°씩 튀었다 (원문 56).
눈과 입꼬리의 세로 간격이 5~6cm라, 깊이가 몇 cm만 틀려도 수십 도가 된다. 몸 모델의 z는 머리 방향을 구할 만큼 정확하지 않다.

## 결정
- 같은 패키지(MediaPipe Tasks Vision 1.0)의 Face Landmarker를 쓴다. 모델 3.8MB, Apache-2.0
- 머리 방향: 얼굴 변환 행렬(4×4)의 회전을 쓴다. 저장 순서는 맨 아래 행이 [0 0 0 1]인지로 확인한다
- 정면 기준: 측정 시작 뒤 얼굴이 처음 보이고 2초 동안의 평균 방향을 정면으로 삼는다. 카메라가 모니터 위나 옆에 있어도 화면을 보면 캐릭터가 나를 본다
- 떨림: 머리 방향을 0.05초 시간 상수로 부드럽게 한다. 3D는 화면 프레임 사이도 이어 준다
- 눈·입: 얼굴 478점에서 눈꺼풀 사이 ÷ 눈 너비, 입술 사이 ÷ 입 너비를 잰다. 눈은 정면 기준 2초 동안의 값을 평소로 본다. 어느 눈인지는 번호가 아니라 화면 위치로 정한다
- 표정 계수(blendshapes)는 받지 않는다. 왼쪽·오른쪽 이름이 사람 기준인지 화면 기준인지 확인하지 못했다
- 머리 자리와 크기는 지금처럼 몸 모델의 귀로 정한다. 스켈레톤 목에 붙어 있어야 해서다
- 데모에서 켜고 끌 수 있다. 끄거나 얼굴을 못 찾으면 둥근 머리는 정면을 본다

## 근거
- 얼굴 전체 모양을 맞춰 방향을 구해서, 깊이값 몇 개에 기대는 방법보다 정확하고 덜 떨린다
- 눈 깜빡임·입 벌림을 따라 해 캐릭터가 살아 있어 보인다
- 목 전방 측정 후보 C(design §5.4)에서도 쓰려던 모델이다
- 사용자가 두 방법(얼굴 모델 추가 / 모델 없이 화면상 위치로 계산) 중 이쪽을 골랐다 (원문 57)

## 결과
- 추론이 한 번 더 돈다. fps가 15 밑으로 떨어지면 얼굴 추론을 두 프레임에 한 번으로 줄인다
- 정면 기준을 잡는 2초 동안 화면을 보고 있어야 한다. 제품에서는 기준선 보정(FR-M-03) 때 함께 찍는다
- 정면 기준은 그리는 데만 쓴다. 판정 지표에는 쓰지 않는다
- 사람 얼굴로 확인한 것은 사용자 테스트뿐이다. 회전 방향은 가짜 얼굴 상태와 단위 테스트로 2D·3D가 맞는지까지 확인했다
