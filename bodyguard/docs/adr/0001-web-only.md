# ADR-0001. 웹 전용, 데스크톱 크롬·엣지

상태: 웹 전용은 확정 (2026-09-13, 차터) · 브라우저 범위는 제안 (Q-22) · 근거: 원문 7, 차터 범위

## 맥락
과목은 서버·DB가 있는 웹 서비스를 기본으로 한다(원문 7). 대상 사용자는 노트북 앞에 앉아 있다.

## 결정
- 네이티브 앱을 만들지 않는다. 웹으로 한정한다
- 데스크톱 크롬·엣지 최신 버전만 지원한다 `[PO 제안]`
- 모바일 브라우저는 지원하지 않는다 `[PO 제안]`

## 근거
- 자세가 무너지는 곳이 노트북 앞이고, 거기 웹캠이 있다
- 가려진 탭 동작(M-1)과 카메라 API가 브라우저마다 다르다. 두 사람이 모든 브라우저를 확인할 수 없다
- 크롬과 엣지는 엔진이 같아 한 번 확인하면 둘 다 된다. 가려진 탭 측정에 쓸 수 있는 `MediaStreamTrackProcessor`도 이쪽에만 있다

## 결과
- 사파리·파이어폭스 사용자에게는 안내 문구를 띄운다
- 사용자 테스트 참가자는 크롬이나 엣지를 쓴다
