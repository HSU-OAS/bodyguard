# ADR — 의사결정 기록

왜 그렇게 정했는지 남긴다. 이유가 없으면 나중에 팀원이나 에이전트가 되돌려 놓는다.

상태는 세 가지다.
- **확정**: 사용자가 정했거나 과목 차터·PRD에서 합의된 것
- **제안**: PO가 정했고 아직 확인받지 않은 것 (`open-questions.md`)
- **검토 중**: 실측이나 결정이 끝나야 확정되는 것

| # | 결정 | 상태 |
|---|---|---|
| 0001 | 웹 전용, 데스크톱 크롬·엣지 | 웹 전용은 확정, 브라우저 범위는 제안 |
| 0002 | 포즈 추정은 브라우저 안에서, 영상은 밖으로 나가지 않음 | 확정 |
| 0003 | 서버에는 1분 요약만 저장 | 확정 |
| 0004 | 웹을 켜 둔 동안만 측정, 가려진 탭은 1초 간격 | 확정 (가려진 탭 측정은 M-1 검증 전) |
| 0005 | 정자세 기준은 사용자가 찍은 자기 자세 | 확정 (보정 세부는 제안) |
| 0006 | 로그인은 구글과 이메일 가입, FastAPI에서 직접 | 확정 |
| 0007 | 포즈 추정은 MediaPipe를 검증 대상으로 | 검토 중 (설치·동작은 확인) |
| 0008 | 의학적 진단을 하지 않음 | 확정 |
| 0009 | 정자세 모델은 뼈대로 시작해 마네킹형으로 | 시제품 경로로 한정; 첫 출시 기준은 0018 |
| 0010 | 알림은 자세 이탈 5분, 연속 착석 50분 | 확정 (세는 방식은 제안) |
| 0011 | 한 레포 안에 frontend와 backend | 확정 |
| 0012 | 판정 엔진은 브라우저 API 없는 순수 TypeScript | 제안 |
| 0013 | 리포트 요약은 상용 LLM API, 가장 싼 모델로 | 확정 (제공사는 비교 후) |
| 0014 | 판정은 3단계 색, 시제품 스켈레톤에 표시 | 3단계는 유지; 출시 시각화는 0018 |
| 0015 | 기술 스택과 버전 (실제 설치·빌드로 검증) | 확정 |
| 0016 | 손가락은 MediaPipe Gesture Recognizer로 | 확정 |
| 0017 | 둥근 머리의 방향과 눈·입은 MediaPipe Face Landmarker로 | 확정 |
| 0018 | Blender 제작 남녀 3D 아바타 두 개와 안전한 판정 경계 | 출시 범위 확정, 세부 검증 중 |
