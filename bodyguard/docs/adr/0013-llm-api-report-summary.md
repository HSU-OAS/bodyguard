# ADR-0013. 리포트 요약은 상용 LLM API, 가장 싼 모델로

상태: 확정 (2026-09-26) · 제공사는 비교 후 결정 (Q-27) · 근거: 원문 6, 8, 41

## 맥락
차터는 AI 기능 3개 중 하나로 "측정 리포트 생성"을 적었다. 9/13에는 이를 "측정 결과 → 자연어 리포트"로 잡았다.
그런데 PRD부터는 "PDF 출력"만 남아 설계에 LLM이 없었다.

## 결정
- 리포트 첫 장에 LLM이 쓴 한 단락 요약을 넣는다
- 모델을 직접 만들지 않고 상용 LLM API를 부른다
- 회사별 가장 싼 모델 2~3개를 같은 테스트 입력 20개로 비교해, 검사를 통과하는 것 중 가장 싼 모델을 쓴다

## 근거
- 사용자가 골랐다 (원문 41). 9/13에도 "클로드나 GPT API 할수도"라고 했다 (원문 6)
- 요약 한 장은 입력 3천·출력 5백 토큰 정도라 가장 싼 모델이면 장당 몇 원 수준이다
- 검사 통과율을 비교한 결과가 곧 과목의 Hallucination 평가 자료가 된다

## 결과
- 서버에서만 부른다. API 키는 `.env`에만 둔다
- 집계 숫자만 보낸다. 이름·이메일·계정 ID는 보내지 않는다. 영상과 좌표는 원래 서버에 없다
- 문장 속 숫자가 입력에 없거나 질환·진단 표현이 있으면 요약을 버리고 PDF만 만든다 (FR-R-07)
- 호출이 실패하거나 느려도 요약 없이 리포트를 만든다. 요약은 있으면 좋은 것이지 리포트의 전제가 아니다
- 외부 AI로 숫자가 간다는 고지는 개인정보 동의(Q-26)와 함께 개발 막바지에 정한다
