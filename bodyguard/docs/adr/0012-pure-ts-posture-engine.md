# ADR-0012. 판정 엔진은 브라우저 API 없는 순수 TypeScript

상태: 제안 · 근거: constitution T1

## 맥락
판정 수치는 실측하면서 계속 바뀐다. 바꿀 때마다 카메라 앞에 앉아서 확인하면 느리고, 같은 조건을 재현할 수 없다.

## 결정 `[PO 제안]`
- `posture/`(지표·상태 머신)와 `stretch/`(스트레칭 판정)는 DOM·MediaPipe·Three.js를 import하지 않는다
- 입력은 관절 좌표 배열, 출력은 숫자와 상태다
- 팀원이 기록한 관절 좌표 픽스처로 Vitest에서 검증한다

## 근거
- 임계값을 바꾸고 수백 개 샘플을 몇 초 안에 다시 돌릴 수 있다
- 같은 입력으로 결과를 재현할 수 있어 일치율 실험(NFR-04)에 쓸 수 있다

## 결과
- 픽스처에는 관절 좌표만 담는다. 영상은 담지 않는다
- 픽스처는 팀원 본인 것만 쓴다. 사용자 테스트 참가자의 데이터는 넣지 않는다
