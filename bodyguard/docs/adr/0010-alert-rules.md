# ADR-0010. 알림은 자세 이탈 5분, 연속 착석 50분

상태: 확정 (2026-09-26) · 세는 방식은 제안 (Q-07, Q-08) · 근거: 원문 32

## 맥락
과목 PRD에는 "정자세 이탈이 이어지면 스트레칭 안내"만 있었다.
그러면 자세만 괜찮으면 몇 시간을 앉아 있어도 알림이 없다.

## 결정
- 자세가 5분 넘게 무너지면 알린다
- 자세가 괜찮아도 50분 앉아 있으면 알린다
- 두 값은 초기값이다. 설정에서 바꾸거나 끌 수 있다

## 근거
- 사용자가 골랐다 (원문 32)
- 자세가 나쁜 것과 오래 앉아 있는 것은 다른 문제다. 둘 다 잡아야 "스트레칭을 잊는다"는 문제를 푼다

## 결과
- 짧게 바로 앉았다가 다시 무너진 경우를 어떻게 셀지, 자리를 비운 걸 어떻게 알지는 design §7의 제안이다
- 카메라는 앉았는지 섰는지 모른다. "화면에 보이면 앉아 있음"으로 본다
