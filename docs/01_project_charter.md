## 만들 것

- 웹캠 기반 실시간 자세 인식 (브라우저 온디바이스)
- 3D 인체 아바타 정자세 가이드, 어긋난 부위 색상 구분
- 스트레칭 6~8종(목·어깨·등·허리) 코칭, 필요한 동작은 유지시간 판정
- 자세 지표 3종 측정·누적 및 대시보드
- 측정 리포트 PDF 출력
- 자세 지표 시계열 변화 탐지

## 만들지 않을 것

| 제외 | 이유 |
|---|---|
| 의학적 진단 및 질환 판정 | 규제 영역. 측정 기록 제공까지만 |
| 카메라 영상 저장·전송 | 개인정보 보호 설계의 전제 |
| Native App (iOS / Android) | 웹으로 한정 |
| 자체 포즈 추정 모델 학습 | 기존 OSS 활용 |
| 상용 운영 및 결제 | 범위 밖 |
| 웨어러블·외부 센서 연동 | 범위 밖 |
